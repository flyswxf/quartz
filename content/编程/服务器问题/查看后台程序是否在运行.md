
```bash
# 查找进程 ID
ps aux | grep "node"
# 终止进程
kill -9 <PID>
```

# 使用案例:
![[assets/进程监控结果.png]]
#### **第一行：Node.js 进程**

```bash
root      753293  0.0  4.8 11812100 92488 ?      Sl   14:01   0:03 node server.js
```
- ​**USER**: `root`  
    进程所有者是 `root` 用户。
    
- ​**PID**: `753293`  
    进程的唯一标识符（Process ID）。
    
- ​**%CPU**: `0.0%`  
    CPU 使用率较低，当前未占用 CPU。
    
- ​**%MEM**: `4.8%`  
    内存占用率为系统总内存的 4.8%。
    
- ​**VSZ**: `11812100`  
    虚拟内存大小（约 11.8 GB）。
    
- ​**RSS**: `92488`  
    实际使用的物理内存（约 92.5 MB）。
    
- ​**TTY**: `?`  
    进程未关联到任何终端（通常是后台服务或守护进程）。
    
- ​**STAT**: `Sl`
    
    - `S`: 进程处于休眠（Sleep）状态（等待事件完成）。
    - `l`: 多线程进程。
- ​**START**: `14:01`  
    进程启动时间为 14:01。
    
- ​**TIME**: `0:03`  
    累计 CPU 使用时间为 3 秒。
    
- ​**COMMAND**: `node server.js`  
    启动进程的命令，表示这是一个 Node.js 应用，运行 `server.js` 文件。
    
#### ​**第二行：grep 进程自身**
```bash
root      755217  0.0  0.0 221528   868 pts/0    S+   14:53   0:00 grep --color=auto node
```
- ​**USER**: `root`  
    您当前使用的 `grep` 命令以 `root` 身份运行。
    
- ​**PID**: `755217`  
    `grep` 进程的 ID。
    
- ​**%CPU** / ​**%MEM**: `0.0%`  
    资源占用极低，因为是瞬时命令。
    
- ​**TTY**: `pts/0`  
    进程关联到终端 `pts/0`（您当前的操作终端）。
    
- ​**STAT**: `S+`
    
    - `S`: 休眠状态。
    - `+`: 进程在前台运行（您通过终端直接执行了命令）。
- ​**COMMAND**: `grep --color=auto node`  
    这是您运行的 `grep` 命令本身，用于搜索包含 "node" 的进程。  
    （由于 `grep` 命令包含 "node" 关键字，所以它也会出现在结果中。）
    

---

### 关键结论：

1. ​**Node.js 应用在运行**  
    第一个进程是实际运行的 Node.js 服务（`node server.js`），占用了 4.8% 的系统内存。
    
2. ​**grep 自身进程**  
    第二个进程是 `grep` 命令的临时进程，执行完成后会自动消失。
