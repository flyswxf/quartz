# 批量归一化 (Batch Normalization)

## 1. 简介
**批量归一化 (Batch Normalization, BN)** 是深度学习中非常重要的一项技术，由 Ioffe 和 Szegedy 在 2015 年提出。它的主要作用是加速神经网络的训练过程，并使其更加稳定。虽然它主要被认为是一种优化手段，但由于其在小批量上计算带来的噪声效应，它也具有轻微的**正则化 (Regularization)** 作用，可以在一定程度上减少过拟合。

## 2. 核心思想
在深度神经网络中，随着前面各层参数的不断更新，后面各层接收到的输入数据的分布也会不断发生变化，这种现象被称为**内部协变量偏移 (Internal Covariate Shift, ICS)**。这导致网络难以训练，需要极小的学习率和严格的参数初始化。

批量归一化的核心思想是：**在每一层的非线性激活函数之前（或之后），对该层的输入数据进行归一化处理，使其均值为 0，方差为 1。** 然后再通过两个可学习的参数进行缩放和平移，以恢复网络的表达能力。

## 3. 计算公式
对于一个大小为 $m$ 的小批量 (Mini-batch) 数据 $\mathcal{B} = \{x_1, x_2, \dots, x_m\}$，批量归一化的具体步骤如下：

### 3.1 计算小批量均值 (Mini-batch mean)
$$ \mu_{\mathcal{B}} = \frac{1}{m} \sum_{i=1}^m x_i $$

### 3.2 计算小批量方差 (Mini-batch variance)
$$ \sigma_{\mathcal{B}}^2 = \frac{1}{m} \sum_{i=1}^m (x_i - \mu_{\mathcal{B}})^2 $$

### 3.3 标准化 (Normalize)
$$ \hat{x}_i = \frac{x_i - \mu_{\mathcal{B}}}{\sqrt{\sigma_{\mathcal{B}}^2 + \epsilon}} $$
> 其中 $\epsilon$ 是一个极小的常数（如 $1e-5$），用于防止方差为零导致的分母异常。

### 3.4 缩放和平移 (Scale and Shift)
$$ y_i = \gamma \hat{x}_i + \beta $$
> 其中 $\gamma$ 和 $\beta$ 是网络在训练过程中**需要学习的参数**。
> **为什么需要这一步？** 如果只做标准化，网络强制将特征限制在标准正态分布，可能会破坏底层特征的非线性表达能力。通过引入 $\gamma$ 和 $\beta$，网络可以自己学习是否需要撤销归一化（当 $\gamma = \sqrt{\sigma_{\mathcal{B}}^2 + \epsilon}$ 且 $\beta = \mu_{\mathcal{B}}$ 时，就能完全恢复原始特征）。

## 4. 为什么 BN 具有正则化效果？
将 BN 归类到正则化方法中是合理的。在训练阶段，每一个样本的归一化结果 $\hat{x}_i$ 都依赖于当前同一个小批量中的其他样本（因为均值和方差是基于整个 Batch 动态计算的）。

这种机制为单个样本的特征计算引入了**一定的随机噪声**。类似于 Dropout，这种随机性使得网络不能过度依赖某一个特定的局部特征，从而起到了轻微的正则化效果。使用 BN 的网络往往可以减少甚至完全移除 Dropout。

## 5. 训练与推理（测试）的区别
批量归一化在训练和测试阶段的行为是**完全不同**的：
- **训练阶段 (Training)**：均值 $\mu_{\mathcal{B}}$ 和方差 $\sigma_{\mathcal{B}}^2$ 是在**当前的小批量**上实时计算的。同时，网络会在后台维护一个全局的移动平均均值 (Running Mean) 和移动平均方差 (Running Variance)。
- **推理阶段 (Evaluation/Testing)**：在预测单个样本或测试集时，不存在或不应该依赖当前的“批量”概念。因此，测试时**不再计算**当前的批量均值和方差，而是直接使用训练期间积累保存好的**全局移动平均均值和方差**。

## 6. PyTorch 实现与应用
在 PyTorch 中，根据处理的数据维度不同，通常使用 `nn.BatchNorm1d` (处理全连接层输出) 或 `nn.BatchNorm2d` (处理卷积层输出)。

### 6.1 归一化作用的具体维度 (全连接层 vs 卷积层)
批量归一化在处理不同类型的层时，其计算均值和方差的**维度**是不同的：

- **全连接层 (Fully Connected Layer / Linear)**
  - **输入形状**：通常为 `[N, D]`，其中 $N$ 是批次大小 (Batch Size)，$D$ 是特征维度 (Features)。
  - **归一化维度**：在**批次维度 $N$** 上进行归一化。
  - **具体表现**：对于 $D$ 个特征中的每一个单独特征，网络会跨越整个 Batch 的 $N$ 个样本计算一个均值和方差。因此，最终会得到 $D$ 个均值和 $D$ 个方差。
  - **对应 PyTorch 类**：`nn.BatchNorm1d`。

- **卷积层 (Convolutional Layer)**
  - **输入形状**：通常为 `[N, C, H, W]`，其中 $N$ 是批次大小，$C$ 是通道数 (Channels)，$H$ 和 $W$ 是空间高和宽。
  - **归一化维度**：在**批次维度 $N$ 以及空间维度 $H$ 和 $W$** 上同时进行归一化。
  - **具体表现**：对于 $C$ 个通道中的每一个通道，网络会把所有 $N$ 个样本在该通道下的所有 $H \times W$ 个像素点聚在一起，计算出一个均值和方差。因此，最终会得到 $C$ 个均值和 $C$ 个方差（而不是 $C \times H \times W$ 个）。这种方式也被称为**空间批量归一化 (Spatial Batch Normalization)**。
  - **对应 PyTorch 类**：`nn.BatchNorm2d`。

### 6.2 常用的放置位置
在经典的 CNN 架构（如 ResNet）中，标准的位置通常是放在**线性层或卷积层之后，激活函数之前**。

```python
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        # 卷积层 -> BN层 -> 激活层
        self.conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)
        # 注意：BatchNorm2d 的参数 (num_features) 必须是上一层卷积的输出通道数
        self.bn2d = nn.BatchNorm2d(num_features=16)
        self.relu_conv = nn.ReLU()
        
        # 全连接层 -> BN层 -> 激活层
        # 假设输入特征展平后大小为 16 * 32 * 32
        self.fc = nn.Linear(16 * 32 * 32, 128)
        # 注意：BatchNorm1d 的参数必须是上一层全连接层的输出神经元数
        self.bn1d = nn.BatchNorm1d(num_features=128)
        self.relu_fc = nn.ReLU()

    def forward(self, x):
        # 卷积块
        x = self.conv(x)
        x = self.bn2d(x)
        x = self.relu_conv(x)
        
        # 展平后进入全连接块
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        x = self.bn1d(x)
        x = self.relu_fc(x)
        return x
```
