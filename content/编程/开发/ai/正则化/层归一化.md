# 层归一化 (Layer Normalization)

## 核心思想
层归一化（Layer Normalization, LayerNorm）旨在解决批量归一化（Batch Normalization）在小批量（Small Batch Size）和序列模型（如 RNN、Transformer）中表现不佳的问题。

与 BatchNorm 在特征维度（通道维度）上对整个 Batch 计算均值和方差不同，**LayerNorm 是在单个样本上，对所有特征（或指定的最后几个维度）计算均值和方差**。

因此，LayerNorm 的计算**完全独立于 Batch Size**，即使 Batch Size 为 1 也能正常工作。

**计算公式**：
$$y = \frac{x - E[x]}{\sqrt{Var[x] + \epsilon}} * \gamma + \beta$$
其中 $\gamma$ 和 $\beta$ 是可学习的仿射变换参数（缩放和平移），$\epsilon$ 是为了防止分母为 0 的极小值。

## PyTorch 实现/使用
在 PyTorch 中，可以使用 `torch.nn.LayerNorm` 来实现层归一化。

```python
import torch
import torch.nn as nn

# 假设输入特征维度为: (batch_size, seq_len, hidden_size)
# 例如 NLP 中的常见形状: (32, 10, 512)
batch_size, seq_len, hidden_size = 32, 10, 512
x = torch.randn(batch_size, seq_len, hidden_size)

# 1. 实例化 LayerNorm
# normalized_shape 通常是输入张量的最后几个维度的形状
# 这里我们对最后一个维度 (hidden_size) 进行归一化
layer_norm = nn.LayerNorm(normalized_shape=hidden_size)

# 2. 前向传播
output = layer_norm(x)

print("输入形状:", x.shape)
print("输出形状:", output.shape)

# 验证均值和方差 (在最后一个维度上计算)
# output 的均值应该接近 0，方差应该接近 1
print("均值:", output[0, 0, :].mean().item()) 
print("方差:", output[0, 0, :].var(unbiased=False).item())
```

## 关键要点说明
- **独立于批量大小**：LayerNorm 的计算不需要依赖同一 Batch 内的其他样本，这使得它非常适合动态序列长度的模型（如 RNN）以及 Batch Size 极其受限的场景。
- **Transformer 的标配**：LayerNorm 是 Transformer 架构（包括 BERT、GPT 等模型）中的核心组件之一，通常应用于 Multi-Head Attention 和 Feed Forward Network 的前后（Pre-Norm 或 Post-Norm）。
- **`normalized_shape` 参数**：指定要进行归一化的维度形状。
  - 如果输入形状是 `(N, C, H, W)`，`normalized_shape=[C, H, W]` 会在 `C, H, W` 这三个维度上求均值和方差。
  - 如果传入一个整数如 `normalized_shape=W`，则只在最后一个维度求均值和方差。
- **`elementwise_affine` 参数**：默认为 `True`，表示是否包含可学习的参数 $\gamma$ 和 $\beta$。如果不希望模型去学习缩放和平移，可以将其设置为 `False`。
