# 二分类评价指标

二分类模型的输出通常是"预测为正类"或"预测为负类"，但仅看预测结果无法全面衡量模型好坏。评价指标从不同角度刻画模型性能，选择哪个指标取决于实际场景中**更关心什么**。

## 1. 混淆矩阵 (Confusion Matrix)

所有二分类指标的起点。对于 $N$ 个样本，模型预测与真实标签的组合形成四类：

|              | 预测为正       | 预测为负       |
| ------------ | -------------- | -------------- |
| **实际为正** | $TP$（真正例） | $FN$（假负例） |
| **实际为负** | $FP$（假正例） | $TN$（真负例） |

- $TP$：模型正确地将正样本预测为正
- $FP$：模型错误地将负样本预测为正（"误报"）
- $FN$：模型错误地将正样本预测为负（"漏报"）
- $TN$：模型正确地将负样本预测为负

记忆方式: 下午(下面的FP是误报), yolo(右边的FN是漏报)
## 2. 四大核心指标

### 2.1 准确率 (Accuracy)

所有样本中，预测正确的比例：

$$ \text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} $$

**直觉**：100 个样本中模型答对了多少个？

**局限**：当类别严重不平衡时会产生误导。例如正样本仅占 1%，模型全部预测为负，准确率仍为 99%，但对正类毫无识别能力。

### 2.2 精确率 (Precision)

预测为正类的样本中，真正为正的比例：

$$ \text{Precision} = \frac{TP}{TP + FP} $$

**直觉**：模型说"这是正的"，有多大比例真的是正的？

**关注点**：控制**误报**（$FP$）。适用于"宁可漏掉，也不能误判"的场景，如垃圾邮件过滤（误将正常邮件判为垃圾的代价高）。

### 2.3 召回率 (Recall / Sensitivity / True Positive Rate)

所有真正为正的样本中，被模型正确识别的比例：

$$ \text{Recall} = \frac{TP}{TP + FN} $$

**直觉**：100 个真正的正样本，模型找到了多少个？

**关注点**：控制**漏报**（$FN$）。适用于"宁可误报，也不能漏掉"的场景，如癌症筛查（漏诊的代价极高）。

### 2.4 F1 分数 (F1 Score)

精确率和召回率的**调和平均**，综合衡量两者：

$$ F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} $$

**为什么用调和平均而非算术平均？** 调和平均对较小值更敏感。如果 Precision 或 Recall 中有一个很低，$F_1$ 会显著下降，不会被另一个高值"掩盖"。

更一般地，$F_\beta$ 分数可以通过 $\beta$ 调节对精确率和召回率的偏好：

$$ F_\beta = (1 + \beta^2) \cdot \frac{\text{Precision} \cdot \text{Recall}}{\beta^2 \cdot \text{Precision} + \text{Recall}} $$

- $\beta > 1$：更重视召回率
- $\beta < 1$：更重视精确率
- $\beta = 1$：即 $F_1$，两者同等重要

## 3. 指标之间的关系

$$ \text{Precision} \uparrow \iff \text{Recall} \downarrow \quad \text{（通常存在此消彼长的关系）} $$

- 提高阈值 → 预测为正的样本更少 → $FP$ 减少 → Precision 升高，但 $FN$ 增多 → Recall 降低
- 降低阈值 → 预测为正的样本更多 → $FN$ 减少 → Recall 升高，但 $FP$ 增多 → Precision 降低

这种权衡可以通过 **Precision-Recall 曲线**（PR 曲线）来可视化：以 Recall 为横轴、Precision 为纵轴，不同阈值下画出曲线。曲线下面积（AUC-PR）越大，模型越好。

## 4. 场景选择指南

| 场景               | 推荐指标     | 原因                         |
| ------------------ | ------------ | ---------------------------- |
| 类别均衡           | Accuracy     | 直观且有效                   |
| 类别不平衡         | F1 / PR 曲线 | Accuracy 会产生误导          |
| 垃圾邮件过滤       | Precision    | 误报代价高（正常邮件被误删） |
| 癌症筛查           | Recall       | 漏报代价高（漏诊后果严重）   |
| 需要概率输出的质量 | AUC-ROC      | 评估模型对正负样本的排序能力 |

## 5. PyTorch 实现

```python
import torch

def binary_confusion_matrix(preds: torch.Tensor, targets: torch.Tensor, threshold: float = 0.5):
    pred_labels = (preds >= threshold).long()
    tp = ((pred_labels == 1) & (targets == 1)).sum().item()
    fp = ((pred_labels == 1) & (targets == 0)).sum().item()
    fn = ((pred_labels == 0) & (targets == 1)).sum().item()
    tn = ((pred_labels == 0) & (targets == 0)).sum().item()
    return tp, fp, fn, tn

def precision(preds: torch.Tensor, targets: torch.Tensor, threshold: float = 0.5):
    tp, fp, fn, _ = binary_confusion_matrix(preds, targets, threshold)
    return tp / (tp + fp) if (tp + fp) > 0 else 0.0

def recall(preds: torch.Tensor, targets: torch.Tensor, threshold: float = 0.5):
    tp, fp, fn, _ = binary_confusion_matrix(preds, targets, threshold)
    return tp / (tp + fn) if (tp + fn) > 0 else 0.0

def f1_score(preds: torch.Tensor, targets: torch.Tensor, threshold: float = 0.5):
    p = precision(preds, targets, threshold)
    r = recall(preds, targets, threshold)
    return 2 * p * r / (p + r) if (p + r) > 0 else 0.0

preds = torch.tensor([0.9, 0.3, 0.8, 0.1, 0.7])
targets = torch.tensor([1, 0, 1, 0, 1])

print(f"Precision: {precision(preds, targets):.4f}")
print(f"Recall:    {recall(preds, targets):.4f}")
print(f"F1 Score:  {f1_score(preds, targets):.4f}")
```

> 实际项目中推荐使用 `torchmetrics` 库，它提供了更完善的指标计算（支持 batch 累积、分布式训练等）。

## 6. 关键要点说明

- **Accuracy 的陷阱**：类别不平衡时几乎无用，务必配合其他指标
- **Precision 与 Recall 的取舍**：取决于业务场景中误报和漏报哪个代价更大
- **F1 是 Precision 和 Recall 的调和平均**：对短板敏感，不会被单一高值误导
- **阈值的影响**：所有基于硬分类的指标（Precision/Recall/F1）都依赖分类阈值，选择不同阈值会得到不同结果
- **AUC-ROC 和 AUC-PR**：当需要评估模型在**所有阈值**下的综合表现时，使用曲线下的面积更稳健
