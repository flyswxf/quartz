# 访问神经网络特定层的权重 (嵌套结构示例)

在实际的深度学习项目（如 ResNet、VGG 或自定义架构）中，模型结构往往比较深且复杂。我们通常会使用 `nn.Sequential` 来堆叠多个基础模块（Block），而每个 Block 内部可能又是由一个或多个 `nn.Sequential` 组成的卷积、归一化和激活层。

以下是一个更加贴合实际的 PyTorch 模型例子，以及在这种嵌套结构中，如何通过 `state_dict()` 和 `named_parameters()` 访问特定层的权重。

## 1. 贴合实际的模型定义 (嵌套的 Sequential)

```python
import torch
import torch.nn as nn

class ConvBlock(nn.Module):
    """一个基础的卷积块，内部使用 nn.Sequential 包含两个卷积层及其对应的 BN 和激活函数"""
    def __init__(self, in_channels, out_channels):
        super(ConvBlock, self).__init__()
        # Block 内部也是一个 Sequential
        self.block = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels)
        )

    def forward(self, x):
        return self.block(x)

class ComplexNet(nn.Module):
    """一个复杂的网络，包含多个嵌套的模块"""
    def __init__(self):
        super(ComplexNet, self).__init__()
        
        # 特征提取层：外层 Sequential 嵌套了多个 ConvBlock
        self.features = nn.Sequential(
            ConvBlock(3, 16),     # features[0]
            nn.MaxPool2d(2),      # features[1]
            ConvBlock(16, 32),    # features[2]
            nn.MaxPool2d(2)       # features[3]
        )
        
        # 分类器层
        self.classifier = nn.Sequential(
            nn.Linear(32 * 8 * 8, 128),
            nn.ReLU(inplace=True),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.features(x)
        x = torch.flatten(x, 1)
        x = self.classifier(x)
        return x

model = ComplexNet()
```

在这个模型中，层级结构非常深。例如，第一个特征提取块的第一个卷积层实际上位于 `model.features[0].block[0]`。

## 2. 方法一：使用 `state_dict()` 访问

`state_dict()` 返回一个包含模型所有状态（包括所有权重和偏置）的有序字典 `OrderedDict`。对于嵌套结构，PyTorch 会自动使用点号 `.` 将层级名称、索引号连接起来作为字典的键。

**适用场景**：明确知道参数的绝对路径名称，通常在加载部分预训练权重（如只加载骨干网络）时非常有用。

```python
state_dict = model.state_dict()

# 可以先打印所有的键名，观察命名规则
# print(state_dict.keys())
# 输出示例: 
# odict_keys([
#   'features.0.block.0.weight', 'features.0.block.0.bias', 
#   'features.0.block.1.weight', 'features.0.block.1.bias', ..., 
#   'classifier.0.weight', 'classifier.0.bias', ...
# ])

# 1. 访问 features 中第 1 个 ConvBlock (索引0) 的第 1 个 Conv2d (索引0) 的权重
conv1_weight = state_dict['features.0.block.0.weight']
print(f"第一个卷积层的权重形状: {conv1_weight.shape}")  # torch.Size([16, 3, 3, 3])

# 2. 访问 classifier 中第一层 Linear (索引0) 的偏置
linear1_bias = state_dict['classifier.0.bias']
print(f"第一个全连接层的偏置形状: {linear1_bias.shape}") # torch.Size([128])
```

## 3. 方法二：使用 `named_parameters()` 遍历访问

`named_parameters()` 返回一个迭代器，产生元组 `(name, parameter)`。由于支持对 `name` 字符串进行正则匹配或包含判断，它在处理复杂嵌套时比 `state_dict` 更加灵活。

**适用场景**：
- 需要对特定类型（或特定命名规则）的层做统一操作（例如按层名冻结特定层的梯度，进行迁移学习）。
- 结合字符串匹配进行模糊查询来提取权重，而不需要硬编码精确的字典键。

```python
# 需求 1：找到 features 中第 2 个 ConvBlock (即 features.2) 的所有参数
print("--- 查找特定 Block 的参数 ---")
for name, param in model.named_parameters():
    # 只要名字中包含 'features.2'，就说明是该 Block 的权重或偏置
    if 'features.2' in name:
        print(f"找到参数: {name}, 形状: {param.shape}")

        # param.requires_grad = False

# 需求 2：批量获取模型中所有的卷积层权重（假设卷积层的参数都叫 weight 且形状为4维）
print("\n--- 查找所有的卷积层权重 ---")
for name, param in model.named_parameters():
    # 这是一个简单的过滤逻辑：名字中有 'weight' 并且张量维度为 4 (Conv2d的特征)
```

### 总结比较
- **`state_dict()`**: 本质是字典提取，适合静态操作（保存/加载模型，针对某个确定层的直接读取）。
- **`named_parameters()`**: 本质是动态遍历，适合需要动态筛选、条件过滤操作（批量冻结层梯度，自定义优化器参数分组）。
