# PyTorch 全连接层 (Linear Layer) 详解

全连接层（Fully Connected Layer），在 PyTorch 中官方名称为**线性层 (`nn.Linear`)**。它通常位于卷积神经网络的末端，负责将前面卷积层提取到的高级局部特征整合起来，映射到最终的分类或回归结果上。

## 1. nn.Linear 的基本语法

```python
import torch.nn as nn

fc_layer = nn.Linear(
    in_features,   # 输入样本的特征数量 (即输入张量的最后一个维度大小)
    out_features,  # 输出样本的特征数量 (通常是分类的类别数，或隐藏层节点数)
    bias=True      # 是否使用偏置项，默认为 True
)
```

### 数学原理：
全连接层本质上就是对输入数据执行一次线性代数中的矩阵乘法（加法）：
$$ y = x A^T + b $$
其中，$x$ 是输入，$A$ 是权重矩阵 (`weight`)，$b$ 是偏置向量 (`bias`)。

---

## 2. 权重的内部结构

全连接层包含了所有的权重连接，因此它是神经网络中**参数量最大**的层

```python
fc = nn.Linear(in_features=128, out_features=10)

# 权重矩阵的形状是 [out_features, in_features]
print(fc.weight.shape) # torch.Size([10, 128]) 

# 偏置向量的形状是 [out_features]
print(fc.bias.shape)   # torch.Size([10])      
```

---

## 3. 核心难点与进阶：维度匹配与展平 (Flatten)

### 3.1 卷积层如何过渡到全连接层？

这是一个初学者最容易卡住的地方：**维度不匹配**。

*   卷积层/池化层输出的张量通常是四维的图像格式：`[batch_size, channels, height, width]`。
*   而全连接层最标准的输入是二维的表格格式：`[batch_size, in_features]`。

因此，在将数据送入全连接层之前，通常**必须将特征图的空间维度展平 (Flatten)**。

**计算 `in_features` 的大小：**
展平后的总特征数等于：`通道数 × 高度 × 宽度`
即 `in_features = channels * height * width`

### 3.2 nn.Linear 对多维输入的自动处理机制 (进阶)

除了标准的二维输入，`nn.Linear` 其实**可以直接接收多维张量**（例如 3 维或 4 维）。

当输入张量的维度大于 2 时，PyTorch 的处理逻辑是：
**将张量的最后一个维度视为特征维度 (`in_features`)，而将前面的所有维度视作独立的样本（即在内部自动展平前面的维度进行计算，然后再恢复形状）。**

```python
# 假设输入是一个 3 维张量: [batch_size, seq_length, hidden_size]
# 常见于 NLP (如 Transformer/RNN 的输出)
x = torch.randn(32, 10, 256) 

# 定义全连接层，接收最后一个维度的大小 256
fc = nn.Linear(in_features=256, out_features=128)

# 直接传入 3 维张量
output = fc(x)

# 输出形状自动变为 [batch_size, seq_length, out_features]
print(output.shape) # torch.Size([32, 10, 128])
```
*这在处理序列数据时非常方便，不需要你手动去 view 成 2 维再 view 回来。*

### 3.3 代码实战示例：在 Sequential 中使用 nn.Flatten

在现代 PyTorch 代码中，推荐使用 `nn.Flatten()` 层将展平操作直接嵌入到模型结构（如 `nn.Sequential`）中，这样可以避免在 `forward` 函数中手动调用 `torch.flatten()`，让代码更整洁。

```python
import torch
import torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        
        self.features = nn.Sequential(
            # 1. 卷积层：[N, 3, 32, 32] -> [N, 16, 32, 32]
            nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
            nn.ReLU(),
            # 2. 池化层：[N, 16, 32, 32] -> [N, 16, 16, 16]
            nn.MaxPool2d(kernel_size=2, stride=2)
        )
        
        self.classifier = nn.Sequential(
            # 3. 展平层：[N, 16, 16, 16] -> [N, 4096]
            # 默认 start_dim=1, end_dim=-1，完美契合保留 batch_size 的需求
            nn.Flatten(),
            
            # 4. 全连接层：[N, 4096] -> [N, 10]
            nn.Linear(in_features=16 * 16 * 16, out_features=10)
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

## 4. 常见的应用场景与注意事项

1. **分类器的输出层**：网络的最后一层往往是 `nn.Linear`，它的 `out_features` 必须等于你的分类类别数。之后通常会接 `Softmax` 激活函数（如果用 `CrossEntropyLoss` 则不需要手动加 Softmax，因为它内部集成了）。
2. **多层感知机 (MLP)**：纯由全连接层堆叠而成的网络结构。
3. **必须配合非线性激活函数**：如果连续堆叠多个全连接层，它们之间**必须**加入非线性激活函数（如 ReLU）。因为线性运算的叠加依然是线性运算，如果没有激活函数，多层全连接层在数学上等价于单层全连接层，失去了深度的意义。
