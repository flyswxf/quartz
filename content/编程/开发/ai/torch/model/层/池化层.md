# PyTorch 池化层 (Pooling Layer) 详解

池化层（Pooling Layer）通常紧跟在卷积层之后，其主要作用是**下采样（Downsampling）**，即降低特征图的空间尺寸（长和宽），同时保留重要的特征信息。

## 1. 为什么需要池化层？

1. **降维与减少计算量**：通过缩小特征图尺寸，能大幅减少后续全连接层的参数量和计算负担，防止显存爆炸。
2. **平移不变性 (Translation Invariance)**：池化操作提取局部区域的代表性特征，对微小的位置平移不敏感，使得网络对图像中目标的位置变化具有更强的鲁棒性。
3. **扩大感受野 (Receptive Field)**：在不增加参数的情况下，特征图变小意味着后续的卷积核能看到原图更大的区域。

---

## 2. 最大池化 (Max Pooling)

最常用的池化方式。它在池化窗口（感受野）内提取**最大值**，主要用于保留最显著的特征（如边缘、纹理等强信号）。

```python
import torch.nn as nn

max_pool = nn.MaxPool2d(
    kernel_size=2,  # 池化窗口大小 (2x2)
    stride=2,       # 步长，默认值通常等于 kernel_size
    padding=0       # 边缘填充，默认为 0
)
```
*注：由于 `stride` 默认等于 `kernel_size`，所以默认情况下，最大池化的窗口之间是**不重叠**的。一个 `2x2` 的最大池化层会将特征图的高和宽直接减半。*

---

## 3. 平均池化 (Average Pooling)

在池化窗口内提取**平均值**，主要用于保留整体的数据分布背景。在早期的网络如 LeNet 中常见，现代网络中更倾向于在网络的最后阶段使用全局平均池化。

```python
avg_pool = nn.AvgPool2d(
    kernel_size=2, 
    stride=2
)
```

---

## 4. 自适应池化 (Adaptive Pooling) - 🔥 极度重要

在现代主流网络（如 ResNet, DenseNet）中，自适应池化被广泛使用。它的核心特点是：**你不需要手动计算和指定 `kernel_size` 和 `stride`，你只需要告诉 PyTorch 你想要的最终输出尺寸！**

PyTorch 会自动在底层帮你反推并计算出合适的核大小和步长，以达到你指定的输出尺寸。

```python
import torch

# 假设输入特征图形状不同
input1 = torch.randn(1, 64, 32, 32)   # 32x32 尺寸
input2 = torch.randn(1, 64, 224, 224) # 224x224 尺寸

# 定义一个目标尺寸为 7x7 的自适应池化层
adaptive_pool = nn.AdaptiveAvgPool2d(output_size=(7, 7))

# 无论输入多大，输出的空间尺寸一定被强制压缩到 7x7
out1 = adaptive_pool(input1) # 形状: [1, 64, 7, 7]
out2 = adaptive_pool(input2) # 形状: [1, 64, 7, 7]
```

### 全局平均池化 (Global Average Pooling, GAP)
自适应池化最经典的应用场景是作为卷积层通向全连接层的“桥梁”。
通过设置 `output_size=(1, 1)`，网络可以将每个通道的所有像素求平均，输出 $1 \times 1$ 的尺寸。

```python
# 将每个通道的空间维度压缩为一个数值
global_pool = nn.AdaptiveAvgPool2d((1, 1))

out = global_pool(input2) 
# 输出形状: [1, 64, 1, 1] 
# 此时空间维度消失，方便直接展平后送入全连接层
```
**GAP 的巨大优势**：它使得网络可以接受**任意尺寸的输入图像**。因为不论前面卷积层的特征图有多大，到了 GAP 这一层都会被强行压缩成固定大小，从而能够顺利送入后面固定输入维度的全连接层。
