在 PyTorch 中，最推荐且最标准的方法是**只保存和加载模型的** **`state_dict`（状态字典）**。`state_dict` 是一个 Python 字典，它将每一层映射到其对应的参数张量（权重和偏置）。

**保存权重：**

```python
import torch

# 假设 model 是你已经训练好的网络
torch.save(model.state_dict(), 'model_weights.pth') # 后缀名通常用 .pth 或 .pt
```

**读取权重：**

```python
# 1. 必须先实例化一个结构完全相同的模型
model = MyNetwork() 

# 2. 加载权重字典到内存
weights = torch.load('model_weights.pth')

# 3. 将权重加载到模型中
model.load_state_dict(weights)
```

> **注意**：这种方法要求你在加载权重前，必须有生成该模型的类定义代码，否则无法实例化 `MyNetwork`。

### `load_state_dict` 的可选参数

`model.load_state_dict(state_dict, strict=True, assign=False)` 包含两个重要参数：

1. **`strict` (bool, 默认 `True`)：是否严格匹配键名**
   - **`True`**：权重字典与模型的键名必须**完全一致**，否则报错。
   - **`False`**：允许不匹配。只加载名字相同的层，多余的丢弃，缺失的保持随机初始化。**常用于迁移学习**（例如修改了最后的分类头，只加载前面的预训练权重）。

2. **`assign` (bool, 默认 `False`)：权重赋值方式**
   - **`False`**：将数据**拷贝（copy）**到模型现有的参数内存中。
   - **`True`**：直接进行**引用赋值**，替换模型原有的参数对象。**常用于加载大模型**（结合 `device='meta'` 初始化模型，省去双倍内存开销）。

## 复用网络的一部分

在计算机视觉或自然语言处理中，这被称为\*\*迁移学习（Transfer Learning）\*\*或特征提取。我们通常会复用预训练模型的特征提取层，并接上自己新的分类头。

假设我们有一个预训练的 `OldNet`，我们想提取它的前两层，放入 `NewNet` 中。

**方法：在** **`NewNet`** **初始化时，将** **`OldNet`** **的层赋值给** **`NewNet`** **的属性。**

```python
import torch
import torch.nn as nn

# 1. 定义旧网络并假设它已训练好
class OldNet(nn.Module):
    def __init__(self):
        super(OldNet, self).__init__()
        self.layer1 = nn.Linear(10, 20)
        self.layer2 = nn.ReLU()
        self.layer3 = nn.Linear(20, 30) # 我们不要这一层

    def forward(self, x):
        x = self.layer1(x)
        x = self.layer2(x)
        return self.layer3(x)

old_model = OldNet()
# torch.save(old_model.state_dict(), 'old_weights.pth') ... 假设这里加载了训练好的权重

# 2. 定义新网络，并在内部直接使用旧网络的层
class NewNet(nn.Module):
    def __init__(self, pretrained_old_model):
        super(NewNet, self).__init__()
        # 直接复用 old_model 的前两层（注意：这会共享内存中的权重，如果在 NewNet 中更新，旧模型也会变）
        # 通常我们会用 nn.Sequential 把它们包起来
        self.extracted_features = nn.Sequential(
            pretrained_old_model.layer1,
            pretrained_old_model.layer2
        )
        
        # 添加新网络独有的层
        self.new_layer = nn.Linear(20, 5) # 假设我们的新任务是 5 分类

    def forward(self, x):
        x = self.extracted_features(x)
        x = self.new_layer(x)
        return x

# 实例化新网络并传入旧网络实例
new_model = NewNet(old_model)

# 可选操作：如果你不希望旧的层在训练中被更新（冻结特征提取器）
for param in new_model.extracted_features.parameters():
    param.requires_grad = False
```

*(注意：如果你使用* *`state_dict`* *字典来复用，需要手动遍历并匹配键名，这在层名不一致时会比较麻烦。直接传递模型实例并复用子模块是 PyTorch 中最 Pythonic 的做法。)*

## 同时保存网络架构和参数(不推荐)
```python
# 直接传入模型实例，而不是 state_dict
torch.save(model, 'entire_model.pth')

# 不需要提前实例化，直接 load
model = torch.load('entire_model.pth')
```

**官方不推荐这种做法：**
虽然看起来很方便，但这种做法有非常严格的限制和隐患，PyTorch 官方文档强烈**不建议**以此作为常规部署或分享模型的方式。

其核心原因在于 Python 的 `pickle` 序列化机制。`torch.save` 保存整个模型时，**并没有真正把模型的源代码保存在文件里**，而是保存了这些类的**路径引用**（例如 `my_project.models.my_net.MyNetwork`）。

因此，限制包括：

1. **代码结构必须严格保持一致**：当你在另一个脚本中调用 `torch.load('entire_model.pth')` 时，当前 Python 运行环境中必须能够按照相同的包路径找到原本的类定义代码。如果你移动了文件、重命名了类名、或者把代码发给没有这个类文件的人，加载会直接报错。
2. **重构噩梦**：如果在未来的版本中，你修改了 `MyNetwork` 类里的 `__init__` 或 `forward` 方法，即使类名没变，由于加载的模型绑定的是旧的内部结构，经常会导致难以排查的运行时错误。
3. **安全风险**：由于使用 `pickle`，加载不可信的完整模型文件存在执行恶意代码的风险（虽然加载 state\_dict 也有风险，但反序列化整个对象风险更大）。

**总结**：除非是在极短期的本地开发调试中，否则永远优先使用保存 `state_dict` 的方式。

## 保存模型参数的好处
即便你只是在本地机器上做实验，不打算将模型部署到生产环境，定期保存模型参数（通常称为 **Checkpointing，保存检查点**）也是极其重要的，主要好处包括：

1. **防止训练意外中断（容灾恢复）**：深度学习训练动辄需要几个小时甚至几天。如果断电、内存溢出（OOM）或系统崩溃，没有保存参数意味着你要从头开始。保存检查点可以让你从断点处继续训练。
2. **选择最佳模型（Early Stopping / Best Checkpoint）**：模型在训练过程中往往会“过拟合”。通常在验证集（Validation Set）上表现最好的模型并不是最后一个 Epoch 的模型。通过在每个 Epoch 保存参数，你可以回溯并挑选出泛化能力最强的那一组权重。
3. **用于对比实验和消融研究**：你可以保存一个“基座模型”的权重，然后基于这组权重尝试不同的微调策略（如改变学习率、冻结不同层），保证所有实验都有相同的起点。
4. **模型集成（Ensemble）**：保存训练过程中不同阶段的参数，在预测时将这些“不同时期”的模型的输出进行平均，通常能提升最终的准确率。
