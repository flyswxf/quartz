# 绝对误差损失 (Mean Absolute Error Loss)

`nn.L1Loss()` 也叫 **平均绝对误差损失**，常用于回归任务。

它和 MSE 一样，都是衡量预测值与真实值之间的差异，但它不是对误差平方，而是直接取绝对值：
$$ |y - \hat{y}| $$

因此它的核心特点是：**对异常值更鲁棒，但在 0 点附近不如 MSE 平滑。**

## 1. 理论基础：为什么取绝对值？

### 1.1 从误差出发
回归任务中最自然的量是误差：
$$ e_i = \hat{y}_i - y_i $$

为了避免正负误差互相抵消，可以把误差转成非负值。与 MSE 的“平方”不同，L1 选择“绝对值”：
$$ \ell_i = |y_i - \hat{y}_i| $$

### 1.2 为什么这种形式有意义？
绝对值的一个重要性质是：**大误差按线性方式增长，而不是像平方那样被放大。**

例如：
- 误差为 1，L1 损失为 1
- 误差为 5，L1 损失为 5

相比之下，MSE 会从 1 放大到 25。

这意味着 L1 不会让少量离群点主导整个训练过程，因此更鲁棒。

### 1.3 统计学视角
如果假设回归误差服从 **拉普拉斯分布（Laplace Distribution）**，那么做极大似然估计时，对应的目标函数正是最小化绝对误差之和。

所以：

**最小化 L1Loss，等价于在误差服从拉普拉斯分布假设下做最大似然估计。**

---

## 2. 为什么它有效？有什么特点？

### 2.1 对异常值更鲁棒
这是 L1Loss 最著名的优点。

如果数据中有一个离群点，其误差非常大：
- MSE 会因为平方而被大幅放大
- L1 只是线性增长，不会过分偏向该样本

因此在噪声较大或异常值较多的回归任务中，L1 往往比 MSE 更稳。

### 2.2 梯度大小基本恒定
对单个样本：
$$ \ell_i = |y_i - \hat{y}_i| $$

其梯度方向取决于误差符号：
- 当 $\hat{y}_i > y_i$ 时，梯度为正
- 当 $\hat{y}_i < y_i$ 时，梯度为负

这意味着它不会像 MSE 那样随着误差变大而产生越来越大的梯度。

### 2.3 0 点不可导
绝对值函数在 0 点不可导，这是它和 MSE 相比的一个不足。

虽然现代优化器可以通过次梯度等方式处理，但从数学光滑性上说，L1 不如 MSE 友好。

### 2.4 预测更偏向中位数
在统计意义上，最小化 L1 往往使模型更接近预测条件中位数；而最小化 MSE 更偏向条件均值。

这是二者一个很重要但容易被忽略的区别。

## 3. PyTorch 中的 `nn.L1Loss()`

### 3.1 使用方法

**接受参数：**
- `input`: 模型预测值
- `target`: 真实值，形状需与 `input` 相同

```python
import torch
from torch import nn

predictions = torch.tensor([2.0, 5.5, 3.2])
targets = torch.tensor([2.5, 5.0, 3.0])

criterion = nn.L1Loss()
loss = criterion(predictions, targets)

print("L1 损失:", loss.item())
```

### 3.2 📐 数学公式

对于 $N$ 个样本，平均绝对误差为：
$$ \text{L1Loss} = \frac{1}{N} \sum_{i=1}^{N} |y_i - \hat{y}_i| $$

### 3.3 📝 举例说明

假设：
- 预测值 $\hat{y} = [2.0, 5.5, 3.2]$
- 真实值 $y = [2.5, 5.0, 3.0]$

第一步：计算误差
$$ \hat{y} - y = [-0.5, 0.5, 0.2] $$

第二步：取绝对值
$$ [0.5, 0.5, 0.2] $$

第三步：求平均
$$ \text{L1Loss} = \frac{0.5 + 0.5 + 0.2}{3} = \frac{1.2}{3} = 0.4 $$

---

## 4. 和 MSE 的区别

- `L1Loss`：对异常值更鲁棒，但不够平滑
- `MSELoss`：优化更平滑，但对离群点敏感

如果你担心数据中存在异常值，L1 往往是比 MSE 更稳健的选择。

---

## 5. 一句话理解

`nn.L1Loss()` 的本质是：

**直接衡量“平均偏差有多大”，不过分放大大误差，因此对异常值更稳。**
