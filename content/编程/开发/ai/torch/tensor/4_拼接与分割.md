# 4_拼接与分割

## 核心思想
在数据预处理阶段（如构造 Batch）、特征融合（如 ResNet 或 UNet 的特征通道级联），或者序列拆解时，经常需要将多个独立的 Tensor 拼接在一起，或将一个大的 Tensor 切分成多个子块。这是构建复杂模型架构的常用手段。

## PyTorch 实现/使用

```python
import torch

t1 = torch.ones(2, 3)  # 形状: 2x3
t2 = torch.zeros(2, 3) # 形状: 2x3

# ================= 拼接操作 =================

# 1. cat (Concatenate): 在现有的维度上拼接
out_cat_0 = torch.cat([t1, t2], dim=0) # 形状: 4x3
out_cat_1 = torch.cat([t1, t2], dim=1) # 形状: 2x6

# 2. stack: 在全新的维度上堆叠
out_stack = torch.stack([t1, t2], dim=0) # 形状: 2x2x3

# ================= 分割操作 =================

t_large = torch.arange(10) # [0, 1, ..., 9]

# 3. split: 按照指定大小切分
# 将大小为 10 的 tensor 切成大小为 3 的几份
splits = torch.split(t_large, split_size_or_sections=3, dim=0)
# 返回一个元组: (tensor([0, 1, 2]), tensor([3, 4, 5]), tensor([6, 7, 8]), tensor([9]))

# 也可以按不等分的大小切分
splits_uneven = torch.split(t_large, split_size_or_sections=[2, 3, 5], dim=0)
# 返回: (大小为2的张量, 大小为3的张量, 大小为5的张量)

# 4. chunk: 均匀切分为指定数量的块
chunks = torch.chunk(t_large, chunks=2, dim=0)
# 返回两个形状大小均为 5 的 tensor: (tensor([0..4]), tensor([5..9]))
```

## 关键要点说明
- **`cat` 与 `stack` 的核心区别**：
  - `torch.cat` 是**拼接**，拼接后维度的数量（秩）不变。除了指定的 `dim` 维度外，参与拼接的所有 Tensor 其他维度的形状必须完全一致。
  - `torch.stack` 是**堆叠**，会增加一个新的维度。参与堆叠的所有 Tensor 形状必须百分之百一模一样。
- **切分余数问题**：使用 `split(split_size)` 时，如果被切分维度的大小不能被 `split_size` 整除，最后一块会包含剩余的元素（如上面的 10 拆为 3+3+3+1）。
- **`chunk` 的近似平分**：`chunk(chunks=k)` 尝试将数据切分为 `k` 块。如果不能整除，除了最后一块外，前面所有块的大小向上取整（`ceil(L / k)`）。
