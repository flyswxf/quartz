# 1_基础属性

## 核心思想
在 PyTorch 中，了解一个 Tensor（张量）的基本信息是调试和开发深度学习模型的基础。通过访问 Tensor 的基础属性，可以快速获知数据的形状大小、所在设备环境（CPU 还是 GPU）以及数据精度（dtype），从而在运算时进行针对性的排错和对齐。

## PyTorch 实现/使用

```python
import torch

# 创建一个随机初始化的 Tensor
tensor = torch.randn(3, 4, 5)

# 1. 获取形状 (Shape)
print(tensor.shape)   # 输出: torch.Size([3, 4, 5])
print(tensor.size())  # 输出: torch.Size([3, 4, 5])，等价于 .shape

# 2. 获取数据类型 (Data Type)
print(tensor.dtype)   # 输出: torch.float32 (默认浮点数类型)

# 3. 获取所在设备 (Device)
print(tensor.device)  # 输出: cpu

# 4. 获取维度数量/秩 (Number of Dimensions)
print(tensor.ndim)    # 输出: 3 (因为有 3 个维度)
```

## 关键要点说明
- **`shape` 与 `size()`**：在 PyTorch 中，`tensor.shape` 是一个属性，而 `tensor.size()` 是一个方法。它们返回的结果完全相同，都是 `torch.Size` 类型（可以像 Python 元组一样索引，例如 `tensor.shape[0]` 获取第一个维度的大小）。日常开发中根据个人习惯选用即可。
- **排错利器**：当网络层报错（如矩阵乘法形状不匹配）时，第一步总是通过 `print(tensor.shape)` 检查输入张量是否符合预期的维度大小。
- **设备一致性检查**：当遇到 `RuntimeError: Expected all tensors to be on the same device` 错误时，通过 `tensor.device` 检查各个张量所在设备，是快速定位问题来源的方法。
