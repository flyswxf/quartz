# 5_数学与逻辑运算

## 核心思想
Tensor 上的数学与逻辑运算实现了前向传播计算图。从基础的逐元素（element-wise）加减乘除，到深层神经网络依赖的矩阵乘法（Dot-product/Matmul），以及各类统计聚合操作（如求和、均值、最值），这些方法构成了 Tensor 运算体系的骨干。

## PyTorch 实现/使用

```python
import torch

a = torch.tensor([[1., 2.], [3., 4.]])
b = torch.tensor([[5., 6.], [7., 8.]])

# 1. 逐元素基础运算 (Element-wise)
# 直接使用符号，或调用等价方法
add_res = a + b      # 等价于 torch.add(a, b)
sub_res = a - b      # 等价于 torch.sub(a, b)
mul_res = a * b      # 等价于 torch.mul(a, b) （注意：这不是矩阵乘法！）
div_res = a / b      # 等价于 torch.div(a, b)
exp_res = torch.exp(a) # e的指数

# 2. 矩阵乘法 (Matrix Multiplication)
# 常规矩阵乘法，支持广播
matmul_res = torch.matmul(a, b) # 或直接写 a @ b

# 批量矩阵乘法 (Batch Matrix Multiplication)
# 要求输入维度为 (B, N, M) 和 (B, M, P)，B为批次大小
batch_a = torch.randn(10, 3, 4)
batch_b = torch.randn(10, 4, 5)
bmm_res = torch.bmm(batch_a, batch_b) # 结果维度: (10, 3, 5)

# 3. 聚合与统计运算
# 对整个 Tensor 求和/均值/最值
sum_all = a.sum()
max_all = a.max()

# 沿指定维度聚合 (dim=0 代表跨行聚合/即对列操作，dim=1 代表跨列聚合/即对行操作)
sum_dim0 = a.sum(dim=0) # 返回 [4., 6.]
mean_dim1 = a.mean(dim=1)

# 获取最大值及索引
max_val, max_idx = a.max(dim=1) 
# 分类任务常用：仅获取最大值所在的索引位置
argmax_res = a.argmax(dim=1) 

# 4. 掩码与逻辑条件替换
# masked_fill(mask, value): 传入一个与原 tensor 形状一致(或可广播)的 boolean 类型的掩码 tensor
# 将 mask 中为 True 的位置，替换为指定的 value
scores = torch.tensor([[1.5, 2.0, -1.2], [0.5, 3.1, 1.8]])
# 找到所有小于 1 的位置，将其设为 -1e9 (常用于注意力机制中的 softmax 之前)
mask = scores < 1.0 
masked_scores = scores.masked_fill(mask, value=-1e9)
```

## 关键要点说明
- **掩码替换 `masked_fill` 与注意力机制**：在 Transformer 的自注意力机制 (Self-Attention) 中，为了防止模型“看到未来的信息”或处理无用的 Padding 字符，极常使用 `tensor.masked_fill(mask, -1e9)` 将无效位置的分数置为极小值。这样经过 Softmax 操作后，这些位置的权重就会变成 $0$。该方法也有原地版本 `masked_fill_`，可以直接修改原变量从而节省显存。
- **矩阵乘法 `matmul` vs 逐元素乘法 `*`**：这是新手最容易混淆的地方。`*` 仅仅是将对应位置的数字相乘；而 `@` 或 `matmul` 才是线性代数意义上的矩阵乘法。
- **广播机制 (Broadcasting)**：当两个 Tensor 形状不同但满足广播规则时，PyTorch 会自动扩展较小的 Tensor 以匹配较大的 Tensor。例如形状为 `(3, 4)` 的矩阵加上形状为 `(4,)` 的向量，向量会自动扩展至每一行。
- **聚合运算的维度保留 (`keepdim`)**：使用 `a.sum(dim=1)` 后，原来二维的矩阵会降级成一维向量。如果后续还要利用广播机制参与运算，往往需要保留原有的维度结构，应该使用 `a.sum(dim=1, keepdim=True)`，这样结果维度就是 `(N, 1)` 而非 `(N,)`。
