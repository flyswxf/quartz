# 3_数据类型与设备转换

## 核心思想
在训练或部署模型时，数据往往需要在 CPU（内存）和 GPU（显存）之间来回搬运，或者在不同的数据精度（如 `float32` 到 `float16` 进行混合精度训练）之间切换。同时，PyTorch 需要经常与 Python 原生类型、NumPy 数组进行交互互转，这构成了类型和设备转换的核心需求。

## PyTorch 实现/使用

```python
import torch
import numpy as np

tensor = torch.tensor([1.0, 2.0, 3.0])

# 1. 设备与精度转换: to()
if torch.cuda.is_available():
    # 移至 GPU 并转为半精度浮点
    tensor_gpu = tensor.to('cuda:0', dtype=torch.float16)
    # 等价写法
    # tensor_gpu = tensor.cuda().half()

# 2. 标量提取: item()
loss = torch.tensor(0.45)
loss_val = loss.item() # 获取 Python 原生 float: 0.45

# 3. 转为 NumPy 数组: numpy()
# 注意: 如果 tensor 在 GPU 上或有梯度，需先 cpu().detach()
np_array = tensor.cpu().detach().numpy() 

# 4. 从 NumPy 转换回 Tensor: from_numpy()
new_tensor = torch.from_numpy(np_array) # 共享内存

# 5. 深拷贝与梯度分离: clone() 和 detach()
t_clone = tensor.clone()   # 拷贝数据，仍在计算图中（参与梯度计算）
t_detach = tensor.detach() # 共享数据，但从计算图中分离（不再参与梯度计算）
```

## 关键要点说明
- **非就地操作**：`to()` 操作默认不是 in-place（原地）的，它会返回一个新的 Tensor。因此，必须使用变量重新接收它，例如 `x = x.to(device)`，直接写 `x.to(device)` 对 `x` 本身不会有影响。但注意，对模型调用 `model.to(device)` 是原地操作。
- **`tensor.item()` 的限制**：此方法**只能**用于仅包含一个元素的张量（如计算得到的总 loss 或 accuracy）。如果 Tensor 包含多个元素，调用会抛出 `ValueError`，需改用 `.tolist()` 或转为 NumPy。
- **`detach().cpu().numpy()` 连招**：在将网络输出结果绘制成图表或保存为普通文件时，这是最常用的标准写法。`detach()` 取消梯度追踪，`cpu()` 移至主机内存，`numpy()` 完成最终格式转换。
