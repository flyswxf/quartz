# 分布式训练并行策略 (DP, PP, TP)

在深度学习（尤其是大模型训练）中，当模型参数量或训练数据量超出单张 GPU 的显存与算力极限时，需要采用分布式并行训练技术。业界主流的“3D 并行”策略包含：**数据并行 (DP)**、**流水线并行 (PP)** 和 **张量并行 (TP)**。

## 一、核心思想

### 1. 数据并行 (Data Parallelism, DP)
- **切分对象**：数据。
- **原理**：每张 GPU 上都有一份完整的模型副本。将每个 Batch 的训练数据切分（Scatter）给各个 GPU，每张卡独立进行前向传播和反向传播计算梯度。最后在更新参数前，通过卡间通信（All-Reduce）同步梯度，确保所有卡的模型参数保持一致。
- **适用场景**：模型能放入单卡显存，但数据量大、训练时间长的情况。

### 2. 流水线并行 (Pipeline Parallelism, PP)
- **切分对象**：模型（按层切分）。
- **原理**：将模型的不同网络层分布到不同的 GPU 上。例如，前 10 层放在 GPU 0，后 10 层放在 GPU 1。数据像流水线一样依次穿过不同的 GPU。
- **痛点**：容易产生“气泡”（GPU 空闲等待时间）。通常需要配合微批次（Micro-batching）调度算法（如 GPipe, 1F1B）将大 Batch 拆分成多个小 Batch 交错执行，以提升 GPU 利用率。

### 3. 张量并行 (Tensor Parallelism, TP)
- **切分对象**：张量/矩阵运算（按操作维度切分）。
- **原理**：将单个极其庞大的矩阵乘法运算（如 Transformer 中的 Linear 层）切分成多个小矩阵乘法，分发到不同 GPU 上并行计算，最后通过通信合并结果。
- **痛点**：需要在前向和反向传播中进行极高频的通信（如 All-Gather, Reduce-Scatter），因此对带宽要求极高，通常限制在单台物理机（拥有 NVLink 高速互联）内使用。代表实现为 Megatron-LM。

## 二、PyTorch 实现/使用

### 1. 数据并行 (DDP)
PyTorch 提供了成熟的 `DistributedDataParallel` (DDP)：
```python
import torch
import torch.nn as nn
from torch.nn.parallel import DistributedDataParallel as DDP

# 假设已初始化分布式进程组 (init_process_group)
model = nn.Linear(10, 10).to(local_rank)
# 将模型包装为 DDP
ddp_model = DDP(model, device_ids=[local_rank])
```

### 2. 流水线并行 (极简跨设备示例)
原生 PyTorch 中可以手动将不同层放置在不同设备上并控制数据流转：
```python
import torch
import torch.nn as nn

class PipelineModel(nn.Module):
    def __init__(self):
        super().__init__()
        # 将模型前半部分放到 GPU 0
        self.layer1 = nn.Sequential(nn.Linear(1024, 4096), nn.ReLU()).to('cuda:0')
        # 将模型后半部分放到 GPU 1
        self.layer2 = nn.Sequential(nn.Linear(4096, 1024)).to('cuda:1')
        
    def forward(self, x):
        x = x.to('cuda:0')
        out1 = self.layer1(x)
        
        # 将中间结果传输到 GPU 1 继续计算
        out1_on_dev1 = out1.to('cuda:1')
        out2 = self.layer2(out1_on_dev1)
        return out2
```

### 3. 张量并行
原生 PyTorch 实现复杂，通常借助 `torch.distributed.tensor.parallel` 或第三方库（Megatron、ColossalAI）。使用原生的 DTensor (Distributed Tensor) 概念如下：
```python
from torch.distributed.tensor.parallel import parallelize_module, ColwiseParallel
# 概念示例：需要先构建 DeviceMesh 和 DTensor

```

## 三、关键要点说明

- **通信开销对比**：
  - **TP (张量并行)**：极高频，每次矩阵乘法都需同步。要求机内 NVLink 高速互联。
  - **DP (数据并行)**：较高频，每步 (Step) 反向传播结束时同步梯度。
  - **PP (流水线并行)**：低频，仅在相邻阶段 (Stage) 间传递激活值 (Activations) 和梯度，适合跨节点 (Node) 通信。
- **3D 并行组合**：在超大模型训练中，通常组合使用。例如：机内使用 TP（利用 NVLink），机间使用 PP 和 DP。
- **显存优化技术的演进 (ZeRO / FSDP)**：
  - 微软的 **ZeRO** 及 PyTorch 的 **FSDP** 扩展了数据并行的概念。
  - 它们依然按照 DP 的方式切分数据，但进一步**把模型参数、梯度、优化器状态在多卡之间进行了切片（Sharding）**。
  - 这使得 DP 也能实现类似模型并行的显存节省效果，是目前训练大模型（如 LLaMA）最主流且易用的显存优化技术，极大地缓解了直接使用 PP 和 TP 的复杂度。
