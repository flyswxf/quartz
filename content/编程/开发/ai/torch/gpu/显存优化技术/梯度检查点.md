# 梯度检查点 (Gradient Checkpointing)

梯度检查点是一种**用计算时间换取显存空间**的优化技术，专门解决模型过深或激活值过大导致的显存溢出（OOM）问题。

## 一、核心思想

在标准的深度学习训练流程中：
- **前向传播**：模型计算输出，并**将所有中间层的激活值（Activations）保存在显存中**。
- **反向传播**：利用保存的激活值结合链式法则计算梯度。
这种方式导致显存占用与模型层数成正比。

梯度检查点通过改变这一过程来节省显存：
1. 前向传播时，**只保存少数几个关键节点（检查点）的激活值**，丢弃其他所有中间激活值。
2. 反向传播需要用到被丢弃的激活值时，**从最近的检查点重新进行一次局部前向传播**来实时计算这些激活值。

代价是额外增加了一次局部的计算开销，但显存占用可以从 $O(N)$ 降低到 $O(\sqrt{N})$ （其中 $N$ 为层数）。

## 二、PyTorch 使用

PyTorch 提供了 `torch.utils.checkpoint` 模块来实现此功能。通常在封装模型大块结构（如 Transformer Block 或 ResNet Block）时使用。

```python
import torch
import torch.nn as nn
from torch.utils.checkpoint import checkpoint

class LargeBlock(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(1024, 4096)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(4096, 1024)
        
    def forward(self, x):
        return self.fc2(self.relu(self.fc1(x)))

class CheckpointModel(nn.Module):
    def __init__(self, num_blocks):
        super().__init__()
        self.blocks = nn.ModuleList([LargeBlock() for _ in range(num_blocks)])
        
    def forward(self, x):
        for block in self.blocks:
            # 不使用检查点: x = block(x)
            # 使用检查点: 
            # 参数1为前向传播函数, 参数2及以后为输入张量
            # use_reentrant=False 是较新版本推荐的安全配置
            x = checkpoint(block, x, use_reentrant=False)
        return x

model = CheckpointModel(num_blocks=10).cuda()
x = torch.randn(32, 1024, requires_grad=True).cuda()
out = model(x)
out.sum().backward()
```

## 三、关键要点说明

- **性能权衡**：显存通常能减少 50% 甚至更多，但训练速度一般会下降 20% - 30%（因为有额外的重复前向传播）。
- **最佳应用场景**：
  - 计算量小但显存占用大的层（如大词表的 Embedding 层或激活值极大的前馈网络）。
  - 层数极深的模型（如超大的 Transformer 架构）。
- **随机性问题**：如果被检查点的模块内部包含 Dropout 等具有随机性的操作，PyTorch 的 `checkpoint` 会自动记录并恢复随机数种子，确保重计算时的结果与第一次前向传播完全一致。
