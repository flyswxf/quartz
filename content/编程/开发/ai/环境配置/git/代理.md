适用于本地有vpn的情况


仅GitHub走Clash代理
```bash
git config --global 'http."https://github.com".proxy' http://127.0.0.1:7897
```
- 7897: clash的默认端口
- global: 对于所有仓库(并非系统级配置)
- **该情况下, 如果没有设置代理, 也能正常运行(就是直连)**

当git版本过旧时, 只能使用
```bash
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```
- **该情况下, 如果没有设置代理, 会直接报错**


可通过以下命令查看配置
```bash
git config --global --list
```

## 验证调试
验证配置是否生效
```bash
git config --get-urlmatch http.proxy https://github.com
```
输出`http://127.0.0.1:7897`即生效

#### 或者通过以下命令观察git是否通过了代理路径
```bash
GIT_TRACE=1 GIT_CURL_VERBOSE=1 git clone --depth=1 https://github.com/UX-Decoder/Segment-Everything-Everywhere-All-At-Once.git
```
- `GIT_TRACE=1 GIT_CURL_VERBOSE=1`: 仅用于该命令的临时变量, 用于启用调试
