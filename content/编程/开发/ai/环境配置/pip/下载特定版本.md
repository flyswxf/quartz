以下是已解决的问题: 
### 问题描述

在服务器上运行以下命令时没有反应，命令直接结束且没有任何输出：

```bash
pip install rouge-score>=0.1.2
```

### 原因分析

在 bash shell 中，`>` 是**输出重定向运算符**，有特殊含义。

Shell 会将上述命令解析为：
- `pip install rouge-score` → 安装包
- `> 0.1.2` → 将输出重定向到名为 `0.1.2` 的文件

这导致：
1. pip 可能已经安装成功但输出被重定向到文件
2. 或者命令行为异常

### 解决方案

#### 使用引号

```bash
pip install 'rouge-score>=0.1.2'
```
