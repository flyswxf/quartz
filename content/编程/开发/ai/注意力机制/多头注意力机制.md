## 核心思想
多头注意力机制（Multi-Head Attention）是 Transformer 的核心组件之一。它的主要思想是：不只做一次注意力计算，而是将 Query、Key、Value 映射到多个不同的子空间中（拆分为多个 "头"），在各个子空间里并行计算注意力，最后再将结果拼接（Concat）并进行一次线性映射。

这样做的目的是**让模型能够在不同的表示子空间里，关注到输入序列的不同特征（如语法、语义、上下文逻辑等）**。

公式表示：
$$ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W^O $$
$$ \text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V) $$

## 手写实现 (从头编写)

虽然在实际开发中常直接使用内置模块，但手写实现能够帮助深刻理解多头注意力的底层技巧（如矩阵切分、并行计算）。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class CustomMultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0, "d_model 必须能被 num_heads 整除"
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # 每个头的维度
        
        # 合并线性层。使用单次矩阵乘法处理所有头，避免循环创建多个小线性层
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        
        self.W_o = nn.Linear(d_model, d_model)
        
    def forward(self, q, k, v, mask=None):
        batch_size = q.size(0)
        
        # 1. 线性映射并拆分为多个头
        # 原始形状: (batch_size, seq_len, d_model)
        # 利用 view 和 transpose 将 num_heads 提至维度 1，实现多头并行矩阵乘法
        # 变换后形状: (batch_size, num_heads, seq_len, d_k)
        Q = self.W_q(q).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(k).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(v).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # 2. 计算缩放点积注意力
        # Q @ K^T 形状: (batch_size, num_heads, seq_len, seq_len)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            # 注意：传入的 mask 需要能够广播到 (batch_size, num_heads, seq_len, seq_len)
            scores = scores.masked_fill(mask == 0, -1e9)
            
        attn_weights = F.softmax(scores, dim=-1)
        
        # context 形状: (batch_size, num_heads, seq_len, d_k)
        context = torch.matmul(attn_weights, V)
        
        # 3. 拼接所有头
        # 技巧3：transpose 后内存不连续，需调用 contiguous() 重新分配内存，再用 view 展平拼接
        # 形状变化: (batch_size, num_heads, seq_len, d_k) -> (batch_size, seq_len, num_heads, d_k) -> (batch_size, seq_len, d_model)
        context = context.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        
        # 4. 最后的线性映射
        output = self.W_o(context)
        
        return output, attn_weights

# 示例使用
d_model, num_heads = 512, 8
mha_custom = CustomMultiHeadAttention(d_model, num_heads)

batch_size, seq_len = 2, 10
x = torch.randn(batch_size, seq_len, d_model)

# 前向传播 (自注意力)
output, weights = mha_custom(x, x, x)
print("手写多头注意力输出形状:", output.shape)  # [2, 10, 512]
```

## 关键要点与实现技巧
- **合并线性变换 (Fused Linear Projection)**：在实现上，**不应**实例化 $h$ 个独立的线性层进行循环计算，而是用一个大线性层计算后，利用 `view` 进行拆分。这充分利用了 GPU 的并行计算能力。
- **维度的巧妙置换 (Transpose 并行化)**：将张量变形并转置为 `(batch_size, num_heads, seq_len, d_k)` 是核心技巧。此时在调用 `torch.matmul` 时，前两个维度被当作 Batch 维度，从而实现了多个头、多个样本完全独立并行的矩阵乘法。
- **内存连续性保障 (Contiguous)**：执行 `transpose` 后，张量在内存中的物理排布就不再连续了。在调用 `view` 重新拼接（将 `num_heads` 和 `d_k` 乘回 `d_model`）之前，必须先调用 `.contiguous()` 在内存中重塑张量。
- **计算复杂度不变**：每个头的维度为 $d_k = d_{model} / h$。拆分后计算 $h$ 次小维度的点积，总体计算量与进行一次 $d_{model}$ 维度的点积几乎一致，但在不增加计算负担的前提下，使模型获得了捕获多个不同子空间特征（如语法、语义、局部特征等）的能力。

## PyTorch 使用

在实际工程开发中，推荐直接使用 PyTorch 提供的高度优化的内置模块 `nn.MultiheadAttention`，底层集成了更高效的算子。

```python
import torch
import torch.nn as nn

d_model = 512  # 输入和输出的维度
num_heads = 8  # 头的数量 (d_model 必须能被 num_heads 整除)

# 初始化多头注意力层
# batch_first=True 表示输入张量的形状为 (batch_size, seq_len, d_model)
mha = nn.MultiheadAttention(embed_dim=d_model, num_heads=num_heads, batch_first=True)

# 模拟输入 (Query, Key, Value 相同，即自注意力)
batch_size, seq_len = 2, 10
query = torch.randn(batch_size, seq_len, d_model)
key = torch.randn(batch_size, seq_len, d_model)
value = torch.randn(batch_size, seq_len, d_model)

# 前向传播
attn_output, attn_weights = mha(query, key, value)

print("输出形状:", attn_output.shape)    # [2, 10, 512]
```
