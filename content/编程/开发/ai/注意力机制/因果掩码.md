**Causal/Subsequent Mask (因果掩码)**：在自回归任务（如文本生成）中，防止模型“偷看”未来的词，保证第 $t$ 步只能看到 $\le t$ 的信息。

**具体实现与代码演示**：
通常利用一个下三角矩阵作为掩码，将右上角（代表未来时间步）的位置填充为极小值（如 `-1e9` 或 `-inf`）。在通过 Softmax 函数后，未来位置的注意力权重将精确为 $0$。

```python
import torch
import torch.nn.functional as F

seq_len = 4
# 1. 模拟一个注意力打分矩阵 (Q * K^T / sqrt(d_k))
scores = torch.randn(seq_len, seq_len)

# 2. 生成下三角因果掩码 (1 表示保留，0 表示掩蔽)
causal_mask = torch.tril(torch.ones(seq_len, seq_len))

# 3. 应用掩码：将 mask == 0 的位置替换为极小值
masked_scores = scores.masked_fill(causal_mask == 0, -1e9)

# 4. 计算 Softmax
attn_weights = F.softmax(masked_scores, dim=-1)

print("掩码矩阵:\n", causal_mask)
print("Softmax后的注意力权重:\n", attn_weights)
```

输出结果中，`attn_weights` 的上三角部分全为 $0$。这表明第 $i$ 个词在计算注意力时，未分配任何权重给序列中排在 $i$ 之后的词：

```text
 tensor([[1., 0., 0., 0.],
		 [1., 1., 0., 0.],
		 [1., 1., 1., 0.],
		 [1., 1., 1., 1.]])
Softmax后的注意力权重:
 tensor([[1.0000, 0.0000, 0.0000, 0.0000],
		 [0.7241, 0.2759, 0.0000, 0.0000],
		 [0.1583, 0.5401, 0.3015, 0.0000],
		 [0.3421, 0.1345, 0.4523, 0.0710]])
```
