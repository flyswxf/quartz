# 主流 Agent 框架

## 概述
随着 Agent 概念的普及，涌现了许多开源框架来简化 Agent 的开发过程。这些框架封装了底层的 Prompt 拼接、API 调用、记忆管理和工具集成。

## 1. LangChain / LangGraph
LangChain 是目前最流行的 LLM 应用开发框架，而 LangGraph 是其用于构建复杂 Agent 的扩展。
- **特点**：提供极度丰富的组件（Document Loaders, Vector Stores, Tools）。
- **LangGraph**：将 Agent 的执行流建模为图（Graph），允许循环（Cycles）和条件分支，非常适合构建具有复杂状态机的 Agent。
- **适用场景**：需要集成多种外部工具和数据库的复杂企业级应用。

## 2. LlamaIndex
最初作为数据增强生成（RAG）的框架，现在也提供了强大的 Agent 能力。
- **特点**：在数据接入、索引和检索方面具有明显优势。
- **Data Agents**：专注于对复杂数据进行推理和操作的 Agent。
- **适用场景**：以文档查询、知识库问答为核心驱动的 Agent 应用。

## 3. AutoGen (Microsoft)
由微软推出的多智能体（Multi-Agent）开发框架。详见 [[多智能体系统(Multi-Agent)#AutoGen|多智能体系统]]。
- **特点**：允许开发者定义多个具备不同角色的 Agent，它们可以通过对话协作完成任务。
- **核心概念**：`ConversableAgent`（可以相互对话的实体）。
- **适用场景**：代码生成、复杂任务分解执行、需要多角色辩论或评审的场景。

## 4. MetaGPT
将标准化的操作流程（SOP）引入多智能体协作中。
- **特点**：让 Agent 扮演产品经理、架构师、工程师、测试员等角色，模拟整个软件开发公司的运作。
- **优势**：通过结构化的输出（如需求文档、设计图）减少 Agent 之间的沟通歧义。
- **适用场景**：自动化软件工程、复杂工程项目生成。

## 5. HuggingGPT
利用 LLM 作为控制器，调用 Hugging Face 上的各类专业模型（如图像分类、目标检测）来完成多模态任务。
