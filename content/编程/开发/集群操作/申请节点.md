### 资源充沛的cpu节点
```bash
salloc --exclusive -N 1 -n 1 --cpus-per-task=32 --mem=100G -t 4:00:00
```
申请1个完整节点，独占32核128G内存，时长4小时
- `--exclusive`：独占整个节点，不与其他用户共享，避免CPU争抢，性能最稳定
- `-N 1`：固定1个节点
- `--cpus-per-task=32`：匹配节点全部32个物理核
- `--mem=100G`：内存
- `-t 4:00:00`：运行时长，格式`小时:分钟:秒`

申请成功后，登录到计算节点：
```bash
srun --pty --cpu-bind=cores bash
```

### 小的gpu节点
```bash
salloc --partition=gpu --gres=gpu:1 --cpus-per-task=4 --mem=16G --time=4:00:00
```
分配 1 个 GPU，4 个 CPU 核心，16GB 内存，时间限制 4 小时

申请成功后，登录到计算节点：
```bash
srun --pty bash
```
