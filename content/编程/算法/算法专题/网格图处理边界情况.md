dp根据左侧, 上方的状态进行更新, 由于边界情况:
- 如i=0时只能从左侧更新
- j=0时只能从上方更新
- i=0且j=0时无法更新

为避免大量条件语句, 从**什么情况才能更新**的角度思考
- i>0时可以从上方更新
- j>0时可以从左侧更新
代码更加简洁
### 例子
```cpp
if (i > 0)
	dp[i][j][(t + x) % k] = (dp[i - 1][j][t] + dp[i][j][(t + x) % k]) % MOD;
if (j > 0)
	dp[i][j][(t + x) % k] = (dp[i][j - 1][t] + dp[i][j][(t + x) % k]) % MOD;
```
