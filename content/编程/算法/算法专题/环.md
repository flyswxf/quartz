# 算法范例

## LeetCode 1559. 二维网格图中探测环

### 题目描述

**难度**: 中等  
**标签**: 深度优先搜索、广度优先搜索、并查集、图  
**来源**: 第 33 场双周赛 Q4

给你一个二维字符网格数组 `grid`，大小为 `m x n`，你需要检查 `grid` 中是否存在**相同值**形成的环。

一个环是一条开始和结束于同一个格子的长度**大于等于 4**的路径。对于一个给定的格子，你可以移动到它上、下、左、右四个方向相邻的格子之一，可以移动的前提是这两个格子有**相同的值**。

同时，你也不能回到上一次移动时所在的格子。比方说，环 `(1, 1) -> (1, 2) -> (1, 1)` 是不合法的，因为从 `(1, 2)` 移动到 `(1, 1)` 回到了上一次移动时的格子。

如果 `grid` 中有相同值形成的环，请你返回 `true`，否则返回 `false`。

### 示例

#### 示例 1
```
输入: grid = [["a","a","a","a"],["a","b","b","a"],["a","b","b","a"],["a","a","a","a"]]
输出: true
解释: 有 2 个用不同颜色标出来的环
```

#### 示例 2
```
输入: grid = [["c","c","c","a"],["c","d","c","c"],["c","c","e","c"],["f","c","c","c"]]
输出: true
解释: 只有高亮所示的一个合法环
```

#### 示例 3
```
输入: grid = [["a","b","b"],["b","z","b"],["b","b","a"]]
输出: false
```

### 算法实现

```cpp
class Solution {
public:
    bool containsCycle(vector<vector<char>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<vector<bool>> vis(n, vector<bool>(m, false));
        
        // 边界检查函数
        auto inside = [&](int x, int y) {
            return x >= 0 && x < n && y >= 0 && y < m;
        };
        
        // 方向数组：上、右、下、左
        int go[5] = {0, 1, 0, -1, 0};
        
        // DFS 递归函数
        auto dfs = [&](auto&& dfs, int x, int y, int px, int py) -> bool {
            // 越界或字符不匹配
            if (!inside(x, y) || grid[x][y] != grid[px][py])
                return false;
            
            // 发现环：访问到已访问过的节点
            if (vis[x][y])
                return true;
            
            // 标记当前节点为已访问
            vis[x][y] = true;
            
            // 遍历四个方向
            for (int d = 0; d < 4; ++d) {
                int nx = x + go[d], ny = y + go[d + 1];
                
                // 跳过父节点（避免立即回到上一个位置）
                if (nx == px && ny == py)
                    continue;
                
                // 递归搜索
                if (dfs(dfs, nx, ny, x, y))
                    return true;
            }
            
            return false;
        };
        
        // 遍历所有未访问的节点作为起点
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (!vis[i][j] && dfs(dfs, i, j, i, j))
                    return true;
            }
        }
        
        return false;
    }
};
```

### 算法分析

#### 核心思路
1. **DFS + 访问标记**: 使用深度优先搜索遍历图，通过访问标记检测环
2. **父节点跟踪**: 传递父节点坐标 `(px, py)` 避免立即回到上一个位置
3. **环检测条件**: 当访问到已标记的节点时，说明找到了环

#### 关键技巧

##### 1. 优雅的方向数组
```cpp
int go[5] = {0, 1, 0, -1, 0};
// 使用 go[d] 和 go[d+1] 获取方向偏移
// d=0: (0,1)  右
// d=1: (1,0)  下  
// d=2: (0,-1) 左
// d=3: (-1,0) 上
```

##### 2. Lambda 递归技巧
```cpp
auto dfs = [&](auto&& dfs, int x, int y, int px, int py) -> bool {
    // 通过 auto&& 实现 lambda 递归调用
};
```

##### 3. 边界检查封装
```cpp
auto inside = [&](int x, int y) {
    return x >= 0 && x < n && y >= 0 && y < m;
};
```

#### 算法特点
- **简洁性**: 代码结构清晰，逻辑简单
- **效率性**: 一次遍历即可完成环检测
- **正确性**: 正确处理了不能回到父节点的约束

### 复杂度分析

- **时间复杂度**: O(m × n)
  - 每个节点最多被访问一次
  - 总共有 m × n 个节点
  
- **空间复杂度**: O(m × n)
  - 访问标记数组: O(m × n)
  - 递归调用栈: 最坏情况 O(m × n)

#### 1. 并查集解法

// 使用并查集检测环
class UnionFind {
    vector<int> parent, rank;
public:
    UnionFind(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // 发现环
        if (rank[px] < rank[py]) swap(px, py);
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
};

### 总结

这个算法展现了几个优美的设计：

1. **方向数组的巧妙使用**: `go[5] = {0,1,0,-1,0}` 简化了四方向遍历
2. **Lambda 递归**: 现代 C++ 的函数式编程风格
3. **父节点跟踪**: 简单有效地避免了回到上一个位置
4. **一次遍历**: 高效的时间复杂度

这种写法不仅功能完整，而且代码简洁优雅，是图论 DFS 算法的经典范例。
