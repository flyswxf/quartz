快速排序基于分治思想。

通过一趟排序将要排序的数据分割成独立的两部分，其中一部分的所有数据都比另外一部分的所有数据都要小，然后再按此方法对这两部分数据分别进行快速排序，整个排序过程可以递归进行，以此达到整个数据变成有序序列。

### 复杂度分析

- **时间复杂度**：平均情况为 $O(n \log n)$，最坏情况（如每次基准值划分极度不平衡）为 $O(n^2)$。
- **空间复杂度**：平均情况为 $O(\log n)$，主要为递归调用栈所占用的空间。最坏情况为 $O(n)$。
- **稳定性**：不稳定排序。

### C++ 模板

```cpp
void quick_sort(int q[], int l, int r) {
    if (l >= r) return;

    // 取中间元素作为基准值
    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    
    while (i < j) {
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);
        if (i < j) {
            int temp = q[i];
            q[i] = q[j];
            q[j] = temp;
        }
    }

    quick_sort(q, l, j);
    quick_sort(q, j + 1, r);
}
```
