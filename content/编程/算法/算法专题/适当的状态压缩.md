# 适当的状态压缩 - 滑动拼图优化实现

## 问题描述
在一个 2×3 的板上有 5 块砖瓦，用数字 1~5 来表示，以及一块空缺用 0 来表示。一次移动定义为选择 0 与一个相邻的数字（上下左右）进行交换。最终当板 board 的结果是 [[1,2,3],[4,5,0]] 谜板被解开。给出一个谜板的初始状态 board，返回最少可以通过多少次移动解开谜板，如果不能解开谜板，则返回 -1。

## 高效实现代码

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
#include <map>
#include <unordered_map>
#include <cmath>
#include <queue>
#include <set>
#include <cstring>
#include <cstdint>

using namespace std;

#define N 550000
class Solution {
    static constexpr int END=123450;
    static int8_t state_record[N];
public:
    int slidingPuzzle(vector<vector<int>>& board) {
        memset(state_record, 0, sizeof(int8_t)*N);
        auto cal_state=[](string& now_state)->int{
            int x=0;
            for(char& c: now_state){
                x=x*10+c-'0';
            }
            return x;
        };
        queue<tuple<int, string>> q;
        int ori_x, ori_y;
        string ori_state;
        for(int i=0; i<6; i++){
            int x=board[i/3][i%3];
            if(x==0){
                ori_x=i/3; ori_y=i%3;
            }
            ori_state.push_back(x+'0');
        }
        if(cal_state(ori_state)==END) return 0;
        q.emplace(ori_x*3+ori_y, ori_state);
        int res=0;
        while(!q.empty()){
            res++;
            int q_size=q.size();
            while(q_size-->0){
                auto [pos, now_state]=q.front();
                q.pop();
                if(pos%3<2){
                    int npos=pos+1;
                    swap(now_state[pos], now_state[npos]);
                    int state_code=cal_state(now_state);
                    if(state_code==END) return res;
                    else if(state_record[state_code]==0){
                        state_record[state_code]=1;
                        q.emplace(npos, now_state);
                    }
                    swap(now_state[pos], now_state[npos]);
                }
                if(pos%3>0){
                    int npos=pos-1;
                    swap(now_state[pos], now_state[npos]);
                    int state_code=cal_state(now_state);
                    if(state_code==END) return res;
                    else if(state_record[state_code]==0){
                        state_record[state_code]=1;
                        q.emplace(npos, now_state);
                    }
                    swap(now_state[pos], now_state[npos]);
                }
                int npos=(pos+3)%6;
                swap(now_state[pos], now_state[npos]);
                int state_code=cal_state(now_state);
                if(state_code==END) return res;
                else if(state_record[state_code]==0){
                    state_record[state_code]=1;
                    q.emplace(npos, now_state);
                }
            }
        }
        return -1;
    }
};
int8_t Solution::state_record[N];
```

## 核心优化技巧

### 1. 编译时常量优化
```cpp
static constexpr int END=123450;
```
- 使用 `static constexpr` 声明编译时常量
- 目标状态在编译时确定，避免运行时计算
- 提高代码可读性和性能

### 2. 内存优化策略
```cpp
static int8_t state_record[N];
```
- 使用 `int8_t` 而不是 `int`，内存占用减少75%
- 静态数组分配，避免动态内存分配开销
- 更好的缓存局部性，提升访问速度

### 3. 静态数组预分配
```cpp
#define N 550000
```
- 预先计算所需的最大状态数量
- 使用静态数组避免动态分配的性能损耗
- 编译时确定内存布局，优化内存访问模式

### 4. 双重状态表示
```cpp
queue<tuple<int, string>> q;
string ori_state;  // 方便下标访问
int state_code = cal_state(now_state);  // 用于哈希和比较
```
- **string形式**：方便进行下标访问和交换操作 `swap(now_state[pos], now_state[npos])`
- **int形式**：用于状态压缩、哈希和快速比较
- 时空权衡：用少量额外内存换取O(1)的交换复杂度

### 5. 避免重复计算空格位置
```cpp
queue<tuple<int, string>> q;  // 直接存储空格位置
q.emplace(ori_x*3+ori_y, ori_state);
```
- 在队列中直接存储空格的位置信息
- 避免每次都遍历寻找空格位置
- 减少不必要的计算开销

### 6. 层序遍历优化
```cpp
while(!q.empty()){
    res++;  // 步数递增
    int q_size=q.size();
    while(q_size-->0){  // 处理当前层
        // 一旦找到目标立即返回
        if(state_code==END) return res;
    }
}
```
- 按层进行BFS遍历，而不是逐个状态处理
- 找到目标状态立即返回，避免不必要的搜索
- 更早的剪枝机会，提升算法效率

## 性能分析

### 时间复杂度
- 状态空间：O(6!) = O(720)
- 每个状态最多3种移动
- 总时间复杂度：O(状态数 × 移动数) = O(2160)

### 空间复杂度
- 状态记录数组：O(N) = O(550000)
- 队列空间：O(状态数) = O(720)
- 总空间复杂度：O(N)

## 关键启示

1. **适当的状态压缩**：选择合适的状态表示方式，平衡计算复杂度和存储效率
2. **内存优化**：使用合适的数据类型和分配方式
3. **算法结构优化**：层序遍历 + 早期剪枝
4. **工程优化**：避免重复计算，预计算常用值
5. **时空权衡**：用少量额外空间换取显著的时间性能提升
