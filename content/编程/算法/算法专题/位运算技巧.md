# 从集合论到位运算，常见位运算技巧分类总结！

Source: [LeetCode Link](https://leetcode.cn/discuss/post/3571304/cong-ji-he-lun-dao-wei-yun-suan-chang-ji-enve/)

## 前言

在高中，我们学了集合论（set theory）的相关知识。例如，包含若干整数的集合 $S=\{0,2,3\}$。在编程中，通常用哈希表（hash table）表示集合。例如 Java 中的 `HashSet`，C++ 中的 `std::unordered_set`。

如果编程实现「求两个哈希表的交集」，需要一个一个地遍历哈希表中的元素。那么，有没有效率更高的做法呢？

利用位运算「并行计算」的特点，我们可以高效地做一些和集合有关的运算。

## 一、基础集合论与位运算的对应关系

假设集合中的元素都是 $0$ 到 $n-1$ 之间的整数。我们可以用一个 $n$ 位的二进制整数 $x$ 来表示这个集合。
如果 $x$ 的第 $i$ 位是 $1$，表示 $i$ 在集合中；如果是 $0$，表示 $i$ 不在集合中。

| 集合论概念               | 符号            | 位运算实现          | 说明                         |
| :----------------------- | :-------------- | :------------------ | :--------------------------- |
| 集合                     | $S$             | $x$                 | 二进制数表示集合             |
| 全集                     | $U$             | `-1` 或 `(1<<n)-1`  | 所有位都为 1                 |
| 空集                     | $\emptyset$     | `0`                 | 所有位都为 0                 |
| 元素 $i$ 在集合 $S$ 中   | $i \in S$       | `(s >> i) & 1`      | 检查第 $i$ 位是否为 1        |
| 元素 $i$ 不在集合 $S$ 中 | $i \notin S$    | `!((s >> i) & 1)`   | 检查第 $i$ 位是否为 0        |
| 交集                     | $A \cap B$      | `a & b`             | 同时在两个集合中的元素       |
| 并集                     | $A \cup B$      | `a \| b`            | 至少在一个集合中的元素       |
| 补集                     | $\bar{A}$       | `~a` (通常需 `& U`) | 不在 $A$ 中的元素            |
| 差集                     | $A \setminus B$ | `a & ~b`            | 在 $A$ 中但不在 $B$ 中的元素 |
| 对称差                   | $A \Delta B$    | `a ^ b`             | 只在其中一个集合中的元素     |
| 子集关系                 | $A \subseteq B$ | `(a & b) == a`      | $A$ 中的所有元素都在 $B$ 中  |
|                          |                 | `(a \| b) == b`     | 等价写法                     |

## 二、常见的元素操作

| 操作                                 | 代码实现                    | 说明                                        |
| :--------------------------------- | :---------------------- | :---------------------------------------- |
| 添加元素 $i$                           | `s \|= (1 << i)`        | 将第 $i$ 位设为 1                              |
| 删除元素 $i$                           | `s &= ~(1 << i)`        | 将第 $i$ 位设为 0                              |
| 切换元素 $i$                           | `s ^= (1 << i)`         | 0 变 1，1 变 0                               |
| 集合大小                               | `__builtin_popcount(s)` | 二进制中 1 的个数                                |
| 最小元素                               | `__builtin_ctz(s)`      | 尾部 0 的个数 (Count Trailing Zeros)           |
| 最大元素 / $\lfloor \log_2(s) \rfloor$ | `__lg(s)`               | 返回最高位 1 的下标 (等价于 `31 - __builtin_clz(s)`) |
| Lowbit                             | `s & -s`                | 只保留最低位的 1 (等价于 `s & (~s + 1)`)            |
| 位数                                 | `bit_width(s)`          | 求二进制位数(s需要为unsigned)                      |

> 注意：
> 1. `__builtin_` 系列函数是 GCC/Clang 的内建函数。
> 2. **`__lg(s)` 特别说明**：该函数计算 $s$ 二进制下最高位 1 的下标（从 0 开始计数），数学意义上等价于向下取整的以 2 为底的对数 $\lfloor \log_2(s) \rfloor$。例如 `__lg(8) = 3` ($2^3=8$), `__lg(15) = 3`。使用时需保证 $s > 0$。

## 三、遍历集合与子集

### 1. 遍历集合中的所有元素

```cpp
for (int i = 0; i < n; i++) {
    if ((s >> i) & 1) {
        // 处理元素 i
    }
}
```
或者利用 `lowbit` 优化（适合稀疏集合）：
```cpp
while (s) {
    int lb = s & -s; // 取出最低位的 1
    int i = __builtin_ctz(lb); // 获取对应的下标
    // 处理元素 i
    s ^= lb; // 删除最低位的 1
}
```

### 2. 枚举子集 (Subset Enumeration)

枚举集合 $s$ 的所有子集 $sub$：
```cpp
for (int sub = s; sub; sub = (sub - 1) & s) {
    // 处理子集 sub
}
// 注意：上述循环不会处理空集 0，如果需要处理空集，需单独处理或使用 do-while
```
**原理**：`sub - 1` 会将 `sub` 最低位的 1 变成 0，并将更低位的 0 变成 1。`& s` 确保了结果只保留在 $s$ 中的位。

### 3. 枚举全集的所有子集 (从大到小)

```cpp
for (int i = (1 << n) - 1; i >= 0; i--) {
    // 处理子集 i
}
```

### 4. Gosper's Hack

枚举大小固定为 $k$ 的所有子集：
```cpp
void GospersHack(int k, int n) {
    int limit = (1 << n);
    int c = (1 << k) - 1;
    while (c < limit) {
        // 处理子集 c
        // ...
        
        int lb = c & -c;
        int r = c + lb;
        c = (((r ^ c) >> 2) / lb) | r;
    }
}
```

## 四、位运算常用技巧 (Bit Manipulation Tricks)

1. **Lowbit**: `s & -s`
   - 获取二进制表示中最低位的 1。例如 `101100` -> `000100`。
   - 应用：树状数组 (Fenwick Tree)。

2. **消除最低位的 1**: `s & (s - 1)`
   - 例如 `101100` -> `101000`。
   - 应用：判断是否为 2 的幂 (`s > 0 && (s & (s - 1)) == 0`)。

3. **构造低 $n$ 位全 1**: `(1 << n) - 1`

4. **判断是否为 2 的幂**:
   ```cpp
   bool isPowerOfTwo(int n) {
       return n > 0 && (n & (n - 1)) == 0;
   }
   ```

5. **判断是否为 4 的幂 (利用掩码)**:
   - 4 的幂一定是 2 的幂，且唯一的 1 出现在偶数位上 (第 0, 2, 4... 位)。
   - 掩码 `0x55555555` (二进制 `...01010101`) 的所有偶数位为 1。
   ```cpp
   bool isPowerOfFour(int n) {
       // n > 0 && 是 2 的幂 && 唯一的 1 在偶数位
       return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555);
   }
   ```
   > 技巧：`0x55555555` 选取偶数位，`0xAAAAAAAA` 选取奇数位。

## 总结

位运算通过将集合映射为整数，利用计算机底层的并行处理能力，极大地提高了集合操作的效率。在算法竞赛（如 LeetCode 周赛）和高性能计算中非常常见，尤其是在涉及「状态压缩 DP」或「小数据范围集合操作」的题目中。
