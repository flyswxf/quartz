# 生成不含相邻零的二进制字符串

## 题目描述

给你一个正整数 `n`。
如果一个二进制字符串 `x` 的所有长度为 2 的子字符串中包含 **至少** 一个 "1"，则称 `x` 是一个 **有效** 字符串。
返回所有长度为 `n` 的 **有效** 字符串，可以以任意顺序排列。

**示例 1：**
输入： `n = 3`
输出： `["010","011","101","110","111"]`
解释：
长度为 3 的有效字符串有： "010" 、 "011" 、 "101" 、 "110" 和 "111" 。

**示例 2：**
输入： `n = 1`
输出： `["0","1"]`
解释：
长度为 1 的有效字符串有： "0" 和 "1" 。

**提示：**
*   `1 <= n <= 18`

## 解题思路

### 方法一：回溯法 (Backtracking)

最直观的方法是使用回溯法逐位构建字符串。

**思路：**
1.  如果当前生成的字符串末尾是 '1'，那么下一位可以是 '0' 或 '1'。
2.  如果当前生成的字符串末尾是 '0'，那么下一位必须是 '1'（因为不能出现 "00"）。
3.  如果当前字符串为空，下一位可以是 '0' 或 '1'。

**代码实现 (C++)：**

```cpp
#include <vector>
#include <string>

using namespace std;

class Solution {
public:
    vector<string> validStrings(int n) {
        vector<string> result;
        string current;
        backtrack(n, current, result);
        return result;
    }

private:
    void backtrack(int n, string& current, vector<string>& result) {
        // Base case: 如果字符串长度达到 n，加入结果集
        if (current.length() == n) {
            result.push_back(current);
            return;
        }

        // 尝试添加 '0'
        // 只有当当前为空，或者前一位是 '1' 时，才能添加 '0'
        if (current.empty() || current.back() == '1') {
            current.push_back('0');
            backtrack(n, current, result);
            current.pop_back(); // 回溯
        }

        // 尝试添加 '1'
        // '1' 总是可以添加的，不会违反规则
        current.push_back('1');
        backtrack(n, current, result);
        current.pop_back(); // 回溯
    }
};
```

### 方法二：位运算 / 状态压缩 (Bit Manipulation)

我们可以利用位运算来枚举所有可能的二进制串，并快速检查是否合法。

**核心思路：**
遍历 $0$ 到 $2^n - 1$ 的所有整数，将每个整数视为一个长度为 $n$ 的二进制字符串。
关键在于如何快速判断一个整数的二进制表示中是否包含 "00"。

**位运算技巧：**
1.  **取反 (`~x`)**：将原数中的 `0` 变为 `1`，`1` 变为 `0`。此时，我们要找的 "00" 就变成了 "11"。
2.  **掩码 (`mask`)**：由于整数通常是 32 位的，取反后高位会有很多不需要的 `1`，我们需要用 `(1 << n) - 1` 来保留低 `n` 位。
3.  **检测连续位 (`y & (y >> 1)`)**：对于处理后的数 `y`，如果它包含 "11"，那么 `y` 和 `y >> 1` 进行按位与运算的结果一定不为 0。

**代码实现 (C++)：**

```cpp
#include <vector>
#include <string>

using namespace std;

class Solution {
public:
    vector<string> validStrings(int n) {
        vector<string> result;
        // 遍历所有可能的 n 位二进制数 (0 到 2^n - 1)
        int limit = 1 << n; 
        int mask = limit - 1; // 用于截断高位，只保留 n 位

        for (int i = 0; i < limit; ++i) {
            // 1. 取反：将检测 "00" 转换为检测 "11"
            // 2. 截断：只保留低 n 位
            int inverted = (~i) & mask;
            
            // 3. 检查是否存在连续的 1 (即原数中连续的 0)
            if ((inverted & (inverted >> 1)) == 0) {
                // 如果没有连续的 0，则为有效字符串
                result.push_back(intToBinaryString(i, n));
            }
        }
        return result;
    }

private:
    // 辅助函数：将整数转换为固定长度 n 的二进制字符串
    string intToBinaryString(int val, int n) {
        string s = "";
        for (int i = n - 1; i >= 0; --i) {
            s += ((val >> i) & 1) ? '1' : '0';
        }
        return s;
    }
};
```

**复杂度分析：**
- **时间复杂度**: $O(2^n)$。我们需要遍历所有可能的 $2^n$ 个状态。每次检查只需要常数时间的位运算操作。这对于 $n \le 18$ 是完全可行的。
- **空间复杂度**: $O(1)$ (不计算存储结果的空间)。我们只需要几个整型变量来存储状态和掩码。

### 为什么这个技巧有效？
假设 $n=3$，我们检查数字 $1$ (二进制 001 )：

1. i = 001
2. ~i 会得到 ...111110
3. inverted = (~i) & 0111 (因为 $n=3$，掩码是 111 ) $\rightarrow$ 110
4. inverted >> 1 $\rightarrow$ 011
5. inverted & (inverted >> 1) $\rightarrow$ 110 & 011 = 010 (非零)
   - 结果非零，说明存在连续的 1 (即原数存在连续的 0 )，所以无效。
再看数字 $2$ (二进制 010 )：

1. i = 010
2. inverted = (~i) & 111 $\rightarrow$ 101
3. inverted >> 1 $\rightarrow$ 010
4. inverted & (inverted >> 1) $\rightarrow$ 101 & 010 = 0
   - 结果为零，说明有效。
