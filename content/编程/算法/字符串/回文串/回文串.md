# 回文串特殊算法

在算法竞赛中，处理**回文数/回文串**（Palindrome）主要有以下 4 种核心算法与数据结构。根据解决的具体问题不同进行选择：

## 1. Manacher 算法（马拉车算法）

这是最著名的专门针对回文串的特殊算法。它可以在 **$O(N)$ 的线性时间**内求出一个字符串的最长回文子串（而中心扩展法是 $O(N^2)$）。

### 核心思想
1. **统一奇偶长度**：通过在每个字符之间及两端插入一个特殊字符（如 `#`），将所有长度的回文串统一转换为奇数长度。同时在字符串最开头和最末尾插入不同的字符（如 `^` 和 `$`）作为哨兵，防止越界。
2. **利用对称性加速**：维护当前已知最靠右的回文边界 $R$ 以及对应的回文中心 $C$。当遍历到位置 $i$ 时，如果 $i < R$，那么 $i$ 关于 $C$ 的对称点 $i'$ 已经被计算过，可以直接利用 $i'$ 的回文半径来跳过大部分多余的字符比较操作。

### C++ 模板
```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

struct Manacher {
    string s;       // 预处理后的字符串
    vector<int> p;  // p[i] 表示以 s[i] 为中心的回文半径

    Manacher(const string& str) {
        // 1. 预处理：消除奇偶长度差异
        // 例如: "aba" -> "^#a#b#a#$"
        s = "^";
        for (char c : str) {
            s += '#';
            s += c;
        }
        s += "#$";
        
        int n = s.length();
        p.assign(n, 0);
        
        int C = 0, R = 0; // 当前最右回文边界 R 和对应的中心 C
        for (int i = 1; i < n - 1; ++i) {
            int i_mirror = 2 * C - i; // i 关于 C 的对称点
            
            // 状态转移：利用对称性，加速计算
            if (R > i) {
                p[i] = min(R - i, p[i_mirror]);
            } else {
                p[i] = 0;
            }
            
            // 中心扩展法尝试扩大回文半径 (由于有哨兵 ^ 和 $，不会越界)
            while (s[i + 1 + p[i]] == s[i - 1 - p[i]]) {
                p[i]++;
            }
            
            // 更新当前最靠右的回文边界 C 和 R
            if (i + p[i] > R) {
                C = i;
                R = i + p[i];
            }
        }
    }

    // 获取最长回文子串的长度
    int getLongest() {
        int max_len = 0;
        for (int r : p) {
            max_len = max(max_len, r);
        }
        return max_len;
    }
};
```

### 关键要点说明
- **半径即长度**：在预处理后的字符串中，以 `s[i]` 为中心的回文半径 `p[i]`，**恰好等于**原字符串中该回文子串的总长度。
- **复杂度证明**：由于 `R` 的值是单调递增的，且最大不会超过 $2N$，所以 `while` 循环总的执行次数为 $O(N)$，整体时间复杂度为严格的 $O(N)$。

## 2. 回文自动机 / 回文树（Palindromic Tree / PAM）

如果题目不仅要求“最长”，还要求**“本质不同的回文串个数”**或**“某个回文串出现的次数”**，Manacher 就无能为力了，此时需要使用**回文自动机**。

### 核心思想
- 类似于字典树（Trie），但它有两个根节点（一个代表长度为 0 的偶数回文，一个代表长度为 -1 的奇数回文）。
- 它的边代表在当前回文串的**两端**同时添加一个相同字符。
- 维护了 `fail` 指针，指向当前回文串的最长回文真后缀。

### 关键要点说明
- **时间复杂度**：构造时间为 $O(N)$。
- **适用场景**：求本质不同的回文子串数量、求回文子串出现次数、求两个字符串的公共回文子串等。

---

## 3. 正反字符串哈希（String Hashing）

这是竞赛中最万能、最常被用来“逃课”（代替复杂算法）的技巧。

### 核心思想
- 分别维护原字符串的**前缀哈希数组**和**反转字符串的前缀哈希数组**。

### 关键要点说明
- **时间复杂度**：$O(N)$ 预处理，$O(1)$ 查询。
- **适用场景**：可以在 $O(1)$ 时间内判断任意子串 `s[l...r]` 是否为回文串（只需判断正向哈希值和反向哈希值是否相等）。结合二分查找，它也能在 $O(N \log N)$ 的时间内求出最长回文子串，足以通过绝大部分非极限卡常的题目。

---

## 4. 区间 DP（针对回文子序列）

需要特别注意的是，前三种算法都是针对**回文子串**（连续的）。如果题目问的是**回文子序列**（不连续的，比如在 `abcbda` 中找出 `abcba`），通常的解法是动态规划。

### 核心思想
- **状态定义**：`dp[i][j]` 表示区间 `[i, j]` 内的最长回文子序列长度。
- **状态转移**：
  - 如果 `s[i] == s[j]`，则 `dp[i][j] = dp[i+1][j-1] + 2`；
  - 否则 `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`。

---

## 总结建议
在算法竞赛中，遇到回文串问题：
1. **第一反应想正反哈希**（最万能且好写）；
2. 如果是求最长且卡时间，**上 Manacher 模板**；
3. 如果是回文计数或统计类复杂问题，才考虑**回文自动机 (PAM)**。
