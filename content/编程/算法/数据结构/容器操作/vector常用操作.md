# vector (动态数组) 常用操作

`vector` 是 C++ STL 中最基础且最常用的序列式容器，底层封装了动态大小的连续数组。它支持 $O(1)$ 的随机访问，并在尾部提供均摊 $O(1)$ 的插入和删除操作。

## 核心操作表格

| 操作类别 | 代码示例 | 功能说明 | 时间复杂度 |
| :--- | :--- | :--- | :--- |
| **初始化** | `vector<int> v;` | 创建一个空 vector | $O(1)$ |
| | `vector<int> v(n, x);` | 创建大小为 n，全为 x 的 vector | $O(N)$ |
| | `vector<int> v = {1, 2, 3};` | 列表初始化 | $O(N)$ |
| **容量获取** | `v.size();` | 获取当前元素个数 | $O(1)$ |
| | `v.empty();` | 判断是否为空，空返回 true | $O(1)$ |
| **容量调整** | `v.resize(n, x);` | 改变大小为 n，新增元素设为 x | $O(N)$ |
| | `v.reserve(n);` | 预分配 n 个元素的底层空间，不改变 size | $O(N)$ |
| **元素访问** | `v[i]` | 访问第 i 个元素（不进行越界检查） | $O(1)$ |
| | `v.front();` / `v.back();` | 获取第一个 / 最后一个元素 | $O(1)$ |
| **修改操作** | `v.push_back(x);` | 在尾部添加元素 x | 均摊 $O(1)$ |
| | `v.pop_back();` | 弹出尾部元素 | $O(1)$ |
| | `v.insert(v.begin() + i, x);` | 在索引 i 处插入 x（极其低效，尽量避免） | $O(N)$ |
| | `v.erase(v.begin() + i);` | 删除索引 i 处的元素 | $O(N)$ |
| | `v.clear();` | 清空所有元素（size 变为 0） | $O(N)$ |

## 进阶操作与代码示例

### 1. 数组去重 (离散化常用)
在算法竞赛中，经常需要对数组进行排序并去重，这被称为离散化的前置步骤。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    vector<int> v = {3, 1, 2, 2, 1, 3};
    
    // 1. 去重前必须先排序
    sort(v.begin(), v.end()); // v 变为 {1, 1, 2, 2, 3, 3}
    
    // 2. unique 将重复元素移到末尾，并返回去重后逻辑数组的尾迭代器
    // 3. erase 真正删除掉末尾的冗余元素
    v.erase(unique(v.begin(), v.end()), v.end());
    
    // 此时 v 变为 {1, 2, 3}
    return 0;
}
```

### 2. 复制 vector 的几种方法
在不同的场景下，复制 `vector` 有多种高效或灵活的方法。

```cpp
vector<int> v1 = {1, 2, 3, 4, 5};

// 方法一：等号直接赋值 (最常用，深拷贝整个 vector)
vector<int> v2 = v1; 

// 方法二：拷贝构造函数
vector<int> v3(v1);

// 方法三：assign 方法 (覆盖并替换当前 vector 的内容)
vector<int> v4;
v4.assign(v1.begin(), v1.end());

// 方法四：截取部分复制 (利用迭代器，非常灵活)
// 例如：只复制 v1 的前 3 个元素
vector<int> v5(v1.begin(), v1.begin() + 3); // v5 = {1, 2, 3}
```

### 3. 遍历方式推荐
```cpp
vector<int> v = {1, 2, 3};

// 方式一：基于范围的 for 循环 (推荐，加上 & 可以修改原值并避免拷贝开销)
for (int& x : v) {
    x *= 2; 
}

// 方式二：经典下标遍历 (需要获取下标时使用)
for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}
```

## 关键要点说明

1. **`resize()` 与 `reserve()` 的严格区别**：
   - `resize(n)`：真正改变了容器包含的逻辑元素数量（即 `size` 改变）。如果 `n` 大于当前的 `size`，会调用元素的默认构造函数来填充新增加的空间；之后可以直接通过 `v[i]` 访问这些新元素。
   - `reserve(n)`：仅仅预分配底层内存容量（即 `capacity` 改变），但不创建新元素（`size` 不变）。常用于已知大概数据量时，提前分配以避免多次动态扩容带来的性能损耗。**此时不能通过 `v[i]` 访问新空间，只能用 `push_back` 添加。**

2. **`push_back()` 与 `emplace_back()`**：
   - 对于内置类型（如 `int`），两者性能几乎无差别。
   - 对于自定义的结构体或类，`emplace_back()` 可以直接在容器内存中原地构造对象，省去了一次多余的拷贝或移动构造开销。在现代 C++ 中通常推荐优先使用 `emplace_back()`。

3. **迭代器失效与扩容机制**：
   - 当发生扩容时（即当前 `size == capacity` 且继续执行 `push_back`），`vector` 会在内存中开辟一块新的（通常是原大小两倍）空间，并将原数据全部搬过去。**此时指向原空间的所有指针、引用和迭代器都会立刻失效**。
