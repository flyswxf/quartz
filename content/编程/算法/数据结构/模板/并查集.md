# 并查集 (Disjoint Set Union, DSU)

并查集是一种树型的数据结构，用于处理一些不交集 (Disjoint Sets) 的合并及查询问题。常用于连通性问题，如 Kruskal 最小生成树算法、判断图中是否有环、朋友圈等连通块问题。

## 核心思想
- **初始化 (Init)**：每个元素自成一个集合，父节点指向自己。
- **查找 (Find)**：找到某个元素所在集合的代表元素（根节点）。在此过程中应用 **路径压缩**，将路径上的所有节点直接连接到根节点，加速后续查找。
- **合并 (Unite/Union)**：将两个不同集合合并成一个。通过 **按秩合并 (Union by Size/Rank)**，将小树挂到大树下面，避免树退化成链表。
- **时间复杂度**：
  - 单次 `find` 或 `unite` 的均摊时间复杂度为 $O(\alpha(N))$，其中 $\alpha$ 是阿克曼函数的反函数，在实际应用中 $\alpha(N) \le 4$，可认为是 $O(1)$ 常数时间。

## C++ 模板 (路径压缩 + 按秩合并)

以下是标准的并查集模板，包含路径压缩和按大小 (Size) 合并的优化。

```cpp
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

struct DSU {
    vector<int> parent; // 记录每个节点的父节点
    vector<int> sz;     // 记录每个集合的大小（以该节点为根的树的节点数）

    // 构造函数：初始化 n 个节点
    // 注意：默认下标从 0 到 n，若需要 1 到 n，则初始化 n + 1 大小
    DSU(int n) : parent(n + 1), sz(n + 1, 1) {
        // iota 将 parent 初始化为 0, 1, 2, ..., n
        iota(parent.begin(), parent.end(), 0);
    }

    // 查找 x 所属集合的根节点（带路径压缩）
    int find(int x) {
        if (parent[x] != x) {
            // 递归查找根节点，并将当前节点直接连接到根节点
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // 合并 a 和 b 所在的集合（按集合大小合并）
    // 返回值：如果 a 和 b 原本不在同一集合并成功合并，返回 true；否则返回 false
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        
        // 已经在同一个集合中
        if (a == b) {
            return false;
        }
        
        // 按秩合并：将较小的集合合并到较大的集合中
        if (sz[a] < sz[b]) {
            swap(a, b);
        }
        
        // 将 b 的根节点挂在 a 的根节点下
        parent[b] = a;
        // 更新大集合的大小
        sz[a] += sz[b];
        
        return true;
    }
    
    // 扩展：判断 a 和 b 是否在同一个集合
    bool isConnected(int a, int b) {
        return find(a) == find(b);
    }
};
```

## 关键要点说明

1. **`iota` 函数**：
   `iota(begin, end, val)` 是 `<numeric>` 库中的函数，作用是将容器内的元素依次赋值为 `val, val+1, val+2...`。这里用来快速初始化每个节点的父节点为自己。

2. **路径压缩 (Path Compression)**：
   在 `find` 函数中，`parent[x] = find(parent[x])` 是核心。它会在寻找根节点的回溯过程中，把路径上的所有节点都直接指向根节点。这使得下一次查找这些节点时的复杂度直接降为 $O(1)$。

3. **按大小合并 (Union by Size)**：
   在 `unite` 函数中，通过维护 `sz` 数组，始终保证小树挂在大树下面（如果 `sz[a] < sz[b]` 就交换，保证 `a` 是大树）。这样可以保证树的深度始终是对数级别，防止退化。**注意，如果不使用按大小合并，只使用路径压缩，时间复杂度也是极其接近 $O(1)$ 的，在许多竞赛中为了写得快，可以只保留路径压缩。** 

4. **节点编号范围**：
   模板中使用了 `n + 1` 作为数组大小。这是为了同时兼容节点编号是 `0 ~ n-1` (大小需为 $N$) 以及 `1 ~ n` (大小需为 $N+1$) 的题目。
