# 线段树 (Segment Tree)

线段树是一种二叉树形数据结构，主要用于存储区间或线段，能够高效地解决连续区间的动态查询和修改问题，例如区间求和、区间最大/小值等。

## 核心思想
- **分治法**：将一个大区间划分成两个小区间（左半部分和右半部分），每个节点代表一个区间的统计信息。
- **时间复杂度**：
  - **建树 (Build)**: $O(N)$
  - **单点修改/区间修改 (Update)**: $O(\log N)$
  - **区间查询 (Query)**: $O(\log N)$

---

## C++ 模板 (区间修改 + 区间查询)

以下是一个标准的线段树模板，支持 **区间加法** 和 **区间求和**，并使用了 **懒标记 (Lazy Propagation)** 机制来保证区间修改的效率。

```cpp
#include <iostream>
#include <vector>

using namespace std;
typedef long long ll;

class SegmentTree {
private:
    vector<ll> tree; // 存储线段树节点值（例如区间和）
    vector<ll> lazy; // 懒标记数组
    int n;

    // 用子节点的值更新父节点 (Push Up)
    void pushUp(int node) {
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    // 下传懒标记 (Push Down)
    void pushDown(int node, int left, int right) {
        if (lazy[node] != 0) {
            int mid = left + (right - left) / 2;
            
            // 更新左子节点：值增加 lazy[node] * 左区间长度
            tree[node * 2] += lazy[node] * (mid - left + 1);
            lazy[node * 2] += lazy[node]; // 累加懒标记
            
            // 更新右子节点：值增加 lazy[node] * 右区间长度
            tree[node * 2 + 1] += lazy[node] * (right - mid);
            lazy[node * 2 + 1] += lazy[node]; // 累加懒标记
            
            // 清空当前节点的懒标记
            lazy[node] = 0;
        }
    }

    // 递归建树
    void build(const vector<int>& arr, int node, int left, int right) {
        if (left == right) {
            tree[node] = arr[left];
            return;
        }
        int mid = left + (right - left) / 2;
        build(arr, node * 2, left, mid);       // 左子树
        build(arr, node * 2 + 1, mid + 1, right); // 右子树
        pushUp(node);
    }

    // 区间更新
    void update(int node, int left, int right, int ql, int qr, ll val) {
        // 如果当前区间被完全包含在查询区间内，直接更新并打上懒标记
        if (ql <= left && right <= qr) {
            tree[node] += val * (right - left + 1);
            lazy[node] += val;
            return;
        }
        
        // 如果没有完全包含，必须先下传懒标记
        pushDown(node, left, right);
        
        int mid = left + (right - left) / 2;
        if (ql <= mid) update(node * 2, left, mid, ql, qr, val);
        if (qr > mid) update(node * 2 + 1, mid + 1, right, ql, qr, val);
        
        pushUp(node); // 更新完子节点后，更新当前节点
    }

    // 区间查询
    ll query(int node, int left, int right, int ql, int qr) {
        // 如果当前区间被完全包含，直接返回该节点的值
        if (ql <= left && right <= qr) {
            return tree[node];
        }
        
        // 查询前必须下传懒标记
        pushDown(node, left, right);
        
        int mid = left + (right - left) / 2;
        ll sum = 0;
        if (ql <= mid) sum += query(node * 2, left, mid, ql, qr);
        if (qr > mid) sum += query(node * 2 + 1, mid + 1, right, ql, qr);
        
        return sum;
    }

public:
    // 构造函数
    SegmentTree(const vector<int>& arr) {
        n = arr.size();
        // 线段树的空间一般开到原数组大小的 4 倍
        tree.assign(4 * n, 0);
        lazy.assign(4 * n, 0);
        if (n > 0) {
            build(arr, 1, 0, n - 1);
        }
    }

    // 外部接口：将区间 [ql, qr] 内的所有元素加上 val
    void update(int ql, int qr, ll val) {
        update(1, 0, n - 1, ql, qr, val);
    }

    // 外部接口：查询区间 [ql, qr] 的和
    ll query(int ql, int qr) {
        return query(1, 0, n - 1, ql, qr);
    }
};

int main() {
    // 测试用例
    vector<int> arr = {1, 2, 3, 4, 5};
    SegmentTree st(arr);
    
    // 初始状态下 [0, 2] 的和：1 + 2 + 3 = 6
    cout << "Sum of [0, 2]: " << st.query(0, 2) << endl; 
    
    // 将区间 [0, 2] 的每个元素加上 2 (数组变为 3, 4, 5, 4, 5)
    st.update(0, 2, 2);
    
    // 更新后 [0, 2] 的和：3 + 4 + 5 = 12
    cout << "Sum of [0, 2] after update: " << st.query(0, 2) << endl;
    
    return 0;
}
```

## 关键要点说明

1. **数组大小 ($4N$)**：
   对于长度为 $N$ 的数组，对应的线段树最多会有大约 $4N$ 个节点（证明：满二叉树叶子节点为 $N$ 时，总节点数为 $2N-1$；但线段树通常是不完全二叉树，底层可能会出现空隙，因此保守估计开 $4N$ 是安全的）。

2. **懒标记 (Lazy Tag)**：
   在进行**区间修改**时，如果不使用懒标记，每次修改都深入到叶子节点，最坏情况下时间复杂度会退化为 $O(N)$。
   懒标记的作用是：**当修改区间完全覆盖当前节点所代表的区间时，只更新当前节点的值，并将变化量记录在 `lazy` 数组中，不再继续往下递归。** 只有当后续需要查询或更新它的子节点时，才将懒标记传递下去 (`pushDown`)，从而保证了 $O(\log N)$ 的时间复杂度。

3. **节点索引映射**：
   - 根节点下标从 `1` 开始（这样计算左右子节点最方便）。
   - 左子节点索引：`node * 2` (或者 `node << 1`)
   - 右子节点索引：`node * 2 + 1` (或者 `node << 1 | 1`)
