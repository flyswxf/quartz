# 最大公约数与最小公倍数 (GCD & LCM)

求解最大公约数（Greatest Common Divisor, GCD）和最小公倍数（Least Common Multiple, LCM）是数论中最基础的算法之一。

## 核心思想

- **欧几里得算法（辗转相除法）**：基于数学定理 $\gcd(a, b) = \gcd(b, a \bmod b)$。当 $b = 0$ 时，$a$ 的值即为最大公约数。
  - 例如：求 $\gcd(18, 12)$：
    1. $\gcd(18, 12) \rightarrow \gcd(12, 18 \bmod 12) = \gcd(12, 6)$
    2. $\gcd(12, 6) \rightarrow \gcd(6, 12 \bmod 6) = \gcd(6, 0)$
    3. $b=0$，结果为 $6$。
- **最小公倍数**：利用公式 $\text{lcm}(a, b) = \frac{a \times b}{\gcd(a, b)}$。为避免乘法溢出，通常先做除法再做乘法：$a / \gcd(a, b) \times b$。
- **时间复杂度**：$O(\log(\min(a, b)))$，即使输入值非常大（如 $10^{18}$ 级别），算法也会在几十次迭代内迅速收敛，极其高效。

## C++ 模板

在现代 C++（C++17 及以上）中，推荐直接使用 `<numeric>` 头文件中的内置函数。如果环境不支持（例如极老的竞赛平台），则使用简短的手写递归版本。

### 1. 内置函数版本 (推荐, C++17+)

```cpp
#include <numeric>
#include <iostream>

using namespace std;

// std::gcd(a, b) 求最大公约数
// std::lcm(a, b) 求最小公倍数
void example() {
    long long a = 12, b = 18;
    
    // 输出: 6
    cout << "GCD: " << std::gcd(a, b) << "\n"; 
    
    // 输出: 36
    cout << "LCM: " << std::lcm(a, b) << "\n"; 
}
```

### 2. 手写模板版本 (兼容旧标准)

```cpp
// 递归版 GCD (代码最短，最常用)
// 假设 a, b >= 0
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}

// LCM (注意先除后乘防溢出)
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) return 0;
    return (a / gcd(a, b)) * b;
}
```

## 关键要点说明

1. **为什么推荐使用内置函数 `std::gcd`？**
   `<numeric>` 头文件中的 `std::gcd` 已经在底层做好了充分的优化，并且能完美处理负数情况（例如 $\gcd(-12, 18) = 6$）。而如果使用手写模板处理负数（取模运算在 C++ 中对负数的结果仍为负），可能会产生意外行为，还需要额外加上 `std::abs()` 来保证正确性。

2. **防溢出细节（极其重要）**：
   在计算最小公倍数时，直接写 `a * b / gcd(a, b)` 极易在 `a * b` 这一步引发 `long long` 类型的溢出（尤其是当 $a$ 和 $b$ 都是 $10^9$ 级别时）。
   **务必**写成 `a / gcd(a, b) * b`。因为 $a$ 一定能被 $\gcd(a, b)$ 整除，先做除法可以保证计算的中间结果最小，从而有效防止溢出。

3. **多个数字的 GCD/LCM**：
   如果要求一个数组中所有元素的总 GCD 或 LCM，只需遍历数组并两两累积即可。
   例如：$\gcd(a, b, c) = \gcd(\gcd(a, b), c)$。
   ```cpp
   // 求整个 vector 的 GCD
   long long get_array_gcd(const vector<long long>& arr) {
       long long res = arr[0];
       for (size_t i = 1; i < arr.size(); ++i) {
           res = std::gcd(res, arr[i]);
       }
       return res;
   }
   ```
