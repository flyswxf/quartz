# 质数判断 (Primality Test)

判断一个正整数是否为质数的最基础也是最常用的方法是**试除法**。

## 核心思想
- **试除法定理**：如果一个数 $N$ 有大于 $1$ 的因子，那么这些因子必然是成对出现的（即 $N = a \times b$）。在每一对因子中，必然有一个 $\le \sqrt{N}$，另一个 $\ge \sqrt{N}$。
- **结论**：要判断 $N$ 是否为质数，只需检查从 $2$ 到 $\sqrt{N}$ 之间的所有整数能否整除 $N$ 即可。如果都不能整除，则 $N$ 是质数。
- **时间复杂度**：$O(\sqrt{N})$

---

## C++ 模板 (试除法)

```cpp
bool isPrime(int n) {
    // 1 和 0 不是质数，负数也不是质数
    if (n < 2) return false;
    
    // 从 2 遍历到 sqrt(n)
    for (int i = 2; i <= n / i; i++) {
        if (n % i == 0) {
            // 发现除了 1 和 n 之外的因子，说明不是质数
            return false;
        }
    }
    
    return true;
}
```

---

## 关键要点说明

1. **边界条件处理**：
   $0$ 和 $1$ 既不是质数也不是合数。在函数开头必须先拦截小于 $2$ 的数字。
   
2. **循环条件的写法**：
   不推荐写成 `i <= sqrt(n)`，因为 `sqrt()` 是浮点数运算，速度较慢且有精度问题。
   不推荐写成 `i * i <= n`，因为当 `n` 接近 `int` 的最大值时，`i * i` 极易引发**整数溢出**，导致死循环或错误。
   **最佳写法**：`i <= n / i`。既避免了浮点运算，又彻底杜绝了溢出风险。

3. **适用场景**：
   试除法适用于单次判断较小的数（例如 $N \le 10^{12}$，此时 $\sqrt{N} \le 10^6$，时间上完全可以接受）。如果需要批量判断大量数字是否为质数，则应使用[[质数筛法]]。
