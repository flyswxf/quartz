# 质因数分解 (Prime Factorization)

任何一个大于 $1$ 的自然数，都可以唯一地分解成有限个质数的乘积，这被称为**算术基本定理**。

例如：$45 = 3^2 \times 5^1$，分解结果通常表示为一组对：$(3, 2)$ 和 $(5, 1)$，分别代表**质因数**和对应的**指数**。

## 核心思想

对于单次查询，试除法（$O(\sqrt{N})$）已经足够。但如果**需要对大量数据进行质因数分解**，试除法会显得过于缓慢。此时，可以通过预处理极大加速分解过程。根据需求不同，有两种主流的预处理策略：

1. **预处理所有不同质因子**：利用类似埃氏筛的原理，直接为每个数挂载其包含的所有不同质因子。适用于只需要知道有哪些质因子，而不需要知道具体指数的场景。
2. **预处理最小质因数 (LPF, Lowest Prime Factor)**：提前求出每个数字的最小质因数，分解时不断除以其最小质因数，直到 $N = 1$。这种方法可以在 $O(\log N)$ 时间内求出完整的质因数及其指数。

## C++ 模板 (§1.3 质因数分解)

### 模板一：预处理每个数的所有不同质因子
原理同埃氏筛。适用于只需要知道一个数含有哪些不同的质因子。

```cpp
#include <vector>

using namespace std;

constexpr int MX = 1'000'001; 
vector<int> prime_factors[MX]; 
 
int init1 = [] { 
    for (int i = 2; i < MX; i++) { 
        if (prime_factors[i].empty()) { // i 是质数 
            for (int j = i; j < MX; j += i) { // i 的倍数 j 有质因子 i 
                prime_factors[j].push_back(i); 
            } 
        } 
    } 
    return 0; 
}(); 
```

### 模板二：预处理最小质因子 LPF(x)
通过预处理 $x$ 的最小质因子 `lpf[x]`，从而做到 $O(\log x)$ 分解 $x$。可以求出 $x$ 的每个质因子的个数。

```cpp
#include <vector>
#include <utility>

using namespace std;

constexpr int MX = 1'000'001; 
int lpf[MX]; 
 
int init2 = [] { 
    for (int i = 2; i < MX; i++) { 
        if (lpf[i] == 0) { // i 是质数 
            for (int j = i; j < MX; j += i) { 
                if (lpf[j] == 0) { // 首次访问 j 
                    lpf[j] = i; 
                } 
            } 
        } 
    } 
    return 0; 
}(); 
 
// 质因数分解 
// 例如 prime_factorization(45) = {{3, 2}, {5, 1}}，表示 45 = 3^2 * 5^1 
// 时间复杂度 O(log x) 
vector<pair<int, int>> prime_factorization(int x) { 
    vector<pair<int, int>> res; 
    while (x > 1) { 
        int p = lpf[x]; 
        int e = 1; 
        for (x /= p; x % p == 0; x /= p) { 
            e++; 
        } 
        res.emplace_back(p, e); 
    } 
    return res; 
}
```

> **参考来源**：以上模板改写自 [灵茶山艾府 - 【算法题单】数学算法](https://leetcode.cn/discuss/post/IYT3ss/)。

## 关键要点说明

1. **模板一 vs 模板二如何选择？**
   - 如果题目只需要去重后的质因子（例如求一个数有哪些不同的质因子来算贡献），使用**模板一**更直接。
   - 如果题目需要完整的质因数分解（包括每个质因子的指数），使用**模板二**更快且空间开销更小（模板一使用 `vector` 数组，常数较大）。
   
2. **`lpf` 数组的原理 (模板二)**：
   在预处理循环中，当遍历到质数 $i$ 时，将其所有倍数 $j$ 的 `lpf[j]` 设为 $i$。关键在于 `if (lpf[j] == 0)` 的判断，这保证了每个合数 $j$ 只会在被其**最小的质因数**遍历到时被赋值，后续更大的质因数遍历到它时不会发生覆盖。

3. **初始化技巧**：
   使用 `int _init = []{...}();` 这种 lambda 表达式立即执行的方式，可以让预处理代码在 `main` 函数执行之前自动运行，使得核心的业务逻辑中无需再显式调用初始化函数，代码更为优雅。

4. **进阶场景：大整数分解**：
   这两种方法要求开辟大小为值域的数组，因此**仅适用于 $N \le 10^7$ 左右的场景**（受限于内存）。对于非常大的数（例如 $N \le 10^{18}$），需要使用 **Pollard's Rho 算法**（结合 Miller-Rabin 质数测试），能在 $O(N^{1/4})$ 期望时间内完成分解。
