# 质数筛法 (Prime Sieve)

当需要找出从 $1$ 到 $N$ 之间**所有的质数**时，使用单次试除法的时间复杂度会达到 $O(N\sqrt{N})$，效率低下。此时需要使用**筛法**。常用的有两种：埃氏筛 (Sieve of Eratosthenes) 和 欧拉线性筛 (Euler's Linear Sieve)。

## 核心思想

### 1. 埃氏筛 (Sieve of Eratosthenes)
- **原理**：从 $2$ 开始，将每个质数的倍数都标记为合数。未被标记的数即为质数。
- **时间复杂度**：$O(N \log \log N)$，非常接近线性时间，代码短小精悍。

### 2. 欧拉筛 / 线性筛 (Euler's Linear Sieve)
- **原理**：埃氏筛的缺点是同一个合数会被多个质因子重复标记（比如 $12$ 会被 $2$ 筛一次，被 $3$ 筛一次）。欧拉筛通过**让每个合数只被其最小的质因子筛掉**，彻底消除了重复标记。
- **时间复杂度**：严格的 $O(N)$，在 $N \ge 10^7$ 的大规模数据下优势明显。

## C++ 模板

### 模板 1：埃氏筛
```cpp
#include <vector>

using namespace std;

// 找到 1 到 n 的所有质数
vector<int> sieveOfEratosthenes(int n) {
    vector<int> primes;
    // is_prime[i] 表示 i 是否为质数
    vector<bool> is_prime(n + 1, true);
    
    is_prime[0] = is_prime[1] = false;
    
    for (int i = 2; i <= n; i++) {
        if (is_prime[i]) {
            primes.push_back(i);
            // 优化：从 i 的平方开始筛，因为比 i 小的倍数已经被更小的质数筛过了
            if ((long long)i * i <= n) {
                for (int j = i * i; j <= n; j += i) {
                    is_prime[j] = false;
                }
            }
        }
    }
    return primes;
}
```

### 模板 2：欧拉筛 (线性筛) - 推荐
```cpp
#include <vector>

using namespace std;

// 找到 1 到 n 的所有质数
vector<int> eulerSieve(int n) {
    vector<int> primes;
    vector<bool> is_prime(n + 1, true);
    
    is_prime[0] = is_prime[1] = false;
    
    for (int i = 2; i <= n; i++) {
        // 如果未被筛掉，说明是质数
        if (is_prime[i]) {
            primes.push_back(i);
        }
        
        // 遍历目前已找到的质数
        for (int j = 0; j < primes.size() && i * primes[j] <= n; j++) {
            // 用当前的质数 primes[j] 乘以 i，标记为合数
            is_prime[i * primes[j]] = false;
            
            // 核心灵魂代码：如果 i 已经是 primes[j] 的倍数，立刻停止
            // 保证每个合数只被它的最小质因子筛掉
            if (i % primes[j] == 0) {
                break;
            }
        }
    }
    return primes;
}
```

---

## 关键要点说明

1. **线性筛的灵魂 `if (i % primes[j] == 0) break;`**：
   - 这是保证 $O(N)$ 复杂度的关键。
   - 例如当 $i = 4$，遍历到的质数有 $2, 3$。当遇到 $primes[j] = 2$ 时，$4 \times 2 = 8$ 被筛掉。接着判断 $4 \pmod 2 == 0$ 成立，直接 `break`。
   - 为什么需要 `break`？因为如果不 `break`，下一步就会用 $primes[j] = 3$ 去筛 $4 \times 3 = 12$。但是 $12$ 的最小质因子是 $2$（即 $12 = 6 \times 2$），它应该在未来当 $i = 6$ 时被质数 $2$ 筛掉，而不应该在这里被质数 $3$ 越俎代庖。
   
2. **应用场景选择**：
   - 绝大多数普通算法题（$N \le 10^6$），埃氏筛因为常数极小，且代码简单不易写错，完全可以胜任。
   - 若 $N$ 极大（如 $10^7$ 及以上），或需要结合筛法求积性函数（如欧拉函数、莫比乌斯函数），则必须使用线性筛。
