## atan2函数基础
### 函数定义
atan2是一个数学函数，在C/C++等编程语言中常用于计算反正切值。函数原型为：
```cpp
double atan2(double y, double x);
```
注意参数顺序是先y后x，这与数学中常见的(x,y)表示方式不同。
### 计算原理

atan2函数计算的是点(x,y)与原点连线和x轴正方向之间的夹角，即方位角。
### 值域

atan2函数的值域为(-π, π]
这与普通atan函数的值域\[-π/2, π/2]不同，atan2函数能够覆盖整个平面的所有象限，因此能够唯一确定角度。
### 角度连续性问题
从0-2π遍历坐标系的一圈时，通常使用atan2来计算角度，其值域为\[-π,π]。遍历从最小角度开始，但在遇到最大角度(π)附近时，会出现一个问题：再大一点的角度就会大于π，然而大于π的点实际存储为接近-π的点，导致之前的识别策略（比如角度差值<k）无法识别到这些点。
### 解决方案：角度扩展

为了解决这个问题，最好的方法是遍历两圈：
1. 第一圈使用原来的点，值域为\[-π,π]
2. 第二圈使用第一圈+2π的点，值域为\[π,3π]
这样就形成了连续函数。在π附近时，也能识别到后续的点。
### 实际应用示例
比如有两个点，一个点是179°（接近π），另一个点是-179°（接近-π），如果我们设定角度范围为5°，并以179°为起点，加上角度范围就是184°，这个范围是179°到184°，无法覆盖到-179°。

但实际上，-179°应该也在这个范围内（从几何意义上看，它与179°只相差2°）。解决方法是让-179°加上360°，变成181°，这时候就在179°到184°的范围内了，就可以被正确覆盖到。

由于角度范围（5°）小于360°，这就保证了原来的点和它加上360°后的点不可能被同时覆盖到，也就保证了同一个点不会被重复计算两次，保证了结果的正确性。
### 代码实现思路
```cpp
// 假设points是所有点的集合，每个点有一个角度属性angle（通过atan2计算得到）
// 对points按照angle排序
sort(points.begin(), points.end(), [](const Point& a, const Point& b) {
    return a.angle < b.angle;
});

// 复制一份点并加上2π
int n = points.size();
for (int i = 0; i < n; i++) {
    Point p = points[i];
    p.angle += 2 * M_PI; // 角度加上2π
    points.push_back(p);
}
// 现在可以使用滑动窗口等技术处理连续的角度范围
```
这种技术在很多几何问题中非常有用，特别是在处理环形或周期性数据时。
