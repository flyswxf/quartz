### 逆元基础概念

逆元素（简称逆元）是指可以取消另一给定元素运算的元素。例如加法中的相反数，乘法中的倒数。简单来说，$a$ 的逆元就是能抵消 $a$ 的影响的元素。

### 数论中的乘法逆元

#### 定义
如果一个线性同余方程满足：
$$ax \equiv 1 \pmod b$$
则 $x$ 称为 $a \bmod b$ 的逆元，记作 $a^{-1}$。

可以简单理解为：$a^{-1} \times a = 1$，即逆元消除了乘 $a$ 的影响。

#### 作用与意义
在模意义下，除法运算无法直接进行（例如处理 $\frac{a}{b} \bmod m$ 时，$a$ 可能已被取模，导致直接相除结果错误）。
乘法逆元的作用在于**将模意义下的除法转化为乘法**：模意义下除以一个数，等价于乘上这个数的乘法逆元。

推导过程：
若求 $\frac{a}{b} \bmod p$ 的结果 $c$，等价于解方程：
$$b \times c \equiv a \pmod p$$
两边同乘 $b$ 的逆元 $b^{-1}$，即可消去 $b$ 的影响：
$$b \times c \times b^{-1} \equiv a \times b^{-1} \pmod p$$
$$c \equiv a \times b^{-1} \pmod p$$

因此，求 $\frac{a}{b} \bmod m$，只需要找到除数 $b$ 的逆元 $x$，使得：
$$\frac{a}{b} \bmod m = a \times x \bmod m$$

### 逆元存在的条件

逆元存在的最根本条件是：**除数 $b$ 与模数 $p$ 必须互质**，即 $\gcd(b, p) = 1$。
- 如果 $p$ 是质数，那么只要 $b$ 不是 $p$ 的倍数，两者自然互质。
- 如果 $p$ 不是质数，只要满足 $\gcd(b, p) = 1$，逆元依然存在，但不能使用快速幂求解。

### 求逆元的方法与代码实现

#### 方法一：快速幂（要求模数 $p$ 为质数）

利用费马小定理，当模数 $p$ 为质数，且除数 $b$ 与 $p$ 互质时，$b$ 的逆元为 $b^{p-2} \bmod p$。

- **要求**：模数 $p$ 必须为质数。
- **参数说明**：
  - `b`：要求逆元的数（即除数）。
  - `p`：模数（必须为质数）。

```cpp
// 快速幂算法求 base^exp % mod
long long quick_pow(long long base, long long exp, long long mod) {
    if (base == 0 || base == 1) return base % mod;
    
    long long res = 1;
    long long t = base % mod;
    
    while (exp > 0) {
        if (exp & 1) {
            res = (res * t) % mod;
        }
        exp >>= 1;
        t = (t * t) % mod;
    }
    return res;
}

// 求除数 b 在模 p 意义下的乘法逆元
long long get_inv(long long b, long long p) {
    // 根据费马小定理，b 的逆元为 b^(p-2) % p
    return quick_pow(b, p - 2, p);
}
```

#### 方法二：扩展欧几里得算法（通用，模数 $p$ 不要求为质数）

当模数 $p$ 不是质数时，只要 $\gcd(b, p) = 1$，我们就可以使用扩展欧几里得算法（exgcd）来求逆元。

**原理**：
根据逆元的定义，求 $b$ 的逆元 $x$，即求解同余方程 $bx \equiv 1 \pmod p$。
这个同余方程可以转化为不定方程：$bx + py = 1$。
因为 $\gcd(b, p) = 1$，所以该方程一定有整数解。通过扩展欧几里得算法求出 $x$ 的最小正整数解，即为 $b$ 的逆元。

```cpp
// 扩展欧几里得算法，返回 gcd(a, b)，并通过引用求解 ax + by = gcd(a, b) 的一组特解 (x, y)
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}

// 求除数 b 在模 p 意义下的乘法逆元（p 不必是质数）
long long get_inv_exgcd(long long b, long long p) {
    long long x, y;
    long long gcd = exgcd(b, p, x, y);
    if (gcd != 1) {
        // b 和 p 不互质，逆元不存在
        return -1; 
    }
    // x 可能是负数，需要将其转化为 [0, p-1] 范围内的最小正整数
    return (x % p + p) % p;
}
```
