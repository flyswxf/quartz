## atoi 和 stoi 的主要用法

### atoi 函数
- **头文件**: `#include <cstdlib>` 或 `#include <stdlib.h>`
- **函数原型**: `int atoi(const char* str)`
- **功能**: 将C风格字符串转换为整数
- **返回值**: 转换后的整数值，转换失败返回0
- **特点**: 
  - 不进行错误检查
  - 遇到非数字字符会停止转换
  - 前导空格会被忽略

**使用示例**:
```cpp
#include <cstdlib>
#include <iostream>
using namespace std;

int main() {
    const char* str1 = "123";
    const char* str2 = "  456";
    const char* str3 = "789abc";
    
    cout << atoi(str1) << endl;  // 输出: 123
    cout << atoi(str2) << endl;  // 输出: 456
    cout << atoi(str3) << endl;  // 输出: 789
    return 0;
}
```

### stoi 函数
- **头文件**: `#include <string>`
- **函数原型**: `int stoi(const string& str, size_t* idx = 0, int base = 10)`
- **功能**: 将string对象转换为整数
- **参数**:
  - `str`: 要转换的字符串
  - `idx`: 可选，存储第一个未转换字符的位置
  - `base`: 可选，进制（2-36），默认为10
- **返回值**: 转换后的整数值
- **特点**:
  - 提供错误检查，转换失败会抛出异常
  - 支持不同进制转换
  - 更安全和现代化

**使用示例**:
```cpp
#include <string>
#include <iostream>
using namespace std;

int main() {
    string str1 = "123";
    string str2 = "1010";
    string str3 = "FF";
    
    try {
        cout << stoi(str1) << endl;        // 输出: 123
        cout << stoi(str2, 0, 2) << endl;  // 输出: 10 (二进制)
        cout << stoi(str3, 0, 16) << endl; // 输出: 255 (十六进制)
    } catch (const exception& e) {
        cout << "转换错误: " << e.what() << endl;
    }
    return 0;
}
```

### 主要区别
1. **参数类型**: atoi接受C风格字符串，stoi接受string对象
2. **错误处理**: atoi不提供错误检查，stoi会抛出异常
3. **进制支持**: atoi只支持十进制，stoi支持2-36进制
4. **安全性**: stoi更安全，推荐在现代C++中使用
5. **标准**: atoi来自C标准库，stoi是C++11引入的
