# C++ 自定义排序与运算符重载

在 C++ STL 中，`std::sort`、`std::priority_queue` 等容器或算法依赖比较规则来确定元素的顺序。对于基本数据类型（如 `int`, `double`），标准库已经定义好了规则；但对于自定义结构体或类，我们需要明确告诉编译器“谁大谁小”。

## 1. 标准库的默认行为

- **`std::sort`**: 默认是 **升序** (从小到大)。它默认使用 `std::less<T>`，底层依赖 `operator<`。
- **`std::priority_queue`**: 默认是 **大顶堆** (最大的在堆顶)。它默认使用 `std::less<T>`。

| 比较器 | 对应运算符 | sort 效果 | priority_queue 效果 |
| :--- | :--- | :--- | :--- |
| `std::less<T>` (默认) | `operator<` | 升序 (1, 2, 3) | 大顶堆 (Top 是最大值) |
| `std::greater<T>` | `operator>` | 降序 (3, 2, 1) | 小顶堆 (Top 是最小值) |

## 2. 自定义结构体的排序

假设有一个 `Car` 结构体：

```cpp
struct Car {
    int pos;
    int speed;
    Car(int p, int s) : pos(p), speed(s) {}
};
```

### 方法一：重载运算符 (Operator Overloading)

这是最“正统”的方法，将比较逻辑封装在类内部。

#### 场景 A：支持默认排序 (升序)
如果想直接使用 `sort(v.begin(), v.end())`，必须重载 `operator<`。

```cpp
struct Car {
    int pos;
    // ... 构造函数 ...

    // const 修饰符非常重要！
    // 这里的逻辑是：pos 小的 Car 被认为是“更小”的
    bool operator<(const Car& other) const {
        return pos < other.pos;
    }
};
```

#### 场景 B：支持 `greater` 排序 (降序)
如果想使用 `sort(v.begin(), v.end(), greater<Car>())`，必须重载 `operator>`。

```cpp
struct Car {
    int pos;
    // ...

    // 逻辑：pos 大的 Car 被认为是“更大”的
    bool operator>(const Car& other) const {
        return pos > other.pos;
    }
};
```

### 方法二：Lambda 表达式 (推荐)

在算法竞赛或刷题中，为了代码简洁，通常**不需要**在结构体里重载运算符，而是直接在 `sort` 时传入一个 Lambda 函数。

```cpp
vector<Car> v;
// ... 填充数据 ...

// 按 pos 升序 (从小到大)
sort(v.begin(), v.end(), [](const Car& a, const Car& b) {
    return a.pos < b.pos;
});

// 按 pos 降序 (从大到小)
sort(v.begin(), v.end(), [](const Car& a, const Car& b) {
    return a.pos > b.pos;
});
```

### 方法三：自定义仿函数 (Functor)

这类似于 `std::greater` 的实现原理。

```cpp
struct CompareCar {
    bool operator()(const Car& a, const Car& b) {
        return a.pos > b.pos; // 降序
    }
};

// 使用
sort(v.begin(), v.end(), CompareCar());
```

## 3. 常见陷阱

1.  **const correctness**: 重载运算符时，务必在函数末尾加上 `const`，且参数也是 `const` 引用。因为 STL 算法通常通过 const 引用来访问元素。
    - ✅ `bool operator<(const Car& other) const { ... }`
    - ❌ `bool operator<(Car other) { ... }`
2.  **严格弱序 (Strict Weak Ordering)**:
    - 比较函数必须保证：如果 `a < b` 为真，则 `b < a` 必须为假。
    - **千万不要**写 `return a.pos <= b.pos;`（带等号），这在元素相等时会导致死循环或运行时错误！标准库要求遇到相等元素返回 `false`。

## 4. 总结

- 想简单快速？用 **Lambda**。
- 想让结构体本身具有可比性？重载 **`operator<`**。
- 想配合 `greater<T>` 使用？重载 **`operator>`**。
