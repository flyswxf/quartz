# 事件的关系与运算

在概率论中，随机试验的每一个可能结果称为**样本点**，所有样本点组成的集合称为**样本空间**（记为 $\Omega$ 或 $S$）。**随机事件**（简称事件）是样本空间的子集。

## 1. 事件的基本关系

假设 $A, B$ 是同一个样本空间 $\Omega$ 中的两个事件：

- **包含关系 ($A \subset B$)**：
  若事件 $A$ 发生，则事件 $B$ 必然发生。
- **相等关系 ($A = B$)**：
  若 $A \subset B$ 且 $B \subset A$，则事件 $A$ 与 $B$ 相等。
- **互斥/互不相容 ($A \cap B = \emptyset$)**：
  事件 $A$ 与 $B$ 不能同时发生。
- **对立/互逆事件 ($A \cup B = \Omega$ 且 $A \cap B = \emptyset$)**：
  事件 $A$ 与 $B$ 有且仅有一个发生。记 $A$ 的对立事件为 $\bar{A}$ 或 $A^c$。
  *注意：对立事件必然互斥，但互斥事件不一定对立。*
- **独立事件**：
  事件 $A$ 的发生与否不影响事件 $B$ 发生的概率，即 $P(AB) = P(A)P(B)$。
  *注意：互斥是集合关系，独立是概率关系。若 $P(A)>0, P(B)>0$，互斥事件绝对不可能独立。* ^c34425

## 2. 事件的运算

事件的运算完全对应于集合的运算：

- **和事件 ($A \cup B$ 或 $A + B$)**：
  事件 $A$ 与 $B$ 中至少有一个发生。
- **积事件 ($A \cap B$ 或 $AB$)**：
  事件 $A$ 与 $B$ 同时发生。
- **差事件 ($A - B$)**：
  事件 $A$ 发生且事件 $B$ 不发生。等价于 $A \cap \bar{B}$ 或 $A - AB$。

## 3. 运算定律

事件的运算满足以下定律（与集合论一致）：

1. **交换律**：
   $A \cup B = B \cup A$
   $AB = BA$
2. **结合律**：
   $(A \cup B) \cup C = A \cup (B \cup C)$
   $(AB)C = A(BC)$
3. **分配律**：
   $A \cup (BC) = (A \cup B) \cap (A \cup C)$
   $A(B \cup C) = (AB) \cup (AC)$
4. **德·摩根定律 (De Morgan's laws) / 对偶律**：
   $$ \overline{A \cup B} = \bar{A} \cap \bar{B} $$
   $$ \overline{A \cap B} = \bar{A} \cup \bar{B} $$
   *(口诀：长杠变短杠，开口换方向)*
