## 核心思想与适用场景
- 分治：将数组二分递归排序，再线性时间合并两个有序子数组。
- **稳定排序**；在需要稳定性且可接受线性辅助空间时表现优良。

## 算法步骤
1. 若区间长度 ≤ 1，返回。
2. 取中点 `mid`，递归排序 `[l..mid]` 与 `[mid+1..r]`。
3. 使用辅助数组按序合并两个有序部分，写回原数组。

## 伪代码
```text
MergeSort(A, l, r):
  if r - l + 1 <= 1: return
  mid = (l + r) // 2
  MergeSort(A, l, mid)
  MergeSort(A, mid+1, r)
  Merge(A, l, mid, r)

Merge(A, l, mid, r):
  create temp array T of length (r - l + 1)  // 使用额外空间
  i <- l; j <- mid+1
  while i <= mid and j <= r:
    if A[i] <= A[j]: append A[i] to T; i++
    else: append A[j] to T; j++
  append remaining A[i..mid] to T
  append remaining A[j..r] to T
  copy T back to A[l..r]
```

## 复杂度分析
- 设递归式为：$$T(n) = 2\,T(n/2) + \Theta(n)$$
	- 其中, 每次划分将问题规模分解到原来的一般; 合并已排完序的两数组执行线性时间
- 由主定理或展开可得：$$T(n) = \Theta(n\log n)$$（平均、最坏、最好均为该量级）。
- 空间复杂度：合并需辅助数组，$$S(n)=\Theta(n)$$
