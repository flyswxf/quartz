> [!summary] 一眼看懂
> 选一个枢轴（pivot），原地把小于它的放左边、大于它的放右边；递归排序两边。平均时间 O(n log n)，空间 O(log n)。不稳定。
## 核心流程
- 选枢轴：随机或“三数取中”更稳健。
	- 变式: RANDOMIZED-QUICKSORT
		- 随机选择pivot
- 分区：把数组按枢轴划成左右两部分。
- 递归：分别排序左、右子数组。

## 直观示意
`[小于 pivot] | pivot | [大于 pivot]` → 对左右再做同样的事。

## 代码示例（Hoare 分区，简洁稳健）
```python
def quicksort(a, l, r):
    if l >= r:
        return
    p = partition(a, l, r)  # Hoare 分区，返回右边界 j
    quicksort(a, l, p)
    quicksort(a, p + 1, r)

def partition(a, l, r):
    pivot = a[(l + r) // 2]
    i, j = l, r
    while True:
        while a[i] < pivot: i += 1
        while a[j] > pivot: j -= 1
        if i >= j:
            return j
        a[i], a[j] = a[j], a[i]
        i += 1
        j -= 1
```

## 复杂度与特性
- 平均/期望：`O(n log n)`；最坏：`O(n^2)`（枢轴极不均匀）
- 空间：`O(log n)`（递归栈，经过尾递归优化更小）
- 原地：是；稳定性：否（相等元素次序可能改变）

## 适用与对比
- 适用：通用快速原地排序，实践中常为首选。
- 对比：
  - [[归并排序]]：稳定、最坏 `O(n log n)`，但需 `O(n)` 额外空间。
  - [[堆排序]]：原地、最坏 `O(n log n)`，常数较大、一般比快排慢。
