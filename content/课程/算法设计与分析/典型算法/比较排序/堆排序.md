## 核心概念
- 堆：一种基于数组的完全二叉树结构。
- 最大堆：任一结点的值不小于其子结点；用于升序排序。
- 最小堆：任一结点的值不大于其子结点；用于降序排序。
- 0 基下标的数组表示：
  - 父结点：$parent(i) = \left\lfloor\frac{i - 1}{2}\right\rfloor$
  - 左孩子：$left(i) = 2i + 1$
  - 右孩子：$right(i) = 2i + 2$

## 算法步骤（升序）
1) 用待排序数组[[堆排序#^cc2658|构建最大堆（自底向上的下滤/堆化）]]
2) 交换堆顶与当前堆的最后一个元素，将堆规模减 1。
3) 对新的堆顶执行[[堆排序#^ade98a|下滤]]，恢复最大堆性质。
4) 重复步骤 23，直到堆大小为 1。

**时间与空间复杂度**

| 项目       | 复杂度          | 说明               |
| -------- | ------------ | ---------------- |
| 建堆       | $O(n)$       | 自底向上堆化，按高度求和     |
| 下滤       | $O(\log n)$   |                  |
| 排序       | $O(n\log n)$ | 每次取堆顶并下滤 $\log n$ |
| 总时间      | $O(n\log n)$ | 额外空间 $O(1)$（就地）  |
| 稳定性      | 不稳定          | 相等元素相对次序可能改变     |
| 最好/平均/最坏 | $O(n\log n)$ | 最坏情况也有上界保证       |

## 复杂度详细说明

### 建堆 $O(n)$（自底向上）
- 记高度为 $h$ 的结点执行一次下滤的代价为 $\Theta(h)$；高度 $h$ 的结点最多约为 $\left\lceil\dfrac{n}{2^{h+1}}\right\rceil$ 个。
- 总成本上界：
$$
\sum_{h=0}^{\lfloor \log_2 n \rfloor} \frac{n}{2^{h+1}}\,\Theta(h)
\;\le\; n \sum_{h=0}^{\infty} \frac{h}{2^{h+1}}
\;=\; n\cdot 1
\;=\; \Theta(n)
$$
- 由此建堆整体时间复杂度为 $$\Theta(n)$$

### 下滤（sift-down / heapify）$O(\log n)$
- 高度界：完全二叉树高度为 $\lfloor\log_2 n\rfloor$，每次比较/交换为常数开销，因此 $$T(n)=\Theta(\log n)$$
- 更严格的递推上界：最坏情况下，交换后继续下滤的子堆规模不超过 $\tfrac{2}{3}n$，于是
$$
T(n) \le T\!\left(\tfrac{2}{3}n\right) + \Theta(1)
$$
由[[主定理]]Case 2可得 $$T(n)=\Theta(\log n)$$

### 总排序 $O(n\log n)$
- 建堆：$$\Theta(n)$$
- 提取堆顶并下滤共 $n-1$ 次：第 $m$ 次在大小约为 $m$ 的堆中开销为 $\Theta(\log m)$，总和为
$$
\sum_{m=2}^{n} \Theta(\log m)
\;=\; \Theta\!\left(\sum_{m=2}^{n} \log m\right)
\;=\; \Theta(n\log n)
$$
可用积分界证明：$\sum_{m=2}^{n} \log m \le \int_{1}^{n} \log x\,dx = n\log n - n + 1$。
- 合并得到总时间复杂度：$$T(n)=\Theta(n) + \Theta(n\log n) = \Theta(n\log n)$$

## C++ 示例：迭代版堆排序（升序）
#### 下滤（sift-down / heapify）

^ade98a

- 目标：将索引 `i` 的元素向下移动到合适位置，使以 `i` 为根的子树满足堆性质。
- 迭代实现避免深递归：从当前结点与左右孩子中选择更大者交换，直到越界或不用交换。
```cpp
static void siftDown(std::vector<int>& a, int i, int n) {
    // n 为当前堆大小（开区间 [0, n)）
    while (true) {
        int l = i * 2 + 1;
        int r = l + 1;
        int largest = i;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest == i) break;           // 已满足最大堆
        std::swap(a[i], a[largest]);
        i = largest;                        // 继续向下
    }
}
```
### 构建最大堆（Build-Heap）

^cc2658

- 最后一个非叶子结点索引：`n/2 - 1`（0 基下标）。
- 从 `n/2 - 1` 到 `0` 依次下滤即可在 `O(n)` 时间完成建堆。
```cpp
static void buildMaxHeap(std::vector<int>& a) {
    for (int i = (int)a.size() / 2 - 1; i >= 0; --i) {
        siftDown(a, i, (int)a.size());
    }
}
```
### 堆排序
- **end不会遍历到0**, 因为没必要
```cpp
void heapSort(std::vector<int>& a) {
    int n = (int)a.size();
    buildMaxHeap(a);
    for (int end = n - 1; end > 0; --end) {
        std::swap(a[0], a[end]);           // 将堆顶最大值放到末尾
        siftDown(a, 0, end);               // 在缩小的堆中恢复堆性质
    }
}

// 使用示例
// std::vector<int> v{2, 3, 8, 6, 1};
// heapSort(v); // 结果：1 2 3 6 8
```

**使用 STL 的方式**
- `std::make_heap` 构建堆，`std::sort_heap` 完成排序（默认最大堆，升序）：
```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> a{2, 3, 8, 6, 1};
    std::make_heap(a.begin(), a.end());  // 构建最大堆
    std::sort_heap(a.begin(), a.end());  // 升序排序
}
```
- 降序排序：传入比较器，构建最小堆或对结果反向输出。

**适用与对比**
- 适用：需要就地且最坏时间受控的排序；内存紧张场景。
- 对比：
  - 快速排序：平均常数因子小、缓存友好，通常更快，但最坏 `O(n^2)`（有随机化可缓解）。
  - 归并排序：稳定、`O(n log n)`，但需要 `O(n)` 额外空间。
  - 堆排序：最坏也为 `O(n log n)`，就地但不稳定，常数因子略大。

**扩展：Top-K（选前 K 大/小）**
- 用大小为 `K` 的堆维护候选：
  - 取前 K 大：维护最小堆，遇到更大的替换堆顶；复杂度 `O(n log K)`。
  - 取前 K 小：维护最大堆，原理相同。
