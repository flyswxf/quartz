## 核心思想与适用场景
- 对有限且较小的整数键（值域大小为 `k`）统计出现次数，并通过前缀和确定每个元素在输出中的最终位置。
- 适用于键值分布在已知区间（如 `[0, k-1]`），当 `k` 与 `n` 同量级时拥有近线性时间。

## 算法步骤
1. 设输入数组 `A` 长度 `n`，键值范围大小为 `k`。
2. 建计数数组 `C[0..k-1]`，初始化为 `0`，统计每个键出现次数。
3. 对 `C` 做前缀和：`C[i] = C[i] + C[i-1]`，得到每个键的尾端位置。
4. **逆序扫描 `A`**，将元素稳定地放入输出数组 `B`：`B[ C[key]-1 ] = x; C[key]--`。
5. 将 `B` 写回或直接返回。

## 伪代码
```text
CountingSort(A, k):
  C[0..k-1] <- 0
  for x in A:
    C[key(x)]++

  // 前缀和
  for i in 1..k-1:
    C[i] <- C[i] + C[i-1]

  B[0..n-1]
  for x in A (从右到左):
    i <- key(x)
    pos <- C[i] - 1
    B[pos] <- x
    C[i] <- C[i] - 1

  return B
```

## 复杂度分析
- 计数与前缀和阶段：$\Theta(k)$。
- 分配阶段（稳定写入）：$\Theta(n)$。
- 总时间复杂度：
$$
T(n) = \Theta(n + k)
$$
- 空间复杂度：输出数组与计数数组共 $\Theta(n + k)$。

## 稳定性与注意事项
- **逆序扫描并使用前缀位置递减可保证稳定性（相同键的相对次序保持）。**
- 键值不从零开始或存在负数时，可做偏移映射：`key'(x) = key(x) - minKey`。
- 当 $k \gg n$ 时会造成空间与时间浪费，应考虑改用桶排序或基数排序等。
