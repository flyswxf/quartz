最短路径问题是图论中的经典问题，旨在寻找图中两点之间权重之和最小的路径。常见的算法包括适用于非负权图的 Dijkstra 算法和适用于带负权图的 Bellman-Ford 算法。

## 基础概念与符号

在计算单源最短路径时，大多数算法都会维护以下属性：

### 1. 顶点属性
对于图中的每个顶点 $v \in V$，我们需要维护：
*   **$v.d$ (Shortest-path estimate)**: 从源点 $s$ 到顶点 $v$ 的最短路径估计值。
    *   初始时，$v.d = \infty$。
    *   随着算法的进行，$v.d$ 会不断减小，直到收敛于实际的最短路径距离 $\delta(s, v)$。
*   **$v.\pi$ (Predecessor)**: 在从源点 $s$ 到顶点 $v$ 的最短路径上，$v$ 的前驱节点。
    *   用于在算法结束后回溯重建最短路径。

### 2. 初始化 (Initialization)
所有单源最短路径算法开始时都会进行初始化：
```python
INITIALIZE-SINGLE-SOURCE(G, s)
    for each vertex v in G.V
        v.d = infinity
        v.pi = NIL
    s.d = 0
```

### 3. 松弛操作 (Relaxation)
**松弛**一条边 $(u, v)$ 是指检查是否可以通过顶点 $u$ 找到一条到达顶点 $v$ 的更短路径。
如果 $v.d > u.d + w(u, v)$，则更新 $v.d$ 和 $v.\pi$。

**伪代码**:
```python
RELAX(u, v, w)
    if v.d > u.d + w(u, v)
        v.d = u.d + w(u, v)
        v.pi = u
```
*   **性质**: 松弛操作后，必然满足 $v.d \le u.d + w(u, v)$。
*   不同的最短路径算法（如 Dijkstra, Bellman-Ford）的区别主要在于**松弛边的顺序**和**松弛次数**。

## 最短路径的性质

### 最短路径树 (Shortest-Paths Tree)
给定带权有向图 $G = (V, E)$ 和源点 $s$，如果图 $G$ 中不包含从 $s$ 可达的负权回路，则最短路径树是一棵有根树，该树包含了从源点 $s$ 到所有可达顶点的最短路径。
最短路径树由 $v.\pi$ 属性定义：$G_{\pi} = (V_{\pi}, E_{\pi})$，其中 $V_{\pi} = \{v \in V \mid v.\pi \neq \text{NIL}\} \cup \{s\}$，$E_{\pi} = \{(v.\pi, v) \in E \mid v \in V_{\pi} \setminus \{s\}\}$。

**最短路径树的性质**：
1.  **三角形不等式 (Triangle Inequality)**：对于任意边 $(u, v) \in E$，有 $\delta(s, v) \le \delta(s, u) + w(u, v)$。
2.  **上界性质 (Upper-bound Property)**：对于所有顶点 $v \in V$，始终有 $v.d \ge \delta(s, v)$。一旦 $v.d$ 收敛到 $\delta(s, v)$，它将不再改变。
3.  **无路径性质 (No-path Property)**：如果从 $s$ 到 $v$ 不存在路径，则始终有 $v.d = \delta(s, v) = \infty$。
4.  **收敛性质 (Convergence Property)**：如果 $s \rightsquigarrow u \rightarrow v$ 是一条最短路径，且在某时刻 $u.d = \delta(s, u)$，则在对边 $(u, v)$ 进行松弛后，必有 $v.d = \delta(s, v)$。
5.  **路径松弛性质 (Path-relaxation Property)**：如果 $p = \langle v_0, v_1, \dots, v_k \rangle$ 是从 $s=v_0$ 到 $v_k$ 的最短路径，并且我们按照 $(v_0, v_1), (v_1, v_2), \dots, (v_{k-1}, v_k)$ 的顺序对边进行松弛，则 $v_k.d = \delta(s, v_k)$。这个性质独立于其他边的松弛操作，只要该序列的边被按顺序松弛即可。
6.  **前驱子图性质 (Predecessor-subgraph Property)**：一旦对于所有 $v \in V$，有 $v.d = \delta(s, v)$，则前驱子图是一棵根节点为 $s$ 的最短路径树。

### 最优子结构 (Optimal Substructure)
给定带权有向图 $G = (V, E)$ 和权重函数 $w : E \rightarrow \mathbb{R}$。设 $p = \langle v_0, v_1, \dots, v_k \rangle$ 是从顶点 $v_0$ 到顶点 $v_k$ 的一条最短路径。对于任意 $i$ 和 $j$ ($0 \le i \le j \le k$)，设 $p_{ij} = \langle v_i, v_{i+1}, \dots, v_j \rangle$ 为路径 $p$ 中从顶点 $v_i$ 到顶点 $v_j$ 的子路径。那么，$p_{ij}$ 是从 $v_i$ 到 $v_j$ 的一条最短路径。

#### 证明：
我们将路径 $p$ 分解为 $v_0 \xrightarrow{p_{0i}} v_i \xrightarrow{p_{ij}} v_j \xrightarrow{p_{jk}} v_k$，则路径 $p$ 的权重为 $w(p) = w(p_{0i}) + w(p_{ij}) + w(p_{jk})$。
假设存在一条从 $v_i$ 到 $v_j$ 的路径 $p'_{ij}$，其权重 $w(p'_{ij}) < w(p_{ij})$。
那么，我们可以构造一条从 $v_0$ 到 $v_k$ 的新路径 $v_0 \xrightarrow{p_{0i}} v_i \xrightarrow{p'_{ij}} v_j \xrightarrow{p_{jk}} v_k$，该路径的权重为 $w(p_{0i}) + w(p'_{ij}) + w(p_{jk})$。
由于 $w(p'_{ij}) < w(p_{ij})$，所以新路径的权重严格小于 $w(p)$。这与 $p$ 是从 $v_0$ 到 $v_k$ 的最短路径的假设相矛盾。
因此，$p_{ij}$ 必须是从 $v_i$ 到 $v_j$ 的最短路径。

## Dijkstra 算法

**Dijkstra 算法**是一种用于计算**单源最短路径**的贪心算法。它适用于**权重非负**的有向图或无向图。

### 1. 基本思想
算法维护一个集合 $S$，包含已经找到最短路径的顶点。初始时，$S$ 仅包含源点。
在每一步中，从不在 $S$ 中的顶点集合 $V-S$ 中选择一个距离源点最近的顶点 $u$，将其加入 $S$，并利用 $u$ 更新其邻接顶点 $v$ 的距离（松弛操作）。

### 2. 算法步骤
1.  **初始化**：
    *   `dist` 数组：`dist[s] = 0`，其他顶点 `dist[v] = ∞`。
    *   `visited` 集合：初始为空（或布尔数组全是 False）。
    *   优先队列：将 `(0, s)` 加入队列。
2.  **循环**：
    *   从未访问的顶点中选择 `dist` 值最小的顶点 $u$。
    *   标记 $u$ 为已访问。
    *   **松弛 (Relaxation)**：遍历 $u$ 的所有邻居 $v$。如果 `dist[u] + weight(u, v) < dist[v]`，则更新 `dist[v] = dist[u] + weight(u, v)`。
3.  重复上述步骤，直到所有顶点都被访问或队列为空。

### 3. 代码示例

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <limits>

using namespace std;

const int INF = numeric_limits<int>::max();

struct Edge {
    int to;
    int weight;
};

// Dijkstra 算法
void dijkstra(int start, int V, const vector<vector<Edge>>& adj) {
    vector<int> dist(V, INF);
    dist[start] = 0;

    // 优先队列，存储 {distance, vertex}，小顶堆
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
    pq.push({0, start});

    while (!pq.empty()) {
        int d = pq.top().first;
        int u = pq.top().second;
        pq.pop();

        if (d > dist[u]) continue;

        for (const auto& edge : adj[u]) {
            int v = edge.to;
            int weight = edge.weight;

            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({dist[v], v});
            }
        }
    }

    // 输出结果
    for (int i = 0; i < V; ++i) {
        if (dist[i] == INF) cout << "Node " << i << ": INF" << endl;
        else cout << "Node " << i << ": " << dist[i] << endl;
    }
}

int main() {
    int V = 4; // 节点数 0, 1, 2, 3 对应 A, B, C, D
    vector<vector<Edge>> adj(V);

    // 构建图 A=0, B=1, C=2, D=3
    adj[0].push_back({1, 1}); // A->B
    adj[0].push_back({2, 4}); // A->C
    adj[1].push_back({0, 1}); // B->A
    adj[1].push_back({2, 2}); // B->C
    adj[1].push_back({3, 5}); // B->D
    adj[2].push_back({0, 4}); // C->A
    adj[2].push_back({1, 2}); // C->B
    adj[2].push_back({3, 1}); // C->D
    adj[3].push_back({1, 5}); // D->B
    adj[3].push_back({2, 1}); // D->C

    dijkstra(0, V, adj);
    return 0;
}
```

### 4. 时间复杂度
*   **朴素实现** (使用数组): $O(V^2)$
*   **二叉堆优化**: $O((V+E)\log V)$ 或 $O(E \log V)$ (对于连通图)
*   **斐波那契堆优化**: $O(E + V \log V)$

## Bellman-Ford 算法

**Bellman-Ford 算法**也是一种计算**单源最短路径**的算法。与 Dijkstra 不同，它可以处理**带有负权边**的图，并且能够检测图中是否存在**负权环**。

![[assets/负权有向图.png]]

### 1. 基本思想
Bellman-Ford 算法基于动态规划（或迭代松弛）。它对图中的所有边进行 $V-1$ 轮松弛操作。
原理是：在一个包含 $V$ 个顶点的图中，任意两点间的最短路径最多包含 $V-1$ 条边。

### 2. 算法步骤
1.  **初始化**：`dist[s] = 0`，其他 `dist[v] = ∞`。
2.  **松弛操作**：
    *   进行 $V-1$ 次循环。
    *   在每次循环中，遍历图中的**每一条边** $(u, v)$ 及其权重 $w$。
    *   如果 `dist[u] + w < dist[v]`，则更新 `dist[v] = dist[u] + w`。
3.  **检测负权环**：
    *   再遍历一次所有边。
    *   如果仍存在边 $(u, v)$ 使得 `dist[u] + w < dist[v]`，则说明图中存在从源点可达的负权环。

### 3. 代码示例

```cpp
#include <iostream>
#include <vector>

using namespace std;

const int INF = 1e9;

struct Edge {
    int u, v, weight;
};

// Bellman-Ford 算法
bool bellman_ford(int start, int V, int E, const vector<Edge>& edges, vector<int>& dist) {
    dist.assign(V, INF);
    dist[start] = 0;

    // 松弛 V-1 次
    for (int i = 0; i < V - 1; ++i) {
        bool changed = false;
        for (const auto& edge : edges) {
            if (dist[edge.u] != INF && dist[edge.u] + edge.weight < dist[edge.v]) {
                dist[edge.v] = dist[edge.u] + edge.weight;
                changed = true;
            }
        }
        if (!changed) break; 
    }

    // 检测负权环
    for (const auto& edge : edges) {
        if (dist[edge.u] != INF && dist[edge.u] + edge.weight < dist[edge.v]) {
            return true; // 存在负权环
        }
    }

    return false;
}

int main() {
    // S=0, E=1, D=2, A=3, C=4, B=5
    int V = 6;
    vector<Edge> edges = {
        {0, 1, 8}, {0, 3, 10}, // S->E, S->A
        {1, 2, 1},             // E->D
        {2, 3, -4}, {2, 4, -1},// D->A, D->C
        {3, 4, 2},             // A->C
        {4, 5, -2},            // C->B
        {5, 3, 1}              // B->A
    };

    vector<int> dist;
    if (bellman_ford(0, V, edges.size(), edges, dist)) {
        cout << "Graph contains negative weight cycle" << endl;
    } else {
        cout << "Vertex Distances from Source" << endl;
        for (int i = 0; i < V; ++i)
            cout << i << "\t\t" << dist[i] << endl;
    }
    return 0;
}
```

### 4. 时间复杂度
*   $O(V \cdot E)$
*   通常比 Dijkstra 慢，但在有负权边的情况下是必须的。

## 总结对比

| 特性           | Dijkstra               | Bellman-Ford        |
| :------------- | :--------------------- | :------------------ |
| **适用图**     | 非负权图               | 任意权图 (可含负权) |
| **负权环检测** | 无法检测               | 可以检测            |
| **核心思想**   | 贪心 (Greedy)          | 动态规划 / 迭代松弛 |
| **时间复杂度** | $O(E \log V)$ (堆优化) | $O(VE)$             |
| **效率**       | 较高                   | 较低                |
