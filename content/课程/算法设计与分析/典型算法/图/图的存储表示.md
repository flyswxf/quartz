# 图的存储结构 (Graph Storage Structures)

图的存储结构主要有两种：邻接矩阵和邻接表。选择哪种结构取决于图是稠密图还是稀疏图，以及需要进行的操作。

## 1. 邻接矩阵 (Adjacency Matrix)
使用一个二维数组 `A[V][V]` 来表示图。
- 若 $(i, j) \in E$，则 `A[i][j] = 1` (或边的权值)。
- 否则 `A[i][j] = 0` (或 $\infty$)。

### 1.1 空间复杂度
- **空间需求**: $O(V^2)$。
- **适用性**: 适用于 **稠密图** ($|E| \approx |V|^2$)。

### 1.2 特性与示例
- **无向图的对称性**: 无向图的邻接矩阵是关于主对角线对称的。
- **无自环**: 如果图没有自环 (self-loops)，则对角线元素全为 0。

> **问题**: 一个包含 4 个顶点的无向图（无自环），其邻接矩阵表示最少需要多少存储空间？
> **答案**: **6 bits**。
> - **原因**: 
>   1. 无向图矩阵是对称的，只需要存储上三角或下三角部分。
>   2. 无自环，不需要存储对角线。
>   3. 4 个顶点，需要的存储位数为 $V(V-1)/2 = 4 \times 3 / 2 = 6$。

## 2. 邻接表 (Adjacency List)
使用数组 + 链表的方式存储。每个顶点 $v$ 都有一个链表，链表中包含所有与 $v$ 相邻的顶点。

### 2.1 空间复杂度
- **空间需求**: $\Theta(V + E)$。
- **适用性**: 适用于 **稀疏图** ($|E| \approx |V|$)。

### 2.2 度 (Degree) 与 握手引理 (Handshaking Lemma)
顶点的度 (Degree) 定义为与该顶点相连的边的数量。

- **有向图**:
  - **出度 (Out-degree)**: 从该顶点出发的边数。
  - **入度 (In-degree)**: 指向该顶点的边数。
  - **性质**: 邻接表中链表节点的总数等于所有顶点的出度之和，即等于边数 $|E|$。
    - $\sum \text{out-degree}(v) = |E|$

- **无向图**:
  - **度 (Degree)**: 与该顶点相连的边数。
  - **握手引理 (Handshaking Lemma)**: 所有顶点的度之和等于边数的 2 倍。
    - $\sum \text{degree}(v) = 2|E|$
  - **性质**: 邻接表中链表节点的总数等于 $2|E|$。

### 3. 总结与比较

| 特性 | 邻接矩阵 (Adjacency Matrix) | 邻接表 (Adjacency List) |
| :--- | :--- | :--- |
| **空间复杂度** | $O(V^2)$ | $O(V + E)$ |
| **适用场景** | 稠密图 | 稀疏图 |
| **判断边 (u, v) 是否存在** | $O(1)$ | $O(\text{degree}(u))$ |
| **遍历所有边** | $O(V^2)$ | $O(V + E)$ |
