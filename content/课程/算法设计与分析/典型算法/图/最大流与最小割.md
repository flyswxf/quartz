## 1. 基本概念
- **网络 (Network)**: 一个有向图 $G=(V, E)$，其中每条边 $(u, v) \in E$ 都有一个非负容量 $c(u, v) \ge 0$。
- **源点 (Source, $s$)** 和 **汇点 (Sink, $t$)**: 网络中有两个特殊节点，源点 $s$ 只有流出没有流入（入度为0），汇点 $t$ 只有流入没有流出（出度为0）。
- **流 (Flow)**: 一个函数 $f: V \times V \to \mathbb{R}$，满足：
    1.  **容量限制 (Capacity Constraint)**: $\forall u, v \in V, 0 \le f(u, v) \le c(u, v)$。
    2.  **流量守恒 (Flow Conservation)**: $\forall u \in V - \{s, t\}, \sum_{v \in V} f(v, u) = \sum_{v \in V} f(u, v)$ (流入等于流出)。
    3.  **反对称性 (Skew Symmetry)**: $f(u, v) = -f(v, u)$ (通常在某些定义中使用，但在算法实现中常用非负流表示)。
- **流的值 (Value of Flow)**: $|f| = \sum_{v \in V} f(s, v)$，即从源点出发的总流量。

## 2. 最大流问题 (Maximum Flow Problem)
在给定的网络中，找到一个流 $f$，使得流的值 $|f|$ 最大。

## 3. 最小割问题 (Minimum Cut Problem)
- **割 (Cut)**: 将节点集合 $V$ 划分为两个不相交的集合 $(S, T)$，其中 $s \in S, t \in T$。
- **割的容量 (Capacity of Cut)**: $C(S, T) = \sum_{u \in S, v \in T} c(u, v)$。即所有从 $S$ 指向 $T$ 的边的容量之和。
- **最小割**: 找到一个割 $(S, T)$，使得其容量 $C(S, T)$ 最小。

## 4. 最大流最小割定理 (Max-Flow Min-Cut Theorem)
**定理**: 一个网络中的最大流的值等于该网络中最小割的容量。
即：$|f_{max}| = C_{min}(S, T)$。

这意味着：
1.  任意流的值 $\le$ 任意割的容量。
2.  最大流的值 = 最小割的容量。

## 5. 常用算法

### 5.1 Ford-Fulkerson 方法
这不是一个具体的算法，而是一类算法的通称。
- **核心思想**: 不断在**残留网络 (Residual Graph)** 中寻找**增广路径 (Augmenting Path)**，并增加流的值，直到找不到增广路径为止。
- **残留网络 $G_f$**:
    - 对于边 $(u, v)$，如果 $f(u, v) < c(u, v)$，则存在残留容量 $c_f(u, v) = c(u, v) - f(u, v)$。
    - 如果 $f(u, v) > 0$，则存在反向边 $(v, u)$，容量为 $f(u, v)$（用于“反悔”或撤销流量）。
- **增广路径**: 在残留网络中从 $s$ 到 $t$ 的一条简单路径。

### 5.2 Edmonds-Karp 算法
Ford-Fulkerson 的具体实现，使用 **BFS (广度优先搜索)** 来寻找增广路径。
- **特点**: 总是寻找边数最少的增广路径。
- **时间复杂度**: $O(V E^2)$。

### 5.3 Dinic 算法
目前常用的高效最大流算法。
- **核心思想**:
    1.  在残留网络上通过 BFS 构造 **层次图 (Level Graph)**（只保留从层 $i$ 指向层 $i+1$ 的边）。
    2.  在层次图上通过 DFS 寻找 **阻塞流 (Blocking Flow)**（即多次增广直到无法在该层次图上找到更多路径）。
    3.  重复上述步骤直到 $s$ 和 $t$ 不连通。
- **时间复杂度**: $O(V^2 E)$。在二分图匹配中更优，为 $O(E\sqrt{V})$。
- **当前弧优化**: 在 DFS 过程中记录每个节点处理到的边的位置，避免重复遍历已经满流的边。

## 6. 代码模板 (Dinic - C++)

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <cstring>

using namespace std;

const long long INF = 1e18;

struct Edge {
    int to;
    long long cap; // 容量
    int rev;       // 反向边在邻接表中的下标
};

vector<vector<Edge>> adj;
vector<int> level;
vector<int> ptr; // 当前弧优化

void add_edge(int from, int to, long long cap) {
    adj[from].push_back({to, cap, (int)adj[to].size()});
    adj[to].push_back({from, 0, (int)adj[from].size() - 1});
}

// BFS 建立层次图
bool bfs(int s, int t) {
    fill(level.begin(), level.end(), -1);
    level[s] = 0;
    queue<int> q;
    q.push(s);
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (auto& edge : adj[v]) {
            if (edge.cap > 0 && level[edge.to] == -1) {
                level[edge.to] = level[v] + 1;
                q.push(edge.to);
            }
        }
    }
    return level[t] != -1;
}

// DFS 寻找增广路
long long dfs(int v, int t, long long pushed) {
    if (pushed == 0) return 0;
    if (v == t) return pushed;
    for (int& cid = ptr[v]; cid < adj[v].size(); ++cid) {
        auto& edge = adj[v][cid];
        int tr = edge.to;
        if (level[v] + 1 != level[tr] || edge.cap == 0) continue;
        long long tr_pushed = dfs(tr, t, min(pushed, edge.cap));
        if (tr_pushed == 0) continue;
        edge.cap -= tr_pushed;
        adj[tr][edge.rev].cap += tr_pushed;
        return tr_pushed;
    }
    return 0;
}

long long dinic(int s, int t) {
    long long flow = 0;
    while (bfs(s, t)) {
        fill(ptr.begin(), ptr.end(), 0);
        while (long long pushed = dfs(s, t, INF)) {
            flow += pushed;
        }
    }
    return flow;
}

int main() {
    int n, m, s, t;
    // 输入节点数 n, 边数 m, 源点 s, 汇点 t
    // 注意：根据题目要求调整输入
    cin >> n >> m >> s >> t;
    
    adj.resize(n + 1);
    level.resize(n + 1);
    ptr.resize(n + 1);

    for (int i = 0; i < m; ++i) {
        int u, v;
        long long c;
        cin >> u >> v >> c;
        add_edge(u, v, c);
    }

    cout << dinic(s, t) << endl;

    return 0;
}
```
