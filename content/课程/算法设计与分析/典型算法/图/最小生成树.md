## 1. 基本定义

在讨论最小生成树算法之前，我们需要明确几个核心概念：

### 最小生成树 (MST)
对于一个连通的、无向的、带权图 $G = (V, E)$，其最小生成树是一个子图，满足以下条件：
1.  **包含所有顶点**：子图包含图 $G$ 中的所有顶点 $V$。
2.  **连通且无环**：子图是一棵树（连通且没有回路）。
3.  **权重和最小**：子图中所有边的权重之和尽可能小。即寻找一个边集 $T \subseteq E$，使得 $w(T) = \sum_{(u,v) \in T} w(u,v)$ 最小。

### 切割 (Cut)
无向图 $G = (V, E)$ 的一个**切割** $(S, V-S)$ 是将顶点集合 $V$ 划分为两个不相交的集合 $S$ 和 $V-S$。
- 如果一条边 $(u, v) \in E$ 的一个端点在 $S$ 中，另一个端点在 $V-S$ 中，则称这条边**横跨** (cross) 该切割。

### 轻边 (Light Edge)
对于一个给定的切割，如果一条横跨该切割的边的权重是所有横跨该切割的边中最小的，则称这条边为该切割的**轻边**。
- **注意**：轻边可能不止一条（如果有几条边的权重相同且都是最小的）。
- **性质**：对于任意一个切割，其轻边一定属于某棵最小生成树。

## 2. Kruskal 算法 (克鲁斯卡尔算法)

### 算法思想
Kruskal 算法是一种基于**贪心策略**的算法。它的核心思想是“加边”：
1.  将图中所有的边按照权重**从小到大排序**。
2.  初始时，将每个顶点视为一棵独立的树（互不连通）。
3.  依次遍历排序后的边 $(u, v)$：
    - 如果 $u$ 和 $v$ 分别属于两棵不同的树（即它们当前不连通），则将这条边加入 MST，合并这两棵树。
    - 如果 $u$ 和 $v$ 已经在同一棵树中（即它们已经连通），则忽略这条边（否则会形成环）。
4.  重复上述过程，直到选中了 $|V|-1$ 条边，或者所有边都遍历完。

为了高效地判断两个点是否在同一棵树中以及合并两棵树，通常使用**并查集 (Union-Find)** 数据结构。

### 时间复杂度分析
假设图有 $V$ 个顶点，$E$ 条边。
1.  **排序**：使用比较排序（如快速排序或归并排序）对 $E$ 条边进行排序，时间复杂度为 **$O(E \lg E)$**。
2.  **并查集操作**：
    - 初始化并查集需要 $O(V)$ 时间。
    - 最多进行 $E$ 次 `find` 和 `union` 操作。使用路径压缩和按秩合并优化的并查集，每次操作的平均时间几乎是常数（准确说是反阿克曼函数 $\alpha(V)$）。总时间为 **$O(E \alpha(V))$**。
3.  **总复杂度**：由于通常 $E \ge V - 1$，且 $\alpha(V)$ 非常小，因此主导项是排序。
    - 总时间复杂度为 **$O(E \lg E)$**。
    - 也可以写成 $O(E \lg V)$，因为 $E < V^2 \implies \lg E < 2 \lg V$。

### C++ 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

using namespace std;

// 边的结构体
struct Edge {
    int u, v, weight;
    // 重载 < 运算符用于排序
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

// 并查集结构
struct DSU {
    vector<int> parent;
    DSU(int n) {
        parent.resize(n);
        // 初始化，每个节点的父节点是自己
        iota(parent.begin(), parent.end(), 0);
    }
    
    // 查找根节点（路径压缩）
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    // 合并两个集合
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;
            return true; // 合并成功
        }
        return false; // 已经在同一集合
    }
};

int kruskal(int n, vector<Edge>& edges) {
    // 1. 排序
    sort(edges.begin(), edges.end());
    
    DSU dsu(n);
    int mst_weight = 0;
    int edges_count = 0;
    
    // 2. 遍历边
    for (const auto& edge : edges) {
        if (dsu.unite(edge.u, edge.v)) {
            mst_weight += edge.weight;
            edges_count++;
        }
    }
    
    if (edges_count < n - 1) {
        cout << "图不连通，无法构成生成树" << endl;
        return -1;
    }
    
    return mst_weight;
}

int main() {
    int n = 4; // 顶点数 0, 1, 2, 3
    vector<Edge> edges = {
        {0, 1, 1},
        {1, 2, 2},
        {2, 3, 3},
        {0, 2, 4},
        {1, 3, 5}
    };
    
    cout << "Kruskal MST Weight: " << kruskal(n, edges) << endl;
    return 0;
}
```

## 3. Prim 算法 (普里姆算法)

### 算法思想
Prim 算法也是基于**贪心策略**，但它的核心思想是“加点”：
1.  维护一个集合 $S$，表示已经加入 MST 的顶点。初始时 $S$ 只包含一个起始顶点（例如顶点 0）。
2.  维护一个数组（或优先队列），记录 $S$ 之外的每个顶点到 $S$ 中任意顶点的**最小距离**（key 值）。
3.  重复以下步骤，直到 $S$ 包含所有顶点：
    - 从 $V-S$ 中选择一个 key 值最小的顶点 $u$。
    - 将 $u$ 加入 $S$。
    - 更新 $u$ 的所有邻接顶点 $v$ 的 key 值：如果边 $(u, v)$ 的权重小于 $v$ 当前的 key 值，则更新 $key[v] = w(u, v)$。

通常使用**优先队列 (Min-Heap)** 来快速获取 key 值最小的顶点。

### 时间复杂度分析
假设图有 $V$ 个顶点，$E$ 条边。
1.  **使用二叉堆 (Binary Heap) 实现优先队列**：
    - **初始化**：建堆 $O(V)$。
    - **Extract-Min**：每个顶点出队一次，共 $V$ 次。每次操作耗时 $O(\lg V)$。总共 $O(V \lg V)$。
    - **Decrease-Key**：每条边可能导致一次 key 更新。共 $E$ 次。每次操作（在堆中调整位置）耗时 $O(\lg V)$。总共 $O(E \lg V)$。
    - **总复杂度**：**$O(E \lg V)$**（因为通常 $E \ge V$）。

2.  **使用斐波那契堆 (Fibonacci Heap)**：
    - **Extract-Min**：共执行 $V$ 次，每次摊还复杂度 $O(\lg V)$，总计 $O(V \lg V)$。
    - **Decrease-Key**：共执行 $E$ 次，每次摊还复杂度 $O(1)$，总计 $O(E)$。
    - **总复杂度**：**$O(E + V \lg V)$**。
    - **对比**：相比二叉堆，斐波那契堆在 `Decrease-Key` 操作上有显著优势 ($O(1)$ vs $O(\lg V)$)。在稠密图（$E \gg V$）中，斐波那契堆的性能远优于二叉堆。

### C++ 代码实现 (二叉堆优化版)

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>

using namespace std;

// 邻接表节点：{目标顶点, 权重}
typedef pair<int, int> pii; 

int prim(int n, const vector<vector<pii>>& adj) {
    int mst_weight = 0;
    
    // min_heap 存储 {当前距离, 顶点编号}
    // C++ priority_queue 默认是大顶堆，所以用 greater 实现小顶堆
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    
    // 记录顶点是否已在 MST 中
    vector<bool> in_mst(n, false);
    
    // key[i] 记录顶点 i 到 MST 的最小距离，初始为无穷大
    vector<int> key(n, INT_MAX);
    
    // 从顶点 0 开始
    int start_node = 0;
    key[start_node] = 0;
    pq.push({0, start_node});
    
    while (!pq.empty()) {
        // 1. 取出 key 最小的顶点
        int u = pq.top().second;
        int w = pq.top().first;
        pq.pop();
        
        // 如果该顶点已经在 MST 中（可能是旧的较差记录），跳过
        if (in_mst[u]) continue;
        
        // 2. 将 u 加入 MST
        in_mst[u] = true;
        mst_weight += w;
        
        // 3. 更新邻居
        for (auto& edge : adj[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            // 如果 v 不在 MST 中，且通过 u 连接 v 的代价更小
            if (!in_mst[v] && weight < key[v]) {
                key[v] = weight;
                pq.push({key[v], v});
            }
        }
    }
    
    return mst_weight;
}

int main() {
    int n = 4;
    // 邻接表
    vector<vector<pii>> adj(n);
    
    auto add_edge = [&](int u, int v, int w) {
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    };
    
    add_edge(0, 1, 1);
    add_edge(1, 2, 2);
    add_edge(2, 3, 3);
    add_edge(0, 2, 4);
    add_edge(1, 3, 5);
    
    cout << "Prim MST Weight: " << prim(n, adj) << endl;
    
    return 0;
}
```
