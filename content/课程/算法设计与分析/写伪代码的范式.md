# 写伪代码的范式 (Pseudocode Standards)

伪代码（Pseudocode）是一种用于描述算法的高层次、非正式的语言。它忽略了具体的编程语言语法细节，专注于算法逻辑的清晰表达。编写良好的伪代码有助于算法的分析、交流和实现。

## 1. 核心原则 (Core Principles)

*   **清晰性 (Clarity)**: 逻辑必须易于理解，避免歧义。
*   **简洁性 (Conciseness)**: 去除不必要的细节（如变量声明、内存管理），保留核心逻辑。
*   **语言无关性 (Language Independence)**: 不应依赖于特定编程语言的特性。
*   **结构化 (Structured)**: 使用标准的控制结构（如 if-then-else, while, for）。

## 2. 语法规范 (Syntax Guidelines)

### 2.1 赋值与变量
*   使用 `←` 或 `:=` 表示赋值，以区别于相等比较。
*   示例: `x ← 5` 或 `max_val := A[0]`

### 2.2 控制结构 (Control Structures)
所有的控制结构应当通过缩进来表示块结构（Block Structure）。

*   **条件判断 (Conditional)**:
    ```text
    if condition then
        // statements
    else if condition then
        // statements
    else
        // statements
    end if
    ```

*   **循环 (Loops)**:
    *   **While 循环**:
        ```text
        while condition do
            // statements
        end while
        ```
    *   **For 循环**:
        ```text
        for variable ← start to end do
            // statements
        end for
        ```
    *   **Foreach 循环**:
        ```text
        for each item in collection do
            // statements
        end for
        ```

### 2.3 函数与过程 (Functions & Procedures)
*   声明函数名、输入参数和返回值。
*   使用 `return` 返回结果。
    ```text
    Algorithm FunctionName(Input1, Input2)
        // comments explaining the step
        result ← Input1 + Input2
        return result
    End Algorithm
    ```

### 2.4 数组与集合 (Arrays & Sets)
*   **数组访问**: 使用 `A[i]` 表示数组 A 的第 i 个元素。通常假设下标从 1 开始（算法导论风格）或 0 开始（编程语言风格），需在上下文中统一。
*   **数组长度**: `length[A]` 或 `A.length`。
*   **子数组**: `A[i..j]` 表示从索引 i 到 j 的子数组。

### 2.5 注释 (Comments)
*   使用 `//` 进行单行注释。
*   使用 `/* ... */` 进行多行注释（如果需要）。
*   注释应解释“做什么”和“为什么”，而不是“怎么做”。

## 3. 数学符号 (Mathematical Notations)

在伪代码中适当使用数学符号可以提高表达效率：

*   **求和**: $\sum_{i=1}^{n} A[i]$
*   **集合操作**: $\cup$ (并集), $\cap$ (交集), $\in$ (属于), $\subseteq$ (子集), $\emptyset$ (空集)
*   **逻辑运算**: $\land$ (AND), $\lor$ (OR), $\neg$ (NOT)
*   **无穷大**: $\infty$

## 4. 示例 (Examples)

### 示例 1: 寻找数组最大值 (Find Maximum)

```text
Algorithm FindMax(A)
    Input: An array A of n numbers
    Output: The maximum value in A

    max_val ← A[1]
    for i ← 2 to A.length do
        if A[i] > max_val then
            max_val ← A[i]
        end if
    end for
    return max_val
End Algorithm
```

### 示例 2: 冒泡排序 (Bubble Sort)

```text
Algorithm BubbleSort(A)
    Input: An array A of n comparable elements
    Output: Sorted array A in ascending order

    n ← A.length
    swapped ← true
    while swapped = true do
        swapped ← false
        for i ← 1 to n - 1 do
            if A[i] > A[i + 1] then
                swap(A[i], A[i + 1])
                swapped ← true
            end if
        end for
        n ← n - 1  // Optimization: last element is already sorted
    end while
End Algorithm
```

## 5. 最佳实践 (Best Practices)

1.  **保持一致性**: 在整个文档中保持相同的缩进风格、变量命名规则和关键字。
2.  **适当抽象**: 如果某一步骤过于复杂，将其封装为一个子过程（Sub-procedure），只需调用其名字即可。
3.  **明确输入输出**: 在算法开头明确列出 Input 和 Output，有助于读者快速理解算法目的。
4.  **避免过度编程**: 不要陷入具体的语法细节，如 `int i;` 或 `System.out.println`，除非特定上下文需要。
