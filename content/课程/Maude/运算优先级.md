- 左连接（左结合）：gather (E e)
- 右连接（右结合）：gather (e E)
- 优先级：用 \[prec n] 指定；数值越小绑定越紧

## 2. 优先级 precedence
- 在 Maude 中，优先级是自然数，值越小绑定越紧（比价更高的优先级）。
- 用法：在运算符声明中用属性 \[prec n] 指定。
- 最大允许优先级值为 2^31 - 1。
- 未显式指定优先级的运算符会有默认值（例如文中提到 \_+\_ 与 \_\*\_ 的默认是 41，会导致歧义）。
- 常量（如数字 1,2,3）默认优先级为 0。

示例：
```
sort Nat .
ops 1 2 3 : -> Nat .
ops _+_ _*_ : Nat Nat -> Nat .
```
表达式 1 + 2 * 3 在默认情况下是歧义的。给出期望的优先级：
```
op _+_ : Nat Nat -> Nat [prec 33] .
op _*_ : Nat Nat -> Nat [prec 31] .
```
因为 31 < 33，乘法绑定更紧，1 + 2 * 3 的唯一解析为 1 + (2 * 3)。若需要改变优先级，可用括号显式指定：(1 + 2) * 3。

## 3. gather（聚合模式）
- gather 模式对每个参数位置给出一个取值：E、e 或 &，用于限制该位置参数可接受的“顶层运算符优先级”。
  - E：该参数的优先级须“小于或等于”当前运算符的优先级。
  - e：该参数的优先级须“严格小于”当前运算符的优先级。
  - &：该参数允许“任意”优先级。
- 实际上，“优先级”与“gather”配合才能真正消除歧义。例如，二元运算默认 gather (E E) 强制两参数的顶层优先级不高于当前运算符，使 1 + (2 * 3) 合法，而 (1 + 2) * 3 不合法（因为 1+2 的顶层优先级为 33，高于 * 的 31）。

## 4. 结合性（左/右连接）用 gather 表达
- 仅靠优先级无法消除如 1 + 2 + 3 的歧义，需要结合性约束。
- 在 Maude 中，用 gather 对参数位置施加“严格小于”的约束来表达结合性：
  - 左连接（左结合）：gather (E e)
    - 第二参数必须“严格低于”该运算符的优先级，因此形如 1 + (2 + 3) 作为第二参数不合法；唯一解析为 (1 + 2) + 3。
  - 右连接（右结合）：gather (e E)
    - 第一参数必须“严格低于”该运算符的优先级，因此唯一解析为 1 + (2 + 3)。

示例（左结合）：
```
op _+_ : Nat Nat -> Nat [prec 33 gather (E e)] .
op _*_ : Nat Nat -> Nat [prec 31 gather (E e)] .
```
此时 1 + 2 + 3 的唯一解析为 (1 + 2) + 3。

## 5. 默认优先级规则

### 5.1 默认优先级值

^27e400

- **标准形式操作符**（常量和前缀操作符）：优先级固定为 0，用户无法修改
- **混合操作符**（不以下划线开头和结尾）：优先级为 0
  - 例如：`(_)`、`<_:_|_>`、`if_then_else_fi`
- **单边下划线操作符**（仅开头或结尾有下划线）：
  - 一元操作符：优先级 15
  - 其他操作符：优先级 41
  - 例如：`not_`、`_!`、`to_:_`
- **双边下划线操作符**（开头和结尾都有下划线）：优先级 41
  - 例如：`__`、`_+_`、`_*_`、`_?_:_`

### 5.2 默认 gather 模式规则
- **前缀操作符**：所有参数都是 `&`
- **非相邻下划线**：如果下划线不与其他下划线相邻，且不在最左或最右位置，则为 `&`
  - 例如：`if_then_else_fi` → `(& & &)`
  - 例如：`[_and then_]` → `(& &)`
- **相邻或边界下划线**：默认为 `E`
  - 例如：`not_` → `(E)`、`_+_` → `(E E)`、`__` → `(E E)`

### 5.3 特殊情况：结合性操作符
对于以下划线开头和结尾、优先级大于 0 的二元操作符：

**有 assoc 属性**：gather 模式为 `(e E)`
```maude
op _+_ : Nat Nat -> Nat [assoc] .  // gather (e E)
op _*_ : Nat Nat -> Nat [assoc] .  // gather (e E)
```

**无 assoc 属性但满足子类型条件**：
- 如果可以右结合但不能左结合：第一参数改为 `e` → `(e E)`
- 如果可以左结合但不能右结合：最后参数改为 `e` → `(E e)`

```maude
// 假设 Int < IntList
op _<:_ : Int IntList -> IntList .  // gather (e E) - 右结合
op _:>_ : IntList Int -> IntList .  // gather (E e) - 左结合
```

## 6. 括号的特殊地位
- 括号可被视为一个特殊运算符：`(_)`，优先级为 0，gather 为 `(&)`
- 含义：括号内允许任何优先级的子项，且括号可用于覆盖/改变解析优先级
