本文记录 Maude [[操作符 Operator|操作符]]的四个常用属性：`assoc`、`comm`、`id`、`ctor`
## assoc（结合律）
- 作用：声明操作符满足结合律，解析与匹配可在不显式括号的情况下进行重新结合。
- 常见场景：序列拼接、项并置等。

```maude
fmod SEQ-ASSOC is
  sorts Elem Seq .
  subsort Elem < Seq .

  // 一个元素常量，用作示例（真实场景中可有多种 Elem）
  op a : -> Elem .
  op b : -> Elem .
  op c : -> Elem .

  // 仅声明结合律：多个序列并置时可自由结合
  op __ : Seq Seq -> Seq [assoc] .

  // 使用示例（说明性注释）：
  // - 解析：a b c 等价于 (a b) c 与 a (b c)
  // - 模式匹配：X (Y Z) 可匹配 (X Y) Z 无需显式括号
endfm
```

## comm（交换律）
- 作用：声明操作符满足交换律，匹配与化简时不区分参数顺序。
- 常见场景：加法、集合并等可交换运算。

```maude
fmod COMM-EX is
  sort Elt .
  // 三个示例元素常量
  ops x y z : -> Elt .

  // 交换 + 结合：项顺序不影响匹配与化简语义
  op _+_ : Elt Elt -> Elt [comm assoc] .

  // 说明：
  // - 模式 (X + Y) 能匹配 (Y + X)
  // - 组合表达式 x + y + z 的子项顺序可忽略，便于 AC（交换-结合）匹配
endfm
```

## id（单位元）
- 作用：为操作符指定单位元常量，使得该常量与任意项按该操作符组合时不改变值。
- 常与 `assoc`/`comm` 结合形成 AU/ACU 等等价理论，提升匹配能力。

```maude
fmod SEQ-ID is
  sorts Elem Seq .
  subsort Elem < Seq .

  // 空序列常量作为单位元
  op nil : -> Seq .

  // 元素常量示例
  ops a b : -> Elem .

  // 并置操作：结合 + 单位元
  op __ : Seq Seq -> Seq [assoc id: nil] .

  // 说明：
  // - nil 是单位元：nil X = X，X nil = X（由属性语义保证）
  // - 解析：a b 等价于 (a __ b)；多项并置时可省括号并吸收 nil
endfm
```

## ctor（构造子）
- 作用：标记“数据构造”的操作符，表示其产生的项为数据值（通常不由方程进一步定义）；有助于变体生成、窄化与匹配性能。
- 常见场景：代数数据类型的值构造（如自然数的 `zero` 与后继 `s_`）。

```maude
fmod NAT-CTOR is
  sorts Zero NzNat Nat .
  subsorts Zero NzNat < Nat .

  // 构造子：值构造（通常不再由方程去‘定义’）
  op zero : -> Zero [ctor] .          // 自然数 0
  op s_   : Nat -> NzNat [ctor] .     // 后继构造子 s n 表示 n+1

  // 非构造子示例：定义性函数，可由方程给出语义
  op p : NzNat -> Nat .               // 前驱函数（部分定义域：只接受 NzNat）
  eq p(s N) = N .                     // 定义：p(s n) = n

  // 说明：
  // - [ctor] 使 zero、s_ 构成“数据形状”，便于匹配与符号求解
  // - p 非 ctor，作为‘已定义’函数可用方程描述其行为
endfm
```
