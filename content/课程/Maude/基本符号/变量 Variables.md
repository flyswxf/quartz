变量是在[[等式与成员关系|等式]]中使用的, 相当于'对于任意x $\in$ Nat, 一定满足...'
## 1. 变量约束
- 变量被约束在特定的 sort 或 kind 上
- 必须声明变量的类型（sort 或 kind）

## 2. 即时声明语法 #不知道有什么用
**语法格式**：`变量名:类型`

```maude
N:Nat        // 变量 N，类型为 Nat sort
X:[Nat]      // 变量 X，类型为 [Nat] kind
```

**作用域**：仅限于声明出现的位置，每次使用都需要重新声明类型

## 3. 模块内声明

### 3.1 单变量声明
```maude
var N : Nat .
var X : [Nat] .
```

### 3.2 多变量声明
加个`s`
```maude
vars M N : Nat .
vars X Y : [Nat] .
```

**作用域**：整个模块内有效，自动替换为即时声明形式

## 4. 命名规则
- **大小写**：大写和小写都可以，但**大写**更常用
- **命名约定**：与常量操作符相同规则
- **特殊字符**：
  - 下划线 `_` 不能使用
  - 冒号 `:` 可以使用
- **解析规则**：冒号 `:` 从右到左扫描，用于提取类型信息

## 5. 示例对比

| 声明方式 | 语法 | 作用域 | 使用场景 |
|---------|------|--------|----------|
| 即时声明 | `N:Nat` | 当前位置 | 临时使用 |
| 模块声明 | `var N : Nat .` | 整个模块 | 频繁使用 |
| 多变量声明 | `vars M N : Nat .` | 整个模块 | 同类型多变量 |
