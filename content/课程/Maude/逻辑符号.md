- 默认逻辑值都属于`sort Bool .`
- 逻辑值可以使用在[[等式 Equation#条件等式/条件成员关系|条件等式/条件成员关系]], 和`if_then_else_fi`操作符中

| 语义  | Maude 写法     |
| --- | ------------ |
| 等于  | `==`         |
| 不等于 | `=/=`        |
| 与   | `and` 或 `/\` |
| 或   | `or` 或 `\/`  |

**常用布尔项**：
```maude
N == zero                    // 相等判断
M =/= s zero                // 不等判断  
not (K :: NzNat)            // 成员关系否定
(N > zero or M =/= s zero)  // 布尔组合
```
