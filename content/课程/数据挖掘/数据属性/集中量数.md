# 集中量数（计算方法与示例）
集中趋势度量
以下以数据集 A = [1, 2, 2, 3, 3, 3, 4]（已排序，n=7）为例说明。

## 频率（Frequency）
- 绝对频率：$f_i$ 为某值出现的次数。
- 相对频率：$p_i = \frac{f_i}{n}$。
- 累积相对频率：$F_k = \sum_{i\le k} p_i$（对有序类别或数值型）。
- 示例：值 1、2、3、4 的绝对频率分别是 $1, 2, 3, 1$；相对频率分别是 $\frac{1}{7}, \frac{2}{7}, \frac{3}{7}, \frac{1}{7}$。

## 均值（Mean）
- 算术平均数：$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$。
- 加权平均数：$\bar{x}_w = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}$。
- 示例（算术平均）：$\bar{x} = \frac{1+2+2+3+3+3+4}{7} = \frac{18}{7} \approx 2.571$。

## 中位数（Median）
- 将数据升序：$x_{(1)}\le x_{(2)}\le \cdots \le x_{(n)}$。
- 若 $n$ 为奇数：中位数为 $x_{((n+1)/2)}$。
- 若 $n$ 为偶数：中位数为 $\frac{x_{(n/2)} + x_{(n/2+1)}}{2}$。
- 示例：A 的中位数是第 $((7+1)/2)=4$ 个值，$x_{(4)}=3$。若数据为\[1,2,3,4\]（n=4），中位数为 $\frac{2+3}{2}=2.5$。

## 众数（Mode）
- 定义：具有最高频率的数值（可能有多个众数，也可能无众数）。
- 示例：A 中 3 出现 3 次，为众数；若两值并列最高频率，则为双众数等。

## 百分位数（Percentile）
常用两类定义（需先排序）：
- 最近秩法（Nearest Rank）：第 $p$ 百分位取 $k=\lceil\frac{p}{100}n\rceil$，结果为 $x_{(k)}$。
- 线性插值法（常见于统计软件）：计算 $i=\frac{p}{100}(n+1)$；若 $i$ 非整数，令 $j=\lfloor i\rfloor$，$\delta=i-j$，则第 $p$ 百分位为 $x_{(j)} + \delta\,[x_{(j+1)}-x_{(j)}]$。
- 示例（最近秩法）：
  - 第 25 百分位：$k=\lceil0.25\times7\rceil=2$，$x_{(2)}=2$。
  - 第 75 百分位：$k=\lceil0.75\times7\rceil=6$，$x_{(6)}=3$。
- 示例（线性插值法）：
  - 第 40 百分位：$i=0.4\times(7+1)=3.2$，$j=3$、$\delta=0.2$，$x_{(3)}=2$、$x_{(4)}=3$，结果 $=2+0.2\times(3-2)=2.2$。

## 备注
- 连续数据的频率常以区间计数，百分位数在不同软件可能采用不同插值/秩方法，需根据具体工具的实现选择相应公式。
