规范化用于消除量纲差异，让不同变量在同一尺度上比较与建模。

## 方法总览（速查表）
| 方法        | 公式（示例）                                                                                   | 尺度/区间                | 优点        | 注意事项                      |     |     |       |             |
| --------- | ---------------------------------------------------------------------------------------- | -------------------- | --------- | ------------------------- | --- | --- | ----- | ----------- |
| 最小-最大归一化  | $x' = \frac{x-\min}{\max-\min}$；一般区间 $[a,b]$: $x' = a + \frac{(x-\min)(b-a)}{\max-\min}$ | 通常 $[0,1]$ 或 $[a,b]$ | 简洁、保持相对顺序 | 受异常值影响大；$\max=\min$ 需特殊处理 |     |     |       |             |
| 反向归一化     | $x' = \frac{\max-x}{\max-\min}$                                                          | $[0,1]$              | 方向翻转      | 与上同                       |     |     |       |             |
| 中心化       | $x' = x - \bar{x}$                                                                       | 均值为 $0$              | 去除偏移      | 尺度未统一，仍受量纲影响              |     |     |       |             |
| 标准化（Z 分数） | $x' = \frac{x-\bar{x}}{\sigma}$（或样本标准差）                                                  | 均值 $0$、标准差 $1$       | 适合近似正态分布  | 异常值会影响 $\bar{x},\sigma$   |     |     |       |             |
| 小数定标      | $x' = \frac{x}{10^{k}}$，$k = \lceil \log_{10}(\max                                       | x                    | ) \rceil$ | 使 $                       | x'  | <1$ | 简单、快速 | 仅缩放，未考虑分布形状 |
| 鲁棒缩放      | $x' = \frac{x-\mathrm{median}}{\mathrm{IQR}}$                                            | 中位数 0、基于 IQR         | 抗异常值      | 顺序保留但非固定区间                |     |     |       |             |
## 常用公式与解释
- 归一化到 $[0,1]$：$x' = \frac{x-\min}{\max-\min}$；最小值映射为 $0$，最大值映射为 $1$。
- 指定区间 $[a,b]$：$x' = a + \frac{(x-\min)(b-a)}{\max-\min}$。
- 中心化：$x' = x - \bar{x}$，仅改变位置不改变尺度。
- 标准化：$x' = \frac{x-\bar{x}}{\sigma}$，使均值 $0$、标准差 $1$。
- 小数定标：$x' = \frac{x}{10^{k}}$，选 $k$ 使所有值绝对值小于 $1$。

## 数值示例
设数据 $[2,5,8]$，$\min=2,\max=8,\bar{x}=5$。
- $[0,1]$ 归一化：$[0,0.5,1]$。
- $[-1,1]$ 区间：$a=-1,b=1$，得到 $[-1,0,1]$。
- 反向归一化：$[1,0.5,0]$。
- 中心化：$[-3,0,3]$。
- 标准化：$\sigma = \sqrt{\frac{(2-5)^2+(5-5)^2+(8-5)^2}{3}} = \sqrt{6}\approx2.449$，
  Z 分数 $[\,-1.225,\,0,\,1.225\,]$（四舍五入）。
- 小数定标：$\max|x|=8\Rightarrow k=1$，$[0.2,0.5,0.8]$。
