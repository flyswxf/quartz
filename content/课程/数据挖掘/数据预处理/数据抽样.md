# 数据抽样（Sampling）笔记

数据抽样通过选取具有代表性的子样本来降低数据体量、保留关键信息，以便高效分析与建模。

## 原则与目标
- 代表性：样本应体现总体分布和结构。
- 保留特征：尽量保持变量的分布、比例、相关性等。
- 针对性：依据任务与数据特性选择方法（随机/系统/分层/整群）。

## 方法总览（速查表）
| 方法 | 适用场景 | 核心步骤 | 优点 | 风险/局限 |
|---|---|---|---|---|
| 简单随机抽样 | 总体均匀、无明显结构 | 从抽样框中随机选 `n` 个 | 简单、随机性强 | 可能抽到“差样本”，代表性波动大 |
| 系统抽样 | 数据有序、总体大 | 设步长 `k=N/n`，随机起点后每隔 `k` 抽取 | 简便、覆盖均匀 | 若存在周期性可能偏倚 |
| 分层抽样 | 层间异质、层内同质 | 按层划分并分别抽样（比例/等量/最优） | 精度高、层代表性好 | 需高质量分层信息，实施复杂 |
| 整群抽样 | 群可自然划分、群内差异大 | 抽群后调查被抽中群的所有个体 | 成本低、便于实施 | 精度较低、群内趋同性导致偏倚 |

## 简单随机抽样（SRS）
- 定义：完全随机地从总体抽取一定数量的样本。
- 变体：
  - 无放回：每个个体最多被抽一次。
  - 有放回：同一个体可被多次抽中（适合模拟或自助法）。
- 示例：`N=10000`，抽取 `n=1000`。
- Python（Pandas）：
```python
# 无放回
sample = df.sample(n=1000, random_state=42)
# 有放回
sample_wr = df.sample(n=1000, replace=True, random_state=42)
```
- 优点：随机度高、实现简单。缺点：代表性可能波动；在不均匀总体上可能抽到分布不佳的样本。

## 系统抽样（Systematic）
- 步骤：将总体按顺序排列，设步长 `k = N / n`，随机选起点 `r ∈ [0, k-1]`，抽取索引 `r, r+k, r+2k, ...`。
- 示例：`N=10000`、`n=1000`，`k=10`，若 `r=7`，则抽取第 `7, 17, 27, ...` 个。
- Python：
```python
N = len(df); n = 1000; k = N // n
r = np.random.randint(0, k)
idx = list(range(r, N, k))
sample = df.iloc[idx]
```
- 优点：简便、覆盖均匀；缺点：若数据存在与步长相关的周期性，会引入系统性偏差。

## 分层抽样（Stratified）
- 定义：将总体分为互不交叉的同质“层”，在每层内独立抽样。
- 配额策略：
  - 比例分配：各层样本量按层大小比例分配（常用）。
  - 等量分配：各层抽取相同数量（适合小层保护）。
  - Neyman 最优分配：按层标准差与成本加权分配以最小化方差。
- 示例：某电商用户按 `gender` 分层，目标总样本 `n=1000`，按比例抽取：
```python
# 比例分配（按层样本量比例）
frac = 1000 / len(df)
sample = df.groupby('gender', group_keys=False).apply(lambda x: x.sample(frac=frac, random_state=42))
# 或显式按层指定数量
sizes = df.groupby('gender').size()
alloc = (sizes / sizes.sum() * 1000).round().astype(int)
sample = pd.concat([g.sample(n=alloc[name], random_state=42) for name, g in df.groupby('gender')])
```
- 优点：层间异质、层内同质时能显著提升精度，保证层的代表性；缺点：需要可靠的分层变量，实施与误差估计更复杂。

## 整群抽样（Cluster）
- 定义：将总体划为若干“群（cluster）”，抽取部分群并调查被抽中群的全部个体（单阶段）；或在被抽中群内再抽样（两阶段）。
- 示例：按城市为群，先抽取 10 个城市（群），再调查这 10 城市中的所有订单；或两阶段在每城抽取 20 家商户。
- Python：
```python
# 单阶段：抽群后取群中全部个体
clusters = df['city'].unique()
chosen = np.random.choice(clusters, size=10, replace=False)
sample = df[df['city'].isin(chosen)]
# 两阶段：每群再抽固定数量
sample_2stage = (
    df[df['city'].isin(chosen)]
      .groupby('city', group_keys=False)
      .apply(lambda x: x.sample(n=min(20, len(x)), random_state=42))
)
```
- 优点：成本低、组织便利；缺点：群内趋同性导致方差增大，精度通常低于分层与简单抽样。

## 常用样本量估算（参考）
- 二项比例：`n ≈ (z^2 * p * (1-p)) / e^2`，其中 `z` 为置信系数（如 95%→1.96），`p` 为预估比例，`e` 为允许误差。
- 有限总体修正：`n_adj = n / (1 + (n-1)/N)`。
- 建模任务还应考虑类别不平衡、最小事件数（如每特征至少若干正例）。

## 实操建议与注意事项
- 明确抽样框与去重规则，避免重复样本。
- 设定随机种子 `random_state` 以便复现实验。
- 数据存在时间/空间结构时优先考虑分层或整群；有序数据用系统抽样更高效。
- 警惕系统抽样的周期性偏差；在分层时避免信息泄露（仅用训练集确定分层与配额）。
- 抽样后核对关键分布（比例、均值、方差、长尾）以验证代表性。

## 小结
- 简单随机：最快上手，但代表性波动。
- 系统抽样：实现简便，适合大数据有序场景，需避开周期性。
- 分层抽样：提升精度与稳定性，是首选在分布不均或关键子群需保证代表性时。
- 整群抽样：组织友好、成本低，但精度较差，适合按自然群体抽取的场景。
