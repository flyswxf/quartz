关联规则挖掘（Association Rule Mining）是数据挖掘中一种常用的无监督学习方法，旨在从大规模数据集中发现变量（项）之间有趣的、潜在的关联关系或相关性。

## 1. 基本概念

在介绍原理之前，需要理解以下核心概念。假设我们有一个交易数据库 $D$，其中包含一系列的事务（Transaction）。

### 1.1 项与项集 (Item & Itemset)
- **项 (Item)**：数据集中的基本元素。例如，在超市购物数据中，“牛奶”、“面包”就是一个个项。
- **项集 (Itemset)**：由一个或多个项组成的集合。
    - **k-项集**：包含 $k$ 个项的集合。例如 `{牛奶, 面包}` 是一个 2-项集。

### 1.2 事务 (Transaction)
- 数据库中的一条记录，通常包含一个唯一的事务 ID 和一个项集。

### 1.3 关联规则 (Association Rule)
- 形如 $X \Rightarrow Y$ 的蕴含式，其中 $X$ 和 $Y$ 是项集，且 $X \cap Y = \emptyset$（即 $X$ 和 $Y$ 不相交）。
- $X$ 称为规则的前件（Antecedent）或左部（LHS），$Y$ 称为规则的后件（Consequent）或右部（RHS）。
- 含义：如果一个事务包含项集 $X$，那么它很有可能也包含项集 $Y$。

## 2. 评估指标

为了筛选出有意义的规则，通常使用以下三个关键指标：

### 2.1 支持度 (Support)
- 描述项集在数据集中出现的频率。
- **项集的支持度**：包含该项集的事务数占总事务数的比例。
  $$Support(X) = \frac{\text{包含 X 的事务数}}{\text{总事务数}}$$
- **规则 $X \Rightarrow Y$ 的支持度**：同时包含 $X$ 和 $Y$ 的事务数占总事务数的比例。
  $$Support(X \Rightarrow Y) = P(X \cup Y)$$

### 2.2 置信度 (Confidence)
- 描述规则的可靠性，即在包含 $X$ 的事务中，同时包含 $Y$ 的条件概率。
  $$Confidence(X \Rightarrow Y) = P(Y|X) = \frac{Support(X \cup Y)}{Support(X)}$$

### 2.3 提升度 (Lift)
- 描述 $X$ 的出现对 $Y$ 出现概率的提升程度。用于判断 $X$ 和 $Y$ 是正相关、负相关还是独立。
  $$Lift(X \Rightarrow Y) = \frac{Confidence(X \Rightarrow Y)}{Support(Y)} = \frac{P(X \cup Y)}{P(X)P(Y)}$$
- **Lift > 1**：正相关，$X$ 的出现提高了 $Y$ 的出现概率（有效的强关联）。
- **Lift = 1**：相互独立，$X$ 和 $Y$ 没有关联。
- **Lift < 1**：负相关，$X$ 的出现降低了 $Y$ 的出现概率。

## 3. 基本原理

关联规则挖掘的目标通常是找到满足**最小支持度 (Min-Support)** 和 **最小置信度 (Min-Confidence)** 阈值的所有规则。

### 3.1 挖掘过程
整个挖掘过程通常分为两个主要步骤：

1.  **[[计算频繁项集|找出所有频繁项集 (Frequent Itemset Generation)]]**：
    - 找出所有支持度 $\geq$ 最小支持度阈值的项集。
    - 这些项集被称为**频繁项集**。
    - 这是计算量最大的一步，因为项集的组合数量随项数的增加呈指数增长。

2.  **生成强关联规则 (Rule Generation)**：
    - 从上一步找到的频繁项集中，提取出满足最小置信度阈值的规则。
    - 这些规则被称为**强关联规则**。

### 3.2 核心性质 (Apriori 性质)
为了提高频繁项集生成的效率，利用了支持度的**反单调性**（Anti-monotone property）：

- **性质 1**：如果一个项集是频繁的，那么它的所有非空子集也一定是频繁的。
- **性质 2**：如果一个项集是非频繁的，那么它的所有超集也一定是非频繁的。

利用这一性质，可以在搜索过程中对搜索空间进行剪枝（Pruning），避免计算那些肯定不满足条件的项集的支持度，从而大幅提高效率。
