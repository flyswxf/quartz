# 关联规则计算完整实例

## 2. 频繁项集挖掘 (Apriori)

### 第一轮: 1-项集 ($L_1$)
统计每个项的出现次数：
- **I1**: 8 (T100, T400, T500, T700, T800, T900, T1000, T1100) -> **OK**
- **I2**: 9 -> **OK**
- **I3**: 8 -> **OK**
- **I4**: 2 (T200, T400) -> **Fail** (<4)
- **I5**: 3 (T100, T800, T1000) -> **Fail** (<4)
- **I6**: 5 -> **OK**
- **I7**: 5 -> **OK**

**$L_1$**: `{I1}, {I2}, {I3}, {I6}, {I7}`

### 第二轮: 2-项集 ($L_2$)
由 $L_1$ 组合生成候选，并计数：
- `{I1, I2}`: 6 (T100, T400, T700, T800, T1000, T1100) -> **OK**
- `{I1, I3}`: 6 -> **OK**
- `{I1, I6}`: 3 (T500, T700, T1000) -> **Fail**
- `{I1, I7}`: 5 -> **OK**
- `{I2, I3}`: 6 -> **OK**
- `{I2, I6}`: 4 (T200, T300, T700, T1000) -> **OK**
- `{I2, I7}`: 5 -> **OK**
- `{I3, I6}`: 4 -> **OK**
- `{I3, I7}`: 4 (T700, T800, T1000, T1100) -> **OK**
- `{I6, I7}`: 2 (T700, T1000) -> **Fail**

**$L_2$**: `{I1,I2}, {I1,I3}, {I1,I7}, {I2,I3}, {I2,I6}, {I2,I7}, {I3,I6}, {I3,I7}`

### 第三轮: 3-项集 ($L_3$)
由 $L_2$ 连接生成 $C_3$，并剪枝（检查子集是否在 $L_2$ 中）：
- `{I1, I2, I3}`: 子集 {I1,I2}, {I1,I3}, {I2,I3} 均在 $L_2$ -> 保留。计数: 4 (T700, T800, T1000, T1100) -> **OK**
- `{I1, I2, I7}`: 子集 {I1,I2}, {I1,I7}, {I2,I7} 均在 $L_2$ -> 保留。计数: 5 -> **OK**
- `{I1, I3, I7}`: 子集 {I1,I3}, {I1,I7}, {I3,I7} 均在 $L_2$ -> 保留。计数: 4 -> **OK**
- `{I2, I3, I6}`: 子集 {I2,I3}, {I2,I6}, {I3,I6} 均在 $L_2$ -> 保留。计数: 3 (T300, T700, T1000) -> **Fail**
- `{I2, I3, I7}`: 子集 {I2,I3}, {I2,I7}, {I3,I7} 均在 $L_2$ -> 保留。计数: 4 -> **OK**
- `{I2, I6, I7}`: 子集 `{I6, I7}` 不在 $L_2$ 中 -> **剪枝**。

**$L_3$**: `{I1,I2,I3}, {I1,I2,I7}, {I1,I3,I7}, {I2,I3,I7}`

### 第四轮: 4-项集 ($L_4$)
- `{I1, I2, I3, I7}`: 所有 3-项子集均在 $L_3$ 中。计数: 4 (T700, T800, T1000, T1100) -> **OK**

**$L_4$**: `{I1, I2, I3, I7}` (Count = 4)

## 3. 强关联规则生成

我们重点关注最大频繁项集 **$L_4$: {I1, I2, I3, I7}** (Count=4) 的规则生成。
目标置信度 > 0.85。

### 第一层：后件为 1-项集
规则形式: $\{L_4 - x\} \Rightarrow \{x\}$
1.  **{I1, I2, I3} => I7**:
    - Conf = Sup(L4) / Sup({I1,I2,I3}) = 4 / 4 = **1.0 (100%)** -> **保留**
2.  **{I1, I2, I7} => I3**:
    - Conf = Sup(L4) / Sup({I1,I2,I7}) = 4 / 5 = **0.8 (80%)** -> **丢弃**
3.  **{I1, I3, I7} => I2**:
    - Conf = Sup(L4) / Sup({I1,I3,I7}) = 4 / 4 = **1.0 (100%)** -> **保留**
4.  **{I2, I3, I7} => I1**:
    - Conf = Sup(L4) / Sup({I2,I3,I7}) = 4 / 4 = **1.0 (100%)** -> **保留**

### 第二层：后件为 2-项集 (基于合并策略)
根据算法流程，我们只对第一层中**满足条件的规则的后件**进行合并，生成新的候选后件。

- **第一层满足条件的后件**: $\{I7\}, \{I2\}, \{I1\}$
- **被剔除的后件**: $\{I3\}$ (因为规则 $\{I1, I2, I7\} \Rightarrow I3$ 置信度不足)

**合并步骤**:
1.  **合并 $\{I7\}$ 和 $\{I2\}$** $\rightarrow$ 候选后件 $\{I2, I7\}$
    - 对应规则: $\{I1, I3\} \Rightarrow \{I2, I7\}$
    - 计算: Conf = Sup(L4) / Sup({I1,I3}) = 4 / 6 = **0.67 (67%)** $\rightarrow$ **丢弃**

2.  **合并 $\{I7\}$ 和 $\{I1\}$** $\rightarrow$ 候选后件 $\{I1, I7\}$
    - 对应规则: $\{I2, I3\} \Rightarrow \{I1, I7\}$
    - 计算: Conf = Sup(L4) / Sup({I2,I3}) = 4 / 6 = **0.67 (67%)** $\rightarrow$ **丢弃**

3.  **合并 $\{I2\}$ 和 $\{I1\}$** $\rightarrow$ 候选后件 $\{I1, I2\}$
    - 对应规则: $\{I3, I7\} \Rightarrow \{I1, I2\}$
    - 计算: Conf = Sup(L4) / Sup({I3,I7}) = 4 / 4 = **1.0 (100%)** $\rightarrow$ **保留**

*注：由于 $\{I3\}$ 在第一层已被剔除，它不参与合并，因此我们自然地跳过了所有后件包含 $\{I3\}$ 的规则（如 $\{I3, I7\}$），这正是算法自动剪枝的体现。*

### 第三层：后件为 3-项集 (基于合并策略)
尝试对第二层中**满足条件的后件**进行合并。

- **第二层满足条件的后件**: 仅有 $\{I1, I2\}$
- **合并**: 由于只有一个候选项，**无法进行两两合并**。
- **结论**: 过程结束，无法生成后件为 3-项集的规则。

最终筛选出的部分强规则 (从 $L_4$):
- $I1, I2, I3 \Rightarrow I7$
- $I1, I3, I7 \Rightarrow I2$
- $I2, I3, I7 \Rightarrow I1$
- $I3, I7 \Rightarrow I1, I2$
