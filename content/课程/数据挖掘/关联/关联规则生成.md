在关联规则挖掘中，一旦我们找到了**频繁项集 (Frequent Itemsets)**，下一步就是从这些项集中生成满足**最小置信度 (Minimum Confidence)** 要求的**强关联规则**。

## 1. 核心概念回顾

- **输入**: 一个频繁 $k$-项集 $Y$（其中 $k \ge 2$）。
- **目标**: 找到形如 $X \Rightarrow (Y - X)$ 的规则，其中 $X \subset Y$ 且 $X \ne \emptyset$。
- **条件**: 规则的置信度必须 $\ge$ 最小置信度阈值 (`min_conf`)。
  $$Confidence(X \Rightarrow Y-X) = \frac{Support(Y)}{Support(X)} \ge \text{min\_conf}$$
- **注意**: $Support(Y)$ 是已知的（因为 $Y$ 是频繁项集），所以只需要查找其子集 $X$ 的支持度。

## 2. 规则生成算法

如果一个频繁项集 $Y$ 有 $k$ 个项，那么它有 $2^k - 2$ 个可能的关联规则（排除了空集和全集）。暴力枚举所有子集虽然可行，但可以利用**置信度的反单调性**来优化。

### 2.1 定理 (置信度的反单调性)
如果在频繁项集 $Y$ 中，规则 $X \Rightarrow (Y-X)$ **不满足**最小置信度要求，那么对于 $X$ 的任意子集 $X'$ ($X' \subset X$)，规则 $X' \Rightarrow (Y-X')$ 也一定**不满足**最小置信度要求。

**证明直觉**:
- $Confidence(X \Rightarrow Y-X) = \frac{Support(Y)}{Support(X)}$
- $Confidence(X' \Rightarrow Y-X') = \frac{Support(Y)}{Support(X')}$
- 因为 $X' \subset X$，所以 $Support(X') \ge Support(X)$。
- 分母变大（或不变），分子不变，所以分数（置信度）变小（或不变）。

### 2.2 算法流程 (逐层生成)
类似于 Apriori 算法生成频繁项集的过程，我们可以逐层生成规则的**后件 (Consequent)**。

1.  **初始步**: 对于频繁项集 $Y$，先生成所有后件只包含 1 个项的规则：
    - $Y - \{a\} \Rightarrow \{a\}$，其中 $a \in Y$。
    - 计算置信度，保留满足条件的规则。

2.  **迭代步**:
    - **合并策略 (Apriori-Gen)**:
        - 类似于频繁项集挖掘中的连接步，我们只合并那些**前 $m-1$ 个项相同**且**最后一个项不同**的后件。
        - 假设后件内部是有序的 (如字典序或数字序)。
        - **例子**:
            - $\{I3, I5\}$ 和 $\{I3, I7\}$ **可以合并** (前缀 $I3$ 相同) $\rightarrow$ 生成 $\{I3, I5, I7\}$。
            - $\{I3, I7\}$ 和 $\{I2, I5\}$ **不能合并** (前缀 $I3 \ne I2$)。
    - **生成候选规则**:
        - 对于合并得到的新后件 $H_{m+1}$，生成规则 $(Y - H_{m+1}) \Rightarrow H_{m+1}$。
    - 计算置信度，如果满足，则保留。
    - **剪枝**: 如果规则 $(Y - X) \Rightarrow X$ 是低置信度的，那么所有后件是 $X$ 的超集的规则都可以被剪枝。

## 3. 实例演示

**设定**:
- 频繁项集 $Y = \{A, B, C, D\}$
- 已知支持度:
    - $Support(\{A, B, C, D\}) = 20$
    - $Support(\{A, B, C\}) = 25$
    - $Support(\{A, B, D\}) = 50$
    - ... (其他子集支持度已知)
- 最小置信度 (`min_conf`) = 50%

**目标**: 从 $Y$ 中生成规则。

### 第一层: 后件为 1-项集
候选规则:
1.  $ABC \Rightarrow D$: $Conf = 20/25 = 80\%$ (**保留**)
2.  $ABD \Rightarrow C$: ...
3.  $ACD \Rightarrow B$: ...
4.  $BCD \Rightarrow A$: ...

### 第二层: 后件为 2-项集
假设第一层中只有规则 $ABC \Rightarrow D$ 和 $ABD \Rightarrow C$ 满足要求（仅作假设）。
我们可以合并后件 $\{D\}$ 和 $\{C\}$ 得到候选后件 $\{C, D\}$。
新候选规则:
- $AB \Rightarrow CD$
- 计算: $Conf = \frac{Support(ABCD)}{Support(AB)}$
- 如果满足，继续...

**剪枝示例**:
如果第一层中 $BCD \Rightarrow A$ 的置信度 < 50% (低置信度)，那么我们可以断定：
- $CD \Rightarrow AB$ (后件 $\{A, B\} \supset \{A\}$) 一定也是低置信度的。
- $BD \Rightarrow AC$ (后件 $\{A, C\} \supset \{A\}$) 一定也是低置信度的。
- $BC \Rightarrow AD$ (后件 $\{A, D\} \supset \{A\}$) 一定也是低置信度的。
- $D \Rightarrow ABC$ ...
- 我们可以直接跳过对这些规则的检查。
