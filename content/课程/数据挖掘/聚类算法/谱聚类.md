## 1. 简介
**谱聚类**是一种基于**图论**（特别是谱图理论）的聚类算法。与 K-means 等传统算法不同，它不假设数据服从凸分布（如球形），而是利用数据的**相似性矩阵**的特征向量来进行降维，然后在低维空间中进行聚类。
它特别擅长处理**非凸形状**的簇（如环形、螺旋形）以及流形数据。

## 2. 核心概念

谱聚类的核心是将聚类问题转化为图的**最优划分**问题（Graph Cut）。

### 2.1 相似性图 (Similarity Graph)
将数据集中的每个点看作图的一个顶点 $V$，点之间的边 $E$ 的权重 $w_{ij}$ 表示两个点的相似度。
常用的构建方法：
1.  **$\epsilon$-邻近法**：距离小于 $\epsilon$ 则连接。
2.  **$k$-近邻法 (k-NN)**：连接最近的 $k$ 个点。
3.  **全连接法**：使用核函数（如高斯核/RBF核）计算所有点对的相似度：
    $$ w_{ij} = \exp(-\frac{\|x_i - x_j\|^2}{2\sigma^2}) $$

### 2.2 矩阵定义
假设有 $n$ 个数据点：
*   **邻接矩阵 (Adjacency Matrix) $W$**：$n \times n$ 的对称矩阵，其元素 $w_{ij}$ 表示顶点 $v_i$ 和 $v_j$ 之间的**边权重**（即样本点之间的相似度）。
    *   如果 $w_{ij} = 0$，表示两点不相连（或相似度为0）。
    *   通常规定对角线元素 $w_{ii}=0$（无自环）。
    *   简化: 当存在边时, 则 $w_{ij}$ 为1, 否则为0
    * ![[assets/邻接矩阵.png]]
*   **度矩阵 (Degree Matrix) $D$**：$n \times n$ 的对角矩阵，对角线上元素 $d_{ii} = \sum_{j=1}^n w_{ij}$（即该点的所有连接权重之和）。
	* ![[assets/度矩阵示意图.png]]
*   **拉普拉斯矩阵 (Laplacian Matrix) $L$**：
    *   **未归一化 (Unnormalized)**：$L = D - W$
	    * ![[assets/拉普拉斯矩阵.png]]
    *   **归一化 (Normalized)**：
        *   对称归一化：$L_{sym} = D^{-1/2} L D^{-1/2} = I - D^{-1/2} W D^{-1/2}$
        *   随机游走归一化：$L_{rw} = D^{-1} L = I - D^{-1} W$

### 2.3 图切割 (Graph Cut)
聚类的目标是找到一种切图方式，使得：
*   **Cut**：子图之间的**边权重之和最小**（即簇间相似度最低）。
*   同时希望**子图内部足够大**（避免切出孤立点）。为此引入了 **RatioCut** (考虑节点数) 和 **Ncut** (考虑度之和) 等目标函数。
*   谱聚类通过计算 $L$ 的特征向量，实际上是在求这些目标函数的**松弛解**。

## 3. 算法步骤

以常用的 **Ncut** (Normalized Cut) 为例：

1.  **构建图**：计算 $n \times n$ 的相似性矩阵 $W$ 和度矩阵 $D$。
2.  **计算拉普拉斯矩阵**：计算归一化拉普拉斯矩阵 $L_{sym} = D^{-1/2} (D - W) D^{-1/2}$。
3.  **特征分解**：计算 $L_{sym}$ 的特征值和特征向量。
4.  **选特征向量**：取**前 $k$ 个最小**特征值对应的特征向量 $u_1, u_2, ..., u_k$。
5.  **构建新矩阵**：将这 $k$ 个特征向量作为列，组成一个 $n \times k$ 的矩阵 $U$。
6.  **行归一化**：将 $U$ 的每一行进行归一化（使其范数为 1），得到矩阵 $Y$。
    *   *注：第 $i$ 行 $y_i$ 即代表原数据点 $x_i$ 在 $k$ 维谱空间中的表示。*
7.  **聚类**：将 $Y$ 中的每一行看作一个数据点，使用 **K-means** 算法将其聚为 $k$ 类。
8.  **输出**：得到最终的簇划分。

## 4. 优缺点分析

### 优点
1.  **适应性强**：能识别任意形状的簇（如环绕、嵌套结构），不局限于凸集。
2.  **全局最优**：在松弛条件下可以得到全局最优解（特征值问题有唯一解）。
3.  **降维效果**：特征向量自然地对数据进行了降维，滤除了噪声。

### 缺点
1.  **计算复杂度高**：特征值分解的时间复杂度为 $O(n^3)$，难以处理大规模数据集（虽然可用 Lanczos 方法优化，但构建相似度矩阵的空间复杂度仍需 $O(n^2)$）。
2.  **参数敏感**：对相似度图的构建参数（如 RBF 核的 $\sigma$ 或 k-NN 的 $k$）较为敏感。
3.  **K值难定**：通常需要利用“特征值间隙 (Eigengap)”启发式地确定 $k$，但在数据重叠严重时效果不佳。


## 6. 特征值间隙 (Eigengap) 确定 K 值

谱聚类的一个重要特性是可以通过分析拉普拉斯矩阵的特征值来确定簇的数量 $k$。
*   将特征值从小到大排序：$\lambda_1 \le \lambda_2 \le ... \le \lambda_n$。
*   根据**特征值间隙启发式 (Eigengap Heuristic)**：选择 $k$ 使得 $\lambda_{k+1}$ 和 $\lambda_k$ 之间的差距最大（即 $\Delta_k = |\lambda_{k+1} - \lambda_k|$ 最大）。
*   这通常意味着前 $k$ 个特征向量包含了最强的聚类结构信息。
