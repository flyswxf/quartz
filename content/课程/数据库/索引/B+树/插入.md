## B+ 树的插入操作

向 B+ 树中插入一条新数据时，必须保持 B+ 树的结构约束和平衡性质。

### 插入步骤

#### 1. 查找目标位置
从根节点出发，根据搜索键（Search Key）向下遍历，直到找到数据应该插入的**叶子节点**。

#### 2. 处理叶子节点
- **情况 A：叶子节点未满**
  - 节点中现有的键值数 $< n - 1$。
  - **操作**：直接将新数据插入到该叶子节点，并保持键值有序即可。
- **情况 B：叶子节点已满（需分裂）**
  - 节点中现有的键值数等于 $n - 1$，再插入会溢出（变成 $n$ 个键值）。
  - **操作**：将该叶子节点**均分**裂成两个新的叶子节点。
  - **分裂规则**：将这 $n$ 个键值分为两半。习惯上左侧节点保留 $\lceil \frac{n}{2} \rceil$ 个（**左侧多**或相等），右侧节点保留剩下的键值。
  - 例如，原本满的节点插入后有键值 `1, 4, 5`，则分裂为左节点 `[1, 4]` 和右节点 `[5]`。

#### 3. 向上更新父节点（索引节点）
当叶子节点分裂后，会产生一个新的右节点，必须将该右节点的**最小键值**提取出来，作为新的索引键插入到父节点中，并增加一个指向新右节点的指针。
- *如上述例子，右节点为 `[5]`，则需要向父节点插入键值 `5` 和对应的指针。*
- *注意：提取上去作为索引的值不一定就是刚刚插入的新值。*

#### 4. 处理父节点的分裂（递归）
向父节点插入新键值和指针时，如果父节点也满了（指针数超过 $n$）：
- 需要对父节点（中间节点）进行分裂。
- **中间节点分裂规则**：将原本的 $n$ 个键值加上新来的 $1$ 个键值（共 $n+1$ 个），将**正中间**的那个键值“推”给上一级的父节点，剩下的键值平分给两个新的中间节点（左侧 $\lceil \frac{n}{2} \rceil - 1$ 个，右侧其余）。
- 如果分裂一直向上传递，导致**根节点也分裂**，则会创建一个全新的根节点（包含被推上来的 $1$ 个键值和 $2$ 个指针），此时 **B+ 树的高度增加 1**。

---

### 详细示例：连续插入与节点分裂

**条件**：B+ 树初始为空，按升序插入 `(1, 2, 5, 6, 8, 10, 18, 27, 32, 39, 41, 45, 52, 58, 73, 80, 91, 99)`。
设 $n=5$（每个节点最多 5 个指针，4 个键值。中间节点最少 2 个键值，叶子节点最少 2 个键值）。

#### 1. 插入 1, 2, 5, 6
叶子节点未满，直接插入：
```text
[1, 2, 5, 6]
```

#### 2. 插入 8
节点 `[1, 2, 5, 6, 8]` 溢出。分裂为左 `[1, 2, 5]` 和右 `[6, 8]`，提取 6 到父节点：
```text
      [6]
     /   \
[1,2,5] [6,8]
```

#### 3. 插入 10, 18
按顺序插入到右侧节点：
```text
      [6]
     /   \
[1,2,5] [6,8,10,18]
```

#### 4. 插入 27
右侧节点溢出 `[6, 8, 10, 18, 27]`。分裂为左 `[6, 8, 10]` 和右 `[18, 27]`，提取 18 到父节点：
```text
      [6, 18]
     /   |   \
[1,2,5] [6,8,10] [18,27]
```

#### 5. 插入 32, 39
插入到最右侧节点：
```text
      [6, 18]
     /   |   \
[1,2,5] [6,8,10] [18,27,32,39]
```

#### 6. 插入 41
最右侧节点溢出 `[18, 27, 32, 39, 41]`。分裂为 `[18, 27, 32]` 和 `[39, 41]`，提取 39 到父节点：
```text
        [6, 18, 39]
       /   |   |   \
[1,2,5] [6,8,10] [18,27,32] [39,41]
```

#### 7. 插入 45, 52, 58
插入 45, 52 后 `[39, 41, 45, 52]`。
插入 58 溢出，分裂为 `[39, 41, 45]` 和 `[52, 58]`，提取 52 到父节点：
```text
         [6, 18, 39, 52]
       /   |   |    |    \
[1,2,5] [6,8,10] [18,27,32] [39,41,45] [52,58]
```

#### 8. 插入 73, 80
插入到最右侧节点：
```text
         [6, 18, 39, 52]
       /   |   |    |    \
[1,2,5] [6,8,10] [18,27,32] [39,41,45] [52,58,73,80]
```

#### 9. 插入 91
最右侧节点溢出 `[52, 58, 73, 80, 91]`，分裂为 `[52, 58, 73]` 和 `[80, 91]`，提取 80 到父节点。
此时父节点 `[6, 18, 39, 52, 80]` 也溢出！
父节点正中间的 39 被**向上推**，父节点分裂为 `[6, 18]` 和 `[52, 80]`。此时产生了全新的根节点，树高度增加：
```text
               [39]
             /      \
      [6, 18]        [52, 80]
     /   |   \       /   |   \
[1,2,5][6,8,10][18,27,32] [39,41,45][52,58,73][80,91]
```

#### 10. 插入 99
插入到最右侧节点，完成所有插入：
```text
               [39]
             /      \
      [6, 18]        [52, 80]
     /   |   \       /   |   \
[1,2,5][6,8,10][18,27,32] [39,41,45][52,58,73][80,91,99]
```
