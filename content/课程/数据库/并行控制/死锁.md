## Deadlock Prevention

| 特点                 | Wait-Die (等死)           | Wound-Wait (受伤等待)                   | Timeout-Based(超时)    |
| ------------------ | ----------------------- | ----------------------------------- | -------------------- |
| ​**​基本思想​**​       | 年轻者死于冲突                 | 年老者伤害 (杀死) 年轻阻塞者                    | 事务等待一定时间后自杀          |
| ​**​年老者请求年轻者资源​**​ | ​**​等待 (Wait)​**​       | ​**​引发年轻者回滚 (Wound/Rollback)​**​    |                      |
| ​**​年轻者请求年老者资源​**​ | ​**​年轻者立即回滚 (Die)​**​   | ​**​等待 (Wait)​**​                   |                      |
| ​**​回滚主体​**​       | ​**​年轻事务​**​ (因请求资源冲突)  | ​**​年轻事务​**​ (因持有资源阻碍年老者)           | 等待资源者                |
| ​**​回滚频率​**​       | ​**​通常更高​**​ (年轻事务冲突即死) | ​**​通常较低​**​ (回滚仅由年老者引发，年轻者可等待)     |                      |
| ​**​偏向性​**​        | 偏向年老者 (年老者可等待，年轻者直接死)   | ​**​更强烈偏向年老者​**​ (年老者可杀年轻者，年轻者只能等待) |                      |
| ​**​事务重启时间戳​**​    | 保持原时间戳 (保持“年轻”)         | 保持原时间戳 (保持“年轻”)                     |                      |
| ​**​特点​**​         | 回滚次数很多                  | 回滚次数变少                              | 存在没有死锁但误杀的事务; 可能导致饥饿 |
