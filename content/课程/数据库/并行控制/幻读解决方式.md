
| 特性             | 谓词锁 (Predicate Locking) | 索引锁 (Index Locking)   | 临键锁 (Next-Key Locking)                 |
| -------------- | ----------------------- | --------------------- | -------------------------------------- |
| ​**​本质​**​     | ​**​逻辑锁​**​（查询条件）       | ​**​物理锁​**​（索引的叶子节点）  | ​**​物理锁​**​（索引区间）                      |
| ​**​目标​**​     | 防止幻读                    | 防止幻读                  | 高效防止幻读和保证唯一性（利用索引）                     |
| ​**​锁范围​**​    | 抽象查询条件                  | 索引的叶子节点               | \[前一个记录, 查询范围最小值, ..., 查询范围最大值, 后一个记录] |
| ​**​缺点​**​     | 性能开销大, 并行性低​            | 并行性低(当insert较多)       | 无                                      |
| ​**​实际主流应用​**​ | ❌ 极少（如：DB2某些配置）         | ✅ 有（如SQL Server等部分场景） | ✅ ​**​非常广泛​**​（MySQL InnoDB 标志性实现）     |
