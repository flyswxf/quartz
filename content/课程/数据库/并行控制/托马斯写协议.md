Thomas' Write Rule（托马斯写规则）​**​属于[[时间戳排序协议]]（Timestamp-based Protocol）的变体。其核心思想是​**​在特定条件下允许**忽略"过时"的写操作​**​


当一个事务 Ti 试图写入数据项 X 时（执行 W_i(X)），系统根据时间戳进行以下检查：

| ​**​决策条件​**​                   | ​**​操作​**​           |
| ------------------------------ | -------------------- |
| `TS(Ti) < R-TS(X)`             | abort(Ti)            |
| `TS(Ti) < W-TS(X)`             | ​**​忽略写操作, 但继续执行​**​ |
| `TS(Ti) ≥ R-TS(X)` 且 ≥ W-TS(X) | 允许写入并更新              |
