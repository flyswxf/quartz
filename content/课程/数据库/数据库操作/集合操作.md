## 集合操作与比较

SQL 提供了一系列用于关系（Relation）之间的集合运算和比较操作。

### 集合运算

集合运算的操作对象是两个结果集（Relation），并且要求这两个结果集的列数相同，对应列的数据类型也要兼容。

- `UNION`：并集。
- `INTERSECT`：交集。
- `EXCEPT`：差集。

**去重与保留特性**：
- SQL 中的集合运算（`UNION`, `INTERSECT`, `EXCEPT`）**默认去重**。
- 若要保留重复项，需在操作符后添加 `ALL` 关键字，例如 `UNION ALL`, `EXCEPT ALL`。

```sql
-- 找出 2017 年秋季学期开设，但 2018 年春季学期未开设的课程（保留重复）
(SELECT course_id FROM section WHERE semester = 'Fall' AND year = 2017) 
EXCEPT ALL 
(SELECT course_id FROM section WHERE semester = 'Spring' AND year = 2018);
```

### 集合比较操作

用于在 `WHERE` 子句中将单个值与一个集合（通常是子查询的结果）进行比较。

- `SOME` / `ANY`：集合中存在**至少一个**元素满足比较条件，即为真。
- `ALL`：集合中**所有**元素都满足比较条件，即为真。
- `IN` / `NOT IN`：判断某个值是否在集合中（相当于 `= SOME` 和 `!= ALL`）。

```sql
-- 找出薪资高于生物系中至少一位讲师薪资的所有讲师
SELECT name
FROM instructor
WHERE salary > SOME (
    SELECT salary 
    FROM instructor 
    WHERE dept_name = 'Biology'
);

-- 找出薪资高于生物系所有讲师薪资的讲师
SELECT name
FROM instructor
WHERE salary > ALL (
    SELECT salary 
    FROM instructor 
    WHERE dept_name = 'Biology'
);
```
