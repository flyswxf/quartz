 # 第四章 4-1 上下文无关文法 课后作业

**题目：为下列语言设计上下文无关文法。也请思考下列语言可不可以设计正则表达式？**

---

### a) 满足条件的二进制串：每个 0 之后都紧跟着至少一个 1

*   **能否设计正则表达式**：可以。该语言是正则语言。
*   **正则表达式**：$(1 \mid 01)^*$
*   **上下文无关文法 (CFG)**：
    $$
    \begin{aligned}
    S &\rightarrow 1S \mid 01S \mid \epsilon
    \end{aligned}
    $$
*   **关键要点说明**：
    由于每个 $0$ 后面必须有 $1$，所以合法的基本组成单元只能是 $1$ 或 $01$。文法通过不断生成这两种基本单元来构造所有满足条件的字符串。

---

### b) 0 和 1 个数相等的二进制串

*   **能否设计正则表达式**：不可以。该语言需要记录 $0$ 和 $1$ 的数量差，需要无限的计数/记忆能力（如借助栈结构），而正则表达式对应的有限状态自动机无法做到，因此不是正则语言。
*   **上下文无关文法 (CFG)**：
    $$
    \begin{aligned}
    S &\rightarrow 0S1S \mid 1S0S \mid \epsilon
    \end{aligned}
    $$
*   **关键要点说明**：
    任何一个 $0$ 和 $1$ 个数相等的串，必然可以分解为以 $0$ 开头并由某个 $1$ 抵消，或者以 $1$ 开头并由某个 $0$ 抵消的递归结构。

---

### c) 不含 011 子串的二进制串

*   **能否设计正则表达式**：可以。任何不包含特定有限长度子串的语言都是正则语言。
*   **正则表达式**：$1^*(0 \mid 10)^*(1 \mid \epsilon)$
*   **上下文无关文法 (CFG)**：
    可以根据确定的有限状态自动机 (DFA) 的状态转移来构造右线性文法。定义状态：未遇到 $0$（对应 $S$），遇到 $0$（对应 $A$），遇到 $01$（对应 $B$）。
    $$
    \begin{aligned}
    S &\rightarrow 1S \mid 0A \mid \epsilon \\
    A &\rightarrow 0A \mid 1B \mid \epsilon \\
    B &\rightarrow 0A \mid \epsilon
    \end{aligned}
    $$
*   **关键要点说明**：
    如果从状态 $B$ （已读入 $01$）再输入 $1$，就会形成非法子串 $011$，因此在文法中 $B$ 遇到 $1$ 时没有任何转移规则（即直接拒绝该路径）。

---

### d) 具有形式 $xy$ 的二进制串，$x \neq y$

*注：此经典题型的常规语义隐含 $|x| = |y|$，即长度为偶数且前后两半部分不相等的串。*

*   **能否设计正则表达式**：不可以。需要匹配前后两半部分对应的位置和长度，超出了正则表达式的能力范围。
*   **上下文无关文法 (CFG)**：
    $$
    \begin{aligned}
    S &\rightarrow AB \mid BA \\
    A &\rightarrow XAX \mid 0 \\
    B &\rightarrow XBX \mid 1 \\
    X &\rightarrow 0 \mid 1
    \end{aligned}
    $$
*   **关键要点说明**：
    如果两段等长的字符串不完全相同，必定在某个相对位置上一个是 $0$，另一个是 $1$。
    文法中 $A$ 生成以 $0$ 为中心的奇数长度串，$B$ 生成以 $1$ 为中心的奇数长度串。拼接 $AB$ 或 $BA$ 后，中心字符 $0$ 和 $1$ 之间的距离恰好为总长度的一半，这保证了生成串的前后两半部分在对应位置上的字符必定不相等。
    *例子*：要生成串 `0001`（前一半 `00`，后一半 `01`，在第 2 个位置字符不同）。可以通过 $S \rightarrow AB$，其中 $A \rightarrow 000$（中心为 $0$），$B \rightarrow 1$（中心为 $1$），拼接得到 `0001`。

---

### e) 形如 $xx$ 的二进制串

*   **能否设计正则表达式**：不可以。
*   **上下文无关文法 (CFG)**：**无法设计**。
*   **关键要点说明**：
    形如 $xx$ 的语言被称为拷贝语言（Copy Language），它**不是上下文无关语言**（属于上下文有关语言）。根据上下文无关语言的泵引理 (Pumping Lemma) 可以严格证明这一点，因此无法为其设计上下文无关文法，也无法使用正则表达式表示。

---

## 2. 考虑文法

$$
\begin{aligned}
S &\rightarrow (L) \mid a \\
L &\rightarrow L, S \mid S
\end{aligned}
$$

### a) 列出终结符、非终结符和开始符号

*   **终结符**：$a$, $($, $)$, $,$ (逗号)
*   **非终结符**：$S$, $L$
*   **开始符号**：$S$

### b) 给出下列句子的语法树

**i) $(a, a)$**
```text
S
├── (
├── L
│   ├── L
│   │   └── S
│   │       └── a
│   ├── ,
│   └── S
│       └── a
└── )
```

**ii) $(a, (a, a))$**
```text
S
├── (
├── L
│   ├── L
│   │   └── S
│   │       └── a
│   ├── ,
│   └── S
│       ├── (
│       ├── L
│       │   ├── L
│       │   │   └── S
│       │   │       └── a
│       │   ├── ,
│       │   └── S
│       │       └── a
│       └── )
└── )
```

**iii) $(a, ((a, a), (a, a)))$**
```text
S
├── (
├── L
│   ├── L
│   │   └── S
│   │       └── a

│   └── S
│       ├── (
│       ├── L
│       │   ├── L
│       │   │   └── S
│       │   │       ├── (
│       │   │       ├── L
│       │   │       │   ├── L
│       │   │       │   │   └── S
│       │   │       │   │       └── a
│       │   │       │   ├── ,
│       │   │       │   └── S
│       │   │       │       └── a
│       │   │       └── )
│       │   ├── ,
│       │   └── S
│       │       ├── (
│       │       ├── L
│       │       │   ├── L
│       │       │   │   └── S
│       │       │   │       └── a
│       │       │   ├── ,
│       │       │   └── S
│       │       │       └── a
│       │       └── )
│       └── )
└── )
```

### c) 构造 b) 中句子的最左推导

*   **i) $(a, a)$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (S, S) \Rightarrow (a, S) \Rightarrow (a, a)$$
*   **ii) $(a, (a, a))$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (S, S) \Rightarrow (a, S) \Rightarrow (a, (L)) \Rightarrow (a, (L, S)) \Rightarrow (a, (S, S)) \Rightarrow (a, (a, S)) \Rightarrow (a, (a, a))$$
*   **iii) $(a, ((a, a), (a, a)))$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (S, S) \Rightarrow (a, S) \Rightarrow (a, (L)) \Rightarrow (a, (L, S)) \Rightarrow (a, (S, S)) \Rightarrow (a, ((L), S)) \Rightarrow (a, ((L, S), S)) \Rightarrow (a, ((S, S), S)) \Rightarrow (a, ((a, S), S)) \Rightarrow (a, ((a, a), S)) \Rightarrow (a, ((a, a), (L))) \Rightarrow (a, ((a, a), (L, S))) \Rightarrow (a, ((a, a), (S, S))) \Rightarrow (a, ((a, a), (a, S))) \Rightarrow (a, ((a, a), (a, a)))$$

### d) 构造 b) 中句子的最右推导

*   **i) $(a, a)$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (L, a) \Rightarrow (S, a) \Rightarrow (a, a)$$
*   **ii) $(a, (a, a))$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (L, (L)) \Rightarrow (L, (L, S)) \Rightarrow (L, (L, a)) \Rightarrow (L, (S, a)) \Rightarrow (L, (a, a)) \Rightarrow (S, (a, a)) \Rightarrow (a, (a, a))$$
*   **iii) $(a, ((a, a), (a, a)))$**
    $$S \Rightarrow (L) \Rightarrow (L, S) \Rightarrow (L, (L)) \Rightarrow (L, (L, S)) \Rightarrow (L, (L, (L))) \Rightarrow (L, (L, (L, S))) \Rightarrow (L, (L, (L, a))) \Rightarrow (L, (L, (S, a))) \Rightarrow (L, (L, (a, a))) \Rightarrow (L, (S, (a, a))) \Rightarrow (L, ((L), (a, a))) \Rightarrow (L, ((L, S), (a, a))) \Rightarrow (L, ((L, a), (a, a))) \Rightarrow (L, ((S, a), (a, a))) \Rightarrow (L, ((a, a), (a, a))) \Rightarrow (S, ((a, a), (a, a))) \Rightarrow (a, ((a, a), (a, a)))$$

### e) 该文法产生的语言是什么？

*   **语言描述**：该文法产生的是由符号 $a$ 组成的**嵌套列表**（或称为广义表）。每个列表可以包含一个或多个元素，元素之间用逗号分隔，而元素本身既可以是单个字符 $a$，也可以是另一个嵌套的列表。这类似于 LISP 语言中的列表结构。

## 3. 考虑文法

$$
S \rightarrow aSbS \mid bSaS \mid \epsilon
$$

**题目：为某个句子构造两个不同的最左推导，以证明它是二义性的。**

*   **选择的句子**：`abab`
*   **最左推导 1**：
    $$
    \begin{aligned}
    S &\Rightarrow aSbS \quad &&\text{(使用 } S \rightarrow aSbS \text{)} \\
    &\Rightarrow abS \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换第一个 } S \text{)} \\
    &\Rightarrow abaSbS \quad &&\text{(使用 } S \rightarrow aSbS \text{，替换当前的 } S \text{)} \\
    &\Rightarrow ababS \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换第一个 } S \text{)} \\
    &\Rightarrow abab \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换最后一个 } S \text{)}
    \end{aligned}
    $$
*   **最左推导 2**：
    $$
    \begin{aligned}
    S &\Rightarrow aSbS \quad &&\text{(使用 } S \rightarrow aSbS \text{)} \\
    &\Rightarrow abSaSbS \quad &&\text{(使用 } S \rightarrow bSaS \text{，替换第一个 } S \text{)} \\
    &\Rightarrow abaSbS \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换第一个 } S \text{)} \\
    &\Rightarrow ababS \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换第一个 } S \text{)} \\
    &\Rightarrow abab \quad &&\text{(使用 } S \rightarrow \epsilon \text{，替换最后一个 } S \text{)}
    \end{aligned}
    $$
*   **关键要点说明**：
    对于同一个句子 `abab`，成功构造了两个完全不同的最左推导过程（在第二步展开时，一个使用了 $S \rightarrow \epsilon$，另一个使用了 $S \rightarrow bSaS$）。根据二义性文法的定义，只要能为一个句子找到两个不同的最左推导（或两棵不同的语法树），就可以证明该文法是二义性的。
