# LL(1) 文法综合练习 - 答案

## 题目一答案：FIRST 集与 FOLLOW 集计算

**文法：**
$$
\begin{aligned}
S &\to aC \mid AC \\
A &\to a \\
B &\to b \mid \epsilon \\
C &\to bC \mid B
\end{aligned}
$$

### 1. FIRST 集

* **$FIRST(A)$**：产生式 $A \to a$，首符号为 $a$。
  $FIRST(A) = \{a\}$

* **$FIRST(B)$**：产生式 $B \to b$ 首符号为 $b$，$B \to \epsilon$ 包含 $\epsilon$。
  $FIRST(B) = \{b, \epsilon\}$

* **$FIRST(C)$**：
  * $C \to bC$：首符号 $b$。
  * $C \to B$：将 $FIRST(B) \setminus \{\epsilon\} = \{b\}$ 加入，又因 $B \to \epsilon$，所以 $\epsilon \in FIRST(C)$。
  $FIRST(C) = \{b, \epsilon\}$

* **$FIRST(S)$**：
  * $S \to aC$：首符号 $a$。
  * $S \to AC$：将 $FIRST(A) \setminus \{\epsilon\} = \{a\}$ 加入。$A$ 不可推出 $\epsilon$，停止。
  $FIRST(S) = \{a\}$

### 2. FOLLOW 集

* **$FOLLOW(S)$**：$S$ 是开始符号。$FOLLOW(S) = \{\$\}$

* **$FOLLOW(C)$**：
  * $S \to aC$：$C$ 在产生式末尾，将 $FOLLOW(S) = \{\$\}$ 加入。
  * $S \to AC$：$C$ 在产生式末尾，将 $FOLLOW(S) = \{\$\}$ 加入（已存在）。
  $FOLLOW(C) = \{\$\}$

* **$FOLLOW(A)$**：
  * $S \to AC$：$A$ 后跟 $C$，将 $FIRST(C) \setminus \{\epsilon\} = \{b\}$ 加入。因 $C$ 可推出 $\epsilon$，还将 $FOLLOW(S) = \{\$\}$ 加入。
  $FOLLOW(A) = \{b, \$\}$

* **$FOLLOW(B)$**：
  * $C \to B$：$B$ 在产生式末尾，将 $FOLLOW(C) = \{\$\}$ 加入。
  $FOLLOW(B) = \{\$\}$

### 3. 汇总

| 非终结符 | FIRST 集       | FOLLOW 集   |
| :------: | :------------- | :---------- |
| $S$      | $\{a\}$        | $\{\$\}$    |
| $A$      | $\{a\}$        | $\{b, \$\}$ |
| $B$      | $\{b, \epsilon\}$ | $\{\$\}$ |
| $C$      | $\{b, \epsilon\}$ | $\{\$\}$ |

## 题目二答案：判断文法是否为 LL(1)

**文法：**
$$
\begin{aligned}
E &\to E + T \mid T \\
T &\to T * F \mid F \\
F &\to (E) \mid \text{id}
\end{aligned}
$$

**分析：**

该文法中存在**直接左递归**：
* $E \to E + T$（$E$ 出现在产生式右部的最左端）
* $T \to T * F$（$T$ 出现在产生式右部的最左端）

LL(1) 分析法是自顶向下的分析方法，遇到左递归时，分析器会不断用同一个产生式展开同一非终结符，永远无法匹配输入符号，导致**无限循环**。

**结论：该文法不是 LL(1) 文法。**

> 消除左递归后得到的等价文法即为题目三中的文法，该等价文法是 LL(1) 文法。

## 题目三答案：构造 LL(1) 分析表

**文法：**
$$
\begin{aligned}
E &\to TA \\
A &\to +TA \mid \epsilon \\
T &\to FB \\
B &\to *FB \mid \epsilon \\
F &\to (E) \mid \text{id}
\end{aligned}
$$

### 1. FIRST 集

* $FIRST(F) = \{(, \text{id}\}$
* $FIRST(B) = \{*, \epsilon\}$（$B \to *FB$ 得 $*$，$B \to \epsilon$ 得 $\epsilon$）
* $FIRST(T) = FIRST(F) = \{(, \text{id}\}$（$T \to FB$，$F$ 不可推出 $\epsilon$）
* $FIRST(A) = \{+, \epsilon\}$（$A \to +TA$ 得 $+$，$A \to \epsilon$ 得 $\epsilon$）
* $FIRST(E) = FIRST(T) = \{(, \text{id}\}$（$E \to TA$，$T$ 不可推出 $\epsilon$）

### 2. FOLLOW 集

* **$FOLLOW(E)$**：$E$ 是开始符号，$FOLLOW(E) = \{\$, )\}$（$)$ 来自 $F \to (E)$）。
* **$FOLLOW(A)$**：$E \to TA$，$A$ 在末尾，将 $FOLLOW(E)$ 加入。$FOLLOW(A) = \{\$, )\}$。
* **$FOLLOW(T)$**：
  * $E \to TA$：$T$ 后跟 $A$，将 $FIRST(A) \setminus \{\epsilon\} = \{+\}$ 加入；$A$ 可推出 $\epsilon$，再将 $FOLLOW(E) = \{\$, )\}$ 加入。
  * $A \to +TA$：$T$ 后跟 $A$，同理。
  $FOLLOW(T) = \{+, \$, )\}$
* **$FOLLOW(B)$**：$T \to FB$，$B$ 在末尾，将 $FOLLOW(T)$ 加入。$FOLLOW(B) = \{+, \$, )\}$。
* **$FOLLOW(F)$**：
  * $T \to FB$：$F$ 后跟 $B$，将 $FIRST(B) \setminus \{\epsilon\} = \{*\}$ 加入；$B$ 可推出 $\epsilon$，再将 $FOLLOW(T) = \{+, \$, )\}$ 加入。
  * $B \to *FB$：同理。
  $FOLLOW(F) = \{*, +, \$, )\}$

### 3. SELECT 集

| 产生式               | 计算过程                               | SELECT 集           |
| :---------------- | :--------------------------------- | :----------------- |
| $E \to TA$        | $FIRST(TA) = \{(, \text{id}\}$     | $\{(, \text{id}\}$ |
| $A \to +TA$       | $FIRST(+TA) = \{+\}$               | $\{+\}$            |
| $A \to \epsilon$  | $FOLLOW(A) = \{\$, )\}$            | $\{\$, )\}$        |
| $T \to FB$        | $FIRST(FB) = \{(, \text{id}\}$     | $\{(, \text{id}\}$ |
| $B \to *FB$       | $FIRST(*FB) = \{*\}$               | $\{*\}$            |
| $B \to \epsilon$  | $FOLLOW(B) = \{+, \$, )\}$         | $\{+, \$, )\}$     |
| $F \to (E)$       | $FIRST((E)) = \{(\}$               | $\{(\}$            |
| $F \to \text{id}$ | $FIRST(\text{id}) = \{\text{id}\}$ | $\{\text{id}\}$    |

同一非终结符的各产生式 SELECT 集两两交集均为空集，满足 LL(1) 条件。

### 4. LL(1) 分析表

| 非终结符 | $\text{id}$          | $+$                  | $*$               | $($             | $)$                 | $\$$                |
| :------- | :------------------- | :------------------- | :---------------- | :-------------- | :------------------ | :------------------ |
| $E$      | $E \to TA$           |                      |                   | $E \to TA$      |                     |                     |
| $A$      |                      | $A \to +TA$          |                   |                 | $A \to \epsilon$    | $A \to \epsilon$    |
| $T$      | $T \to FB$           |                      |                   | $T \to FB$      |                     |                     |
| $B$      |                      | $B \to \epsilon$     | $B \to *FB$       |                 | $B \to \epsilon$    | $B \to \epsilon$    |
| $F$      | $F \to \text{id}$    |                      |                   | $F \to (E)$     |                     |                     |

表中无冲突项，**该文法是 LL(1) 文法**。

## 题目五答案：SELECT 集与 LL(1) 判断

**文法：**
$$
\begin{aligned}
S &\to AB \mid CD \\
A &\to aA \mid a \\
B &\to b \\
C &\to cC \mid c \\
D &\to dD \mid d
\end{aligned}
$$

### 1. FIRST 集

* $FIRST(A) = \{a\}$
* $FIRST(B) = \{b\}$
* $FIRST(C) = \{c\}$
* $FIRST(D) = \{d\}$

### 2. SELECT 集

| 产生式 | 计算过程 | SELECT 集 |
| :----- | :------- | :-------- |
| $S \to AB$ | $FIRST(AB) = \{a\}$ | $\{a\}$ |
| $S \to CD$ | $FIRST(CD) = \{c\}$ | $\{c\}$ |
| $A \to aA$ | $FIRST(aA) = \{a\}$ | $\{a\}$ |
| $A \to a$ | $FIRST(a) = \{a\}$ | $\{a\}$ |
| $B \to b$ | $FIRST(b) = \{b\}$ | $\{b\}$ |
| $C \to cC$ | $FIRST(cC) = \{c\}$ | $\{c\}$ |
| $C \to c$ | $FIRST(c) = \{c\}$ | $\{c\}$ |
| $D \to dD$ | $FIRST(dD) = \{d\}$ | $\{d\}$ |
| $D \to d$ | $FIRST(d) = \{d\}$ | $\{d\}$ |

### 3. LL(1) 判断

逐一检查各非终结符的 SELECT 集交集：

* $S$：$SELECT(S \to AB) \cap SELECT(S \to CD) = \{a\} \cap \{c\} = \emptyset$ ✓
* $A$：$SELECT(A \to aA) \cap SELECT(A \to a) = \{a\} \cap \{a\} = \{a\} \neq \emptyset$ ✗
* $C$：$SELECT(C \to cC) \cap SELECT(C \to c) = \{c\} \cap \{c\} = \{c\} \neq \emptyset$ ✗
* $D$：$SELECT(D \to dD) \cap SELECT(D \to d) = \{d\} \cap \{d\} = \{d\} \neq \emptyset$ ✗

**结论：该文法不是 LL(1) 文法。**

$A$、$C$、$D$ 三个非终结符各自存在公共左因子，导致 SELECT 集冲突。需要先提取公共左因子：

$$
\begin{aligned}
A &\to aA' \quad &A' &\to A \mid \epsilon \\
C &\to cC' \quad &C' &\to C \mid \epsilon \\
D &\to dD' \quad &D' &\to D \mid \epsilon
\end{aligned}
$$

消除公共左因子后，再对新文法重复 LL(1) 判断流程即可。
