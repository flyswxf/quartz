### 1.  描述下列正规式（正则）定义的语言（请用汉语直白地描述该语言）

a) $0(0|1)^*0$
b) $((\varepsilon|0)1^*)^*$
c) $(0|1)^*0(0|1)(0|1)$
d) $0^*10^*10^*10^*$
e) $(00|11)^*((01|10)(00|11)^*(01|10)(00|11)^*)^*$

---

**解答：**
**a) $0(0|1)^*0$**
所有以 0 开头且以 0 结尾的、长度至少为 2 的由 0 和 0 组成的字符串

**b) $((\varepsilon|0)1^*)^*$**
包含空串在内的所有由 0 和 1 组成的字符串

**c) $(0|1)^*0(0|1)(0|1)$**
所有长度至少为 3，且倒数第三个字符为 `0` 的由 `0` 和 `1` 组成的字符串

**d) $0^*10^*10^*10^*$**
所有恰好包含 3 个 1 的由 0 和 1 组成的字符串

**e) $(00|11)^*((01|10)(00|11)^*(01|10)(00|11)^*)^*$**
所有包含偶数个 0 和偶数个 1 的由 0 和 1 组成的字符串

### 2. 为下列语言写出正规定义 (或正规式、正规文法、有限自动机)

**a) 包含五个元音，且按顺序排列的所有字母串 (RE)**
元音按 `a, e, i, o, u` 的顺序出现
$$other \rightarrow [bcdfghjklmnpqrstvwxyz]$$
$$string \rightarrow other^* a (a|other)^* e (e|other)^* i (i|other)^* o (o|other)^* u (u|other)^*$$

**b) 字母按字典升序排列的所有字母串 (RE)**
$$a^* b^* c^* \dots z^*$$

**c) 以 `/*` 开始，`*/` 结束的注释，中间不能包含 `*/`，除非包含在 `"` 和 `"` 中 (RE)**
```
\/ \* ([^*"]* | ".*" | \*+[^/] )* \* \/
```

其中，
- `[^*"]*`：匹配任何不是\*也不是"的字符序列（普通文本）。
- `".*"`：匹配双引号字符串，允许字符串内包含任意字符（包括*/）
- `\*+[^/]`：匹配一个或多个\*，后跟一个不是/的字符，确保*/不会在字符串外出现


**d) 不包含重复数字的数字串（正规定义 + 扩展正则表达式）**
```
has_repeat -> .*(\d).*\1.*
RE -> ^(?!has_repeat)\d+$
```
其中:
- `has_repeat` 匹配任何包含重复数字的字符串。`(\d)` 捕获一个数字，`\1` 反向引用匹配与之相同的数字
- `(?!has_repeat)` 是前向否定断言，在字符串开头排除了任何包含重复数字的情况，剩下的 `\d+` 即可安全地匹配无重复的数字串

**e) 包含至多一个重复数字的数字串（正规定义 + 扩展正则表达式）**
```
two_diff_repeats -> .*(\d).*\1.*(?!\1)(\d).*\2.*
RE -> ^(?!two_diff_repeats)\d+$
```
其中:
- `two_diff_repeats` 匹配包含两种不同数字重复的情况（如 `1..1..2..2`）
  - `.*(\d).*\1.*`：先捕获一个数字（分组 1），并确保它重复出现（\1）
  - `(?!\1)(\d)`：再捕获一个不同于分组 1的数字（分组 2）。(?!\1) 是负向先行断言，保证第二个数字和第一个不一样
  - `.*\2.*`：确保分组 2 的这个数字也重复出现（\2）


**f) 包含偶数个 0 和奇数个1 的 0,1 串（正规定义）**

```
even_0_even_1 → (00|11)* ((01|10)(00|11)*(01|10)(00|11)*)*  
even_0_odd_1  → 1 even_0_even_1 | 0 (00|11)*(01|10) even_0_even_1
```
其中:
- even_0_even_1: 包含偶数个 0 和偶数个 1的0、1串
- even_0_odd_1:包含偶数个0和奇数个1的0、1串, 有以1开头，包含偶数个0、奇数个1和以0开头，包含偶数个0，奇数个1两种情况
