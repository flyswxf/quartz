### $AG(Start \to EF Heat)$

检查所有满足 $Start$ 的状态 $\{2, 5, 6, 7\}$：

- **状态 6**: 存在路径 $6 \to 7$，到达 $Heat$。$EF Heat$ 为真。
- **状态 5**: 存在路径 $5 \to 3 \to 6 \to 7$，最终到达 $Heat$。$EF Heat$ 为真。
- **状态 2**: 存在路径 $2 \to 5 \to 3 \to 6 \to 7$，最终到达 $Heat$。$EF Heat$ 为真。
因此所有 Start 状态都至少存在一条通往加热状态的路径。

对于 $\neg Start$ 的状态 $\{1,3,4\}$,  $Start \to EF Heat$ 逻辑蕴涵自动成立

**因此模型是满足该公式的**
**满足该公式的状态是全集 $\{1, 2, 3, 4, 5, 6, 7\}$**

### Assignment 7：验证 Hoare 三元组（Sort 的部分正确性）

要验证
$$\{\,P\,\}\ \texttt{Sort}\ \{\,Q\,\}$$
其中
$$P \equiv (n>0)\ \land\ \forall k\,(0\le k<n \to a[k]\in \mathbb N)$$
$$Q \equiv \forall i,j\,(0\le i\le j<n \to a[i]\le a[j])$$

程序（冒泡排序）为：
```c
i = 0;
while (i < n-1) {
  j = 0;
  while (j < n-i-1) {
    if (a[j] > a[j+1]) {
      temp = a[j];
      a[j] = a[j+1];
      a[j+1] = temp;
    }
    j = j + 1;
  }
  i = i + 1;
}
```

#### 外层循环不变式

定义外层循环不变式 $I(i)$：
$$I(i)\equiv (0\le i\le n-1)\ \land\ S(i)\ \land\ R(i)\ \land\ N(a)$$
其中
$$S(i)\equiv \forall p,q\,(n-i\le p\le q<n\to a[p]\le a[q])$$
表示后缀 $a[n-i..n-1]$ 已经非降序排好；
$$R(i)\equiv \forall p,q\,(0\le p<n-i\land n-i\le q<n\to a[p]\le a[q])$$
表示前缀任一元素都不大于该后缀任一元素；
$$N(a)\equiv \forall k\,(0\le k<n\to a[k]\in\mathbb N)$$
表示数组元素仍在 $\mathbb N$ 中。

**初始化**：执行 `i = 0` 后，$0\le i\le n-1$ 成立（由 $n>0$ 得 $n-1\ge 0$）。此时后缀区间 $[n..n-1]$ 为空，$S(0)$ 与 $R(0)$ 真值空泛成立；$N(a)$ 由 $P$ 给出，因此 $I(0)$ 成立。

**保持性**：假设外层循环某次迭代开始时 $I(i)$ 成立且 $i<n-1$。证明执行完内层循环并做 `i=i+1` 后 $I(i+1)$ 成立。关键是：内层循环结束时，位置 $n-i-1$ 上是前缀 $a[0..n-i-1]$ 的最大值。

#### 内层循环不变式（固定外层 i）

令 $m=n-i-1$（内层循环的右端点）。定义内层循环不变式 $J(j)$：
$$J(j)\equiv (0\le j\le m)\ \land\ a[j]=\max(a[0..j])\ \land\ S(i)\ \land\ R(i)\ \land\ N(a)$$

**初始化**：`j=0` 后，$a[0]=\max(a[0..0])$ 显然成立；其余部分由 $I(i)$ 继承，因此 $J(0)$ 成立。

**保持性**：假设 $J(j)$ 成立且 $j<m$。循环体比较 $a[j]$ 与 $a[j+1]$：
- 若 $a[j]\le a[j+1]$，不交换，则 $a[j+1]\ge a[j]=\max(a[0..j])$，从而 $a[j+1]=\max(a[0..j+1])$；
- 若 $a[j]>a[j+1]$，交换后 $a[j+1]$ 变为原来的 $a[j]=\max(a[0..j])$，因此同样有 $a[j+1]=\max(a[0..j+1])$。

交换仅发生在下标 $\le m$ 的前缀范围内，不影响 $S(i)$、$R(i)$；同时也不改变 $N(a)$。因此执行 `j=j+1` 后得到 $J(j+1)$。

**终止**：内层循环结束时 $j=m$，由 $J(m)$ 得
$$a[m]=\max(a[0..m])=\max(a[0..n-i-1]).$$

#### 推出外层保持性

内层结束后执行 `i=i+1`，新的后缀起点变为 $n-(i+1)=m$。由上式可得对任意 $p<m$ 有 $a[p]\le a[m]$，结合旧的 $S(i)$ 与 $R(i)$，得到新的 $S(i+1)$ 与 $R(i+1)$；并且 $0\le i+1\le n-1$、$N(a)$ 仍成立，因此 $I(i+1)$ 成立。

**终止推出后置条件**：外层循环退出时 $i\ge n-1$，又由不变式 $i\le n-1$ 得 $i=n-1$。此时
- $S(n-1)$ 给出 $a[1..n-1]$ 非降序；
- $R(n-1)$ 给出 $a[0]\le a[q]$ 对所有 $1\le q<n$ 成立。

于是对任意 $0\le i\le j<n$ 都有 $a[i]\le a[j]$，即 $Q$ 成立，从而 $\{P\}\ \texttt{Sort}\ \{Q\}$ 的部分正确性成立。
