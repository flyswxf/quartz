```
p:=0;
q:=n - 1;
while p < q do
	if f(p) < f(q) then
		q:=q - 1
	else
		p:=p + 1
	end
	invariant
		p ∈ 0..n - 1
		q ∈ 0..n - 1
		min(f[0..n - 1]) ∈ f[p..q]
	variant
		q - p
	end
```
PRE:
```
n > 0
f ∈ 0..n - 1 -> N
```
POST:
```
p ∈ dom(f)
f(p) = min(ran(f))
```

### 算法原理
从数组两端向中间搜索, 当一端比另一端小时, 较大的一定不是最小值, 因此下标向中间移动
