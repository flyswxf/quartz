```
i := n - 1; 
while f(i) ≠ v do 
	i := i - 1
invariant 
	i ∈ 0..n - 1
	v ∈ f[0..i]
variant
	n - i
end
```
PRE:
```
n > 0
f ∈ 0..n - 1 -> N
v ∈ ran(f)
```
POST:
```
i ∈ dom(f)
f(i) = v
```
在搜索算法(从n开始向下搜索)中, 搜索不会到达边界(i!=0)是一个隐含已知项, 可以**通过P,Q推出** 

# v $\in$ f[0...i], f(i) $\ne$   v $\vdash$ i $\ne$ 0

利用[[反证法的形式化表示]]CT2, 交换 $\vdash$ 前后项(逆否)
v $\in$ f[0...i],  i = 0 $\vdash$ f(i) = v
v $\in$ f[{0}]
v $\in$ {f(0)}
v $\in$ f(0)
得证
