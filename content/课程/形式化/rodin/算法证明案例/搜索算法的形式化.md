## 在一维数组中搜索
```
i := n-1; 
while f(i) ≠ v do 
	i := i - 1
invariant 
	i ∈ 0..n - 1
	v ∈ f[0..i]
variant
	i
end
```
PRE:
```
n > 0
f ∈ 0..n - 1 -> N
v ∈ ran(f)
```
POST:
```
i ∈ dom(f)
f(i) = v
```
证明需要:
1. 找到隐含已知项i$\ne$ 0 [[搜索算法i!=0的证明]], 否则INV无法证明
2. 再根据[[程序正确性验证引理]]正常证明即可


## 在二维数组中搜索
```
i:=m - 1;
j:=n - 1;
while f(i|->j) ≠ v do
	if j = 0 then
		i:=i - 1;
		j:=n - 1
	else
		j:=j - 1
	invariant
		i ∈ 0..m-1
		j ∈ 0..n-1
		v ∈ f[((0..i - 1) × (0..n - 1)) ∪ ({i} × (0..j))]
	variant
		i × n ＋ j
	end
end
```
PRE:
```
m > 0
n > 0
f ∈ (0..m - 1) × (0..n - 1) -> N
v ∈ ran(f)
```
POST:
```
i |-> j ∈ dom(f)
f(i |-> j) = v
```

- v的范围:
	- `((0..i - 1) × (0..n - 1))`代表二维数组中行完整的部分
	- `({i} × (0..j))`代表二维数组中行不完整的部分
- 证明需要额外翻译if语句, 参考[[if...then的翻译]]
