定位与适用：
- **边界值**是等价类的临界点；另有**次边界**需分析实现识别。
- 主要适用于数值/集合；逻辑变量需谨慎，关注与数量/时间/权限边界的组合。

| 类型               | 必测边界与邻近值                                                | 注释                        |
| ---------------- | ------------------------------------------------------- | ------------------------- |
| 数值区间 `(a,b)`     | **a,a+1,a-1,b,b+1,b-1,区间内正常点($\frac{a+b}{2}$)**         | 7个值                       |
| 个数约束 `[min,max]` | **min**、**max**、**min-1**、**min+1**、**max-1**、**max+1** | 覆盖**空/单元素/满/超**等极端规模      |
| 有序集合             | **第一个**、**最后一个**、必要时相邻元素                                | 比较/排序稳定性与边界迭代             |
| 数据结构边界（容量 `N`）   | **N-1**、**N**、**N+1**                                   | 溢出/截断/性能退化；同时测**空**与**单** |
| 输出范围             | **边界值**、**邻近值**                                         | 格式、单位、**精度**与舍入规则         |
| 隐含次边界            | 类型转换、舍入、时间粒度、并发上限、资源配额                                  | 规格未写明，需代码/架构分析            |

### 示例：
- 数值区间 `[0,100]` → 测试：**-1, 0, 1, 99, 100, 101, 50**。
- 个数约束 `[1,10]` → 测试：**0, 1, 2, 9, 10, 11**。

注意要点：
- 先判断区间是**开/闭**，再选边界与越界。
- 逻辑变量测试两值及与**数量/时间/权限**边界的组合。
- 输出同样做边界验证：**范围、格式、精度**。
- 优先覆盖“**边界** + **越界** + **正常点**”。

最小清单（拿来即用）：
- 覆盖：**边界值**、**边界邻近值**、**正常点**。
- 包含：**空、单、满、超**等极端规模。
- 关注：**类型/精度/时间/并发/资源**的隐式边界。
