# Specification Based Testing (SBT) 练习题

## 一、判断题 (True/False)

1.  **[判断]** Specification-based testing (基于规格说明的测试) 也被称为白盒测试 (White-box testing)。
2.  **[判断]** 等价类划分 (Equivalence Partitioning) 只能应用于输入域，不能应用于输出域。
3.  **[判断]** 在边界值分析 (Boundary Value Analysis) 中，我们通常测试确切的边界值以及紧邻边界内部和外部的值。
4.  **[判断]** 决策表测试 (Decision Table Testing) 最适合用于输入的不同组合会导致不同动作或输出的场景。
5.  **[判断]** 状态转换测试 (State Transition Testing) 适用于具有有限个状态以及导致状态转换的事件的系统。
6.  **[判断]** 进行基于规格说明的测试需要了解程序的内部代码结构和实现细节。
7.  **[判断]** 在等价类划分中，如果一个等价类中的一个测试用例执行通过，我们通常假设该等价类中的所有其他值也能通过。
8.  **[判断]** 边界值分析要求测试数据必须是有序的 (ordered)，例如数字或日期。
9.  **[判断]** 用例测试 (Use Case Testing) 主要侧重于隔离测试单个组件的功能，而不是业务流程。
10. **[判断]** 基于规格说明的测试的主要目标是发现实现 (Implementation) 与规格说明 (Specification) 之间的差异。

## 二、选择题 (Multiple Choice)

1.  以下哪项 **不是** 基于规格说明的测试 (Specification-based testing) 技术？
    A. 等价类划分 (Equivalence Partitioning)
    B. 边界值分析 (Boundary Value Analysis)
    C. 语句覆盖 (Statement Coverage)
    D. 决策表测试 (Decision Table Testing)

2.  在应用等价类划分时，需要识别有效等价类和无效等价类。以下说法正确的是：
    A. 只需要测试有效等价类。
    B. 只需要测试无效等价类。
    C. 有效等价类和无效等价类都应该测试。
    D. 等价类划分仅适用于数值输入。

3.  一个系统接受 1 到 100 (含) 之间的整数输入。使用标准的二值边界值分析 (2-value Boundary Value Analysis)，应该测试哪些值？
    A. 0, 1, 100, 101
    B. 1, 2, 99, 100
    C. 0, 1, 50, 100, 101
    D. 1, 100

4.  对于具有多个逻辑条件组合的复杂业务逻辑，哪种测试技术最有效？
    A. 边界值分析
    B. 状态转换测试
    C. 决策表测试
    D. 用例测试

5.  状态转换图 (State Transition Diagram) 通常包含以下哪些元素？
    A. 状态 (States)、转换 (Transitions)、事件 (Events)、动作 (Actions)
    B. 输入 (Inputs)、输出 (Outputs)、边界 (Boundaries)
    C. 类 (Classes)、对象 (Objects)、方法 (Methods)
    D. 参与者 (Actors)、用例 (Use Cases)

6.  在等价类划分中，如果输入条件规定了一个范围 (例如：10 到 50)，通常识别出多少个 **有效** 等价类？
    A. 0 个
    B. 1 个
    C. 2 个
    D. 3 个

7.  基于规格说明的测试的主要信息来源是什么？
    A. 源代码 (Source code)
    B. 需求规格说明书 (Requirements specification)
    C. 数据库模式 (Database schema)
    D. 项目计划 (Project plan)

8.  关于用例测试 (Use Case Testing)，以下哪项是正确的？
    A. 它确保 100% 的代码覆盖率。
    B. 它是为了演练业务场景 (Business scenarios) 而设计的。
    C. 它是一种基于结构的测试技术。
    D. 它主要关注边界值的处理。

9.  如果一个程序要求用户从下拉列表的 5 个可用选项中选择一项，哪种测试技术最适合确保每个选项都被正确处理？
    A. 边界值分析
    B. 等价类划分
    C. 状态转换测试
    D. 决策表

10. 成对测试 (Pairwise testing) 是一种组合测试策略，它的主要目的是：
    A. 测试所有可能的输入组合。
    B. 测试所有输入参数值的两两组合 (Pairs)。
    C. 测试输入参数的边界。
    D. 测试状态之间的转换。

## 答案与解析

### 一、判断题答案

1.  **False (错)** - SBT 是黑盒测试 (Black-box testing)。
2.  **False (错)** - 等价类划分既可用于输入域，也可用于输出域。
3.  **True (对)** - 标准做法通常测试边界值本身以及紧邻的一个值 (如 min-1, min, max, max+1)。
4.  **True (对)** - 决策表擅长处理逻辑组合。
5.  **True (对)** - 状态机的典型应用场景。
6.  **False (错)** - SBT 是黑盒测试，不需要了解内部代码。
7.  **True (对)** - 这是等价类划分的核心假设。
8.  **True (对)** - BVA 依赖于数据的顺序特性。
9.  **False (错)** - 用例测试侧重于用户场景和业务流程，而非组件隔离。
10. **True (对)** - 验证软件是否符合需求规格。

### 二、选择题答案

1.  **C** - 语句覆盖属于白盒/结构化测试。
2.  **C** - 为了充分测试，必须覆盖正常(有效)和异常(无效)情况。
3.  **A** - 0 (min-1), 1 (min), 100 (max), 101 (max+1) 是最典型的边界值集合。
4.  **C** - 决策表专门用于处理复杂的逻辑规则组合。
5.  **A** - 状态图的基本元素。
6.  **B** - 对于一个连续范围 (10-50)，通常有 1 个有效等价类 (10-50) 和 2 个无效等价类 (<10, >50)。
7.  **B** - 顾名思义，基于规格说明。
8.  **B** - 用例反映了真实用户的操作流程。
9.  **B** - 每个选项可以视为一个等价类，或者所有有效选项为一个等价类(如果处理逻辑相同)。但在确保“每个选项被处理”的语境下，通常利用等价类思想去覆盖不同类别。
10. **B** - Pairwise 的定义就是覆盖所有参数对的组合。
