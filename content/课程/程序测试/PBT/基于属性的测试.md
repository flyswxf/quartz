## 核心概念
- 属性：用于判断程序行为是否正确的规则。
- 基于属性的测试：用随机生成的数据验证被测代码是否满足给定属性。

## 典型流程
- [[生成随机输入]]。
- 检查**前置条件**是否满足。
- 验证**属性**在这些输入上是否成立。
- 缩减反例得到**最小反例**。

## Jqwik 示例：成绩判定
- 业务规则：成绩范围 `[1.0, 10.0]`；`grade >= 5.0` 通过，否则不通过；范围外抛异常。
- 派生属性：
  - Fail：`[1.0, 5.0)` 返回 `false`。
  - Pass：`[5.0, 10.0]` 返回 `true`。
  - Invalid：`< 1.0` 或 `> 10.0` 抛异常。

## Jqwik 编写要点
- 使用 `@Property` 声明属性测试。
- 使用 `@ForAll` 标注由框架生成的参数。
- 使用 `@FloatRange(min=..., max=..., maxIncluded=...)` 控制生成范围。
- 使用 `@Provide` 自定义生成器，如 `invalidGrades()`。
- 使用 `Assertions.assertThat(...)` 进行属性的断言。

## 完整 Jqwik 示例
```java
import net.jqwik.api.*;                         // jqwik 核心 API（Property、Arbitrary 等）
import net.jqwik.api.constraints.FloatRange;    // 约束注解：限定生成数据范围
import org.assertj.core.api.Assertions;         // 断言库：更友好的断言语法

class PassingGrade {
  // 业务逻辑：根据成绩判断是否通过
  boolean passed(float grade) {
    // 边界检查：只接受 [1, 10] 范围，否则抛异常
    if (grade < 1 || grade > 10) throw new IllegalArgumentException();
    // 规则：>= 5 视为通过
    return grade >= 5;
  }
}

class PassingGradesPBTest {
  private final PassingGrade pg = new PassingGrade();

  @Property // 属性测试：对大量随机输入检查不变量
  void fail(@ForAll @FloatRange(min = 1f, max = 5f, maxIncluded = false) float grade) {
    // 随机生成 [1, 5) 的成绩，期望不通过
    Assertions.assertThat(pg.passed(grade)).isFalse();
  }

  @Property
  void pass(@ForAll @FloatRange(min = 5f, max = 10f, maxIncluded = true) float grade) {
    // 随机生成 [5, 10] 的成绩，期望通过
    Assertions.assertThat(pg.passed(grade)).isTrue();
  }

  @Property
  void invalid(@ForAll("invalidGrades") float grade) {
    // 对范围外成绩，期望抛出非法参数异常
    Assertions.assertThatThrownBy(() -> pg.passed(grade))
      .isInstanceOf(IllegalArgumentException.class);
  }

  @Provide // 自定义生成器：提供非法成绩
  Arbitrary<Float> invalidGrades() {
    // 组合两个生成器：< 1 或 > 10 的浮点数
    return Arbitraries.oneOf(
      Arbitraries.floats().lessThan(1f),
      Arbitraries.floats().greaterThan(10f)
    );
  }
}
```

## 缩减与定位
- 当实现写成 `grade > 5` 时，`pass` 属性会失败，框架自动缩减到最小反例 `5.0`。
- 失败报告包含随机种子与尝试次数，可据此复现并修复。
