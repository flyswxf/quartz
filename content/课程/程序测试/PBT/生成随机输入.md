`@ForAll` 为属性方法参数生成测试输入。

### 默认生成：
未指定 `value` 时，jqwik对支持类型使用内置生成器。
```java
// 默认生成器示例
@Property
void commutative(@ForAll int a, @ForAll int b) {
  Assertions.assertThat(a + b).isEqualTo(b + a);
}

@Property
void boundedList(@ForAll List<@IntRange(min=0, max=10) Integer> xs) {
  Assertions.assertThat(
    xs.stream().allMatch(x -> x >= 0 && x <= 10)
  ).isTrue();
}
```

### 自定义生成：
  - 使用 `@ForAll("providerName")` 指定@Provide声明的方法。
  - @Provide声明方法返回 `Arbitrary<? extends TParam>`，`TParam` 为参数的静态类型。
  - 以 `Arbitraries.*` 创建基础生成器，可再进行 `filter`、`map`、`flatMap`、`combine` 等操作。
```java
// 使用@Provide自定义生成器
@Property
void invalidGradesThrow(@ForAll("invalidGrades") float grade) {
  Assertions.assertThatThrownBy(() -> new PassingGrade().passed(grade))
    .isInstanceOf(IllegalArgumentException.class);
}

@Provide
Arbitrary<Float> invalidGrades() {
  return Arbitraries.oneOf(
    Arbitraries.floats().lessThan(1f),
    Arbitraries.floats().greaterThan(10f)
  );
}

class PassingGrade {
  boolean passed(float grade) {
    if (grade < 1 || grade > 10) throw new IllegalArgumentException();
    return grade >= 5;
  }
}
```
#### 自定义生成器示例
```java
// 过滤：生成 0..100 的偶数
@Provide Arbitrary<Integer> even0to100() {
  return Arbitraries.integers().between(0, 100).filter(i -> i % 2 == 0);
}

// 映射：大写字母字符串
@Provide Arbitrary<String> upperAlpha() {
  return Arbitraries.strings().alpha().map(String::toUpperCase);
}

// 扁平映射：长度依赖的字符串
@Provide Arbitrary<String> lenMatched() {
  return Arbitraries.integers().between(0, 10)
    .flatMap(n -> Arbitraries.strings().ofMinLength(n).ofMaxLength(n));
}

// 组合：用两个生成器构造更复杂值
@Provide Arbitrary<String> combined() {
  return Arbitraries.combine(
      Arbitraries.integers().between(0, 10),
      Arbitraries.strings().alpha()
    ).as((n, s) -> s.substring(0, Math.min(n, s.length())));
}
```
