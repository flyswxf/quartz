## 1. 样本过窄或不具代表性
- 问题：生成的取值集合过小，导致属性仅被调用极少次数，覆盖不足。

```java
// 错误示例：只会生成一个值 400，属性几乎不被调用
@Property void multiplesOf400AreLeapYearsBad1(@ForAll("multiplesOf400Bad1") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400Bad1() {
  return Arbitraries.integers().between(100, 500)
    .filter(n -> n % 400 == 0); // 仅匹配到 400
}
```

```java
// 正确示例：用映射构造丰富样本（多个 400 的倍数）
@Property void multiplesOf400AreLeapYears(@ForAll("multiplesOf400") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400() {
  return Arbitraries.integers().between(0, 100) // 多个基数
    .map(n -> n * 400);                         // 映射为 400 的倍数
}
```

## 2. 过滤导致无法找到值/大量丢弃
- 问题：过滤条件过于苛刻，出现高拒绝率或 `TooManyFilterMissesException`。

```java
// 错误示例：组合后再过滤导致拒绝率极高
@Property void multiplicationBad(@ForAll("numbersWithProductBad") Tuple3<Integer,Integer,Integer> t) {
  var n1 = t.get1(); var n2 = t.get2(); var n3 = t.get3();
  Assertions.assertThat(n1 * n2).isEqualTo(n3);
}

@Provide Arbitrary<Tuple3<Integer,Integer,Integer>> numbersWithProductBad() {
  var a = Arbitraries.integers();
  var b = Arbitraries.integers();
  var c = Arbitraries.integers();
  return Combinators.combine(a, b, c)
    .filter((n1, n2, n3) -> n1 * n2 == n3) // 大量丢弃
    .as(Tuple::of);
}
```

```java
// 正确示例：派生满足约束的值，避免过滤
@Property void multiplication(@ForAll("numbersWithProduct") Tuple3<Integer,Integer,Integer> t) {
  var n1 = t.get1(); var n2 = t.get2(); var n3 = t.get3();
  Assertions.assertThat(n1 * n2).isEqualTo(n3);
}

@Provide Arbitrary<Tuple3<Integer, Integer, Integer>> numbersWithProduct() {
  var a = Arbitraries.integers();
  var b = Arbitraries.integers();
  return Combinators.combine(a, b)
    .as((x, y) -> Tuple.of(x, y, x * y)); // 直接构造第三个值
}
```

- 唯一性与固定大小约束需与取值域匹配。

```java
// 错误示例：从 0..5 仅 6 个不同值中生成 10 个唯一元素，必然失败
@Property void listUniqueBad(@ForAll @Size(10) @UniqueElements List<@IntRange(min=0, max=5) Integer> numbers) {
  // 测试主体省略
}
```

```java
// 正确示例 1：扩大取值域以满足唯一性
@Property void listUniqueOk1(@ForAll @Size(10) @UniqueElements List<@IntRange(min=0, max=100) Integer> numbers) {
  // 测试主体省略
}

// 正确示例 2：降低 size 或使用 Set 类型并扩大范围
@Property void setUniqueOk(@ForAll Set<@IntRange(min=0, max=100) Integer> numbers) {
  Assume.that(numbers.size() >= 10);
}
```

- 前置条件应通过生成器保证，而非依赖 `Assume` 带来高拒绝率。

```java
// 错误示例：大量拒绝造成耗尽
@Property void multiplesBad(@ForAll int year) {
  Assume.that(year % 400 == 0);
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

// 正确示例：直接生成满足条件的输入
@Property void multiples(@ForAll("multiplesOf400") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}
```

## 3. 不要用导致大量丢弃的过滤
- 核心：用过滤挑选稀有值会让框架生成大量无用样本并全部丢弃，效率低且可能耗尽。

```java
// 错误示例：从所有整数中过滤 400 的倍数，丢弃率极高
@Property void multiplesOf400Bad2(@ForAll("multiplesOf400Bad2") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400Bad2() {
  return Arbitraries.integers() // 全域整数
    .filter(n -> n % 400 == 0); // 大量丢弃非倍数
}
```

```java
// 正确示例：使用映射直接生成 400 的倍数，无需丢弃
@Property void multiplesOf400Ok(@ForAll("multiplesOf400") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400() {
  return Arbitraries.integers().between(0, 1_000_000)
    .map(n -> n * 400);
}
```

```java
// 错误示例：通过过滤生成回文字符串，命中率极低
@Provide Arbitrary<String> palindromeStringsBad() {
  return Arbitraries.strings()
    .filter(s -> s.equals(new StringBuilder(s).reverse().toString()));
}
```

```java
// 正确示例：构造式生成回文，避免过滤
@Property void addingReverseYieldsPalindrome(@ForAll String str) {
  String palindrome = str + new StringBuilder(str).reverse();
  Assertions.assertThat(Palindrome.isPalindrome(palindrome)).isTrue();
}

@Property void addingReverseWithMiddleCharYieldsPalindrome(@ForAll String str, @ForAll char c) {
  String palindrome = str + c + new StringBuilder(str).reverse();
  Assertions.assertThat(Palindrome.isPalindrome(palindrome)).isTrue();
}
```

> 要点：尽量用“派生/构造”满足约束；当约束稀有时，不要依赖 `filter` 去碰运气。

## 4. 不要“滥用”jqwik（伪装成PBT的例子测试）
- 核心：使用 jqwik 的注解或类并不自动等于 PBT；如果只测试少量固定示例，本质仍是例子测试。

```java
// 错误示例：@Example 仅测试一个固定样例，不是属性测试
@Example void multiplesOf400AreLeapYearsBad3() {
  Assertions.assertThat(LeapYear.isLeapYear(2000)).isTrue();
}
```

```java
// 错误示例：手动采样固定集合中的一个元素，每次只测一个例子
@Property void testRandomYrsMultipleOf400() {
  Arbitrary<Integer> yrs = Arbitraries.of(4000, 2400, 2000, 2800, 400, 800, 1200, 1600);
  int year = yrs.sample(); // 不是 @ForAll，且每次只测一个
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}
```

```java
// 正确示例：用 @ForAll + 生成器覆盖广域的 400 倍数
@Property void multiplesOf400AreLeapYears(@ForAll("multiplesOf400") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400() {
  return Arbitraries.integers().between(0, 1_000_000).map(n -> n * 400);
}
```

## 5. 不要在测试中重复生产代码
- 核心：测试不应复制被测实现的逻辑，否则会把同样的 bug 搬到测试里，无法发现问题。

```java
// 错误示例：生成器用生产逻辑（回文判定）来过滤，重复实现
@Provide Arbitrary<String> palindromeStringsBad() {
  return Arbitraries.strings()
    .filter(s -> s.equals(new StringBuilder(s).reverse().toString()));
}
```

```java
// 正确示例：构造式生成，再用“外部定义的属性”验证
@Property void addingReverseYieldsPalindrome(@ForAll String str) {
  String palindrome = str + new StringBuilder(str).reverse();
  Assertions.assertThat(Palindrome.isPalindrome(palindrome)).isTrue();
}

@Property void addingReverseWithMiddleCharYieldsPalindrome(@ForAll String str, @ForAll char c) {
  String palindrome = str + c + new StringBuilder(str).reverse();
  Assertions.assertThat(Palindrome.isPalindrome(palindrome)).isTrue();
}
```


## 6. 不要用现有实现充当“判定器”（oracle）
- 核心：用另一份实现（或库函数）来当“真值判定器”，可能把相同缺陷一起带进来；更好的做法是验证行为性质。

```java
// 错误示例：用 List 的 indexOf 充当 oracle
@Property void indexOfShouldFindFirstValueBad(
  @ForAll @Size(20) List<@IntRange(min=-1000, max=1000) Integer> numbers,
  @ForAll @IntRange(min=-1000, max=1000) int value
) {
  int result = ArrayUtils.indexOf(numbers, value);
  Assertions.assertThat(result).isEqualTo(numbers.indexOf(value));
}
```

```java
// 正确示例：验证“性质”而非比对另一个实现
@Property void indexOfShouldFindFirstValue(
  @ForAll @Size(20) List<@IntRange(min=-1000, max=1000) Integer> numbers,
  @ForAll @IntRange(min=-1000, max=1000) int value
) {
  int result = ArrayUtils.indexOf(numbers, value);
  if (result == -1) {
    Assertions.assertThat(numbers.stream().noneMatch(v -> v == value)).isTrue();
  } else {
    Assertions.assertThat(result).isBetween(0, numbers.size() - 1);
    Assertions.assertThat(numbers.get(result)).isEqualTo(value);
    Assertions.assertThat(numbers.subList(0, result).stream().noneMatch(v -> v == value)).isTrue();
  }
}
```

## 7. 不要手工做框架应该做的事
- 核心：避免手写随机数或在属性里用 `if`/`Assume` 过滤稀有值；应通过生成器直接产生满足前置条件的输入。

```java
// 错误示例：在属性中手工调用随机数选择索引
@Property void testValidElementBad(
  @ForAll @Size(20) List<@IntRange(min=-1000, max=1000) Integer> numbers,
  @ForAll @IntRange(min=-1000, max=1000) int element,
  @ForAll @IntRange(min=0, max=19) int start
) {
  java.util.Random rng = new java.util.Random();
  int index = start + rng.nextInt(20 - start); // 手工随机
  numbers.add(index, element);
  int result = ArrayUtils.indexOf(numbers, element, start);
  Assertions.assertThat(result).isEqualTo(index);
}
```

```java
// 正确示例：用生成器确保索引在范围内
@Property void testValidElement(
  @ForAll("listAndIndex") Tuple2<List<Integer>, Integer> data,
  @ForAll @IntRange(min=-1000, max=1000) int element
) {
  var numbers = data.get1();
  var index = data.get2();
  numbers.add(index, element);
  int result = ArrayUtils.indexOf(numbers, element, 0);
  Assertions.assertThat(result).isEqualTo(index);
}

@Provide Arbitrary<Tuple2<List<Integer>, Integer>> listAndIndex() {
  Arbitrary<List<Integer>> listArb = Arbitraries.integers().between(-1000, 1000).list().ofSize(20);
  return listArb.flatMap(list -> Arbitraries.integers().between(0, list.size())
    .map(i -> Tuple.of(list, i)));
}
```

```java
// 错误示例：在属性中用 if 过滤稀有值，导致大部分调用什么都不断言
@Property void multiplesOf400AreLeapYearsBad1(@ForAll int year) {
  if (year % 400 == 0) {
    Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
  }
}
```

```java
// 正确示例：直接生成满足条件的 year，无需 if/Assume
@Property void multiplesOf400(@ForAll("multiplesOf400") int year) {
  Assertions.assertThat(LeapYear.isLeapYear(year)).isTrue();
}

@Provide Arbitrary<Integer> multiplesOf400() {
  return Arbitraries.integers().between(0, 1_000_000).map(n -> n * 400);
}
```
