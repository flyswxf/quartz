## 示例
### processOrder(qty, ship, pay, country)
- 目标：处理下单；根据数量、配送、支付、国家进行业务校验。
##### 被测因素的划分（分区大小 p）

| 参数      | 分区（取值）                             | 分区数 p |
| --------- | ---------------------------------------- | -------- |
| `qty`     | `0`｜`1–100`｜`>100`                     | 3        |
| `ship`    | `标准`｜`加急`｜`自提`                   | 3        |
| `pay`     | `信用卡`｜`PayPal`｜`银行转账`｜`礼品卡` | 4        |
| `country` | `国内`｜`国际`                           | 2        |
- 分区向量：$$p=[3,3,4,2]$$

> 注：下面的“组合数量”指需要覆盖的分区组合总数（combinations under test），不等同于最少测试用例数；ECC 的最少用例数 = 最大分区数；PWC/TWC 的最少用例数需用覆盖数组构造得到。

## ACoC（全组合值覆盖）
- 定义：覆盖所有参数分区的笛卡尔积。
- 示例组合数量：$$3\times 3\times 4\times 2 = 72$$

## ECC（单值覆盖）

^9fe143

- 定义：每个参数的每个分区至少出现一次。
- 示例组合数量：$$\max(3,3,4,2)=4$$

## PWC（全对偶值覆盖）
- 定义：任意两参数的所有分区对都至少出现一次。
- 示例组合数量：
  - 两两乘积求和：$$\sum_{i<j} p_i p_j = 3\times3 + 3\times4 + 3\times2 + 3\times4 + 3\times2 + 4\times2 = 53$$
  - `qty × country` 的对偶分区（6 个）：

| `qty`   | 国内            | 国际            |
| ------- | --------------- | --------------- |
| `0`     | `(0, 国内)`     | `(0, 国际)`     |
| `1–100` | `(1–100, 国内)` | `(1–100, 国际)` |
| `>100`  | `(>100, 国内)`  | `(>100, 国际)`  |

  - 例如测试用例 `(+ qty=0, ship=标准, pay=信用卡, country=国内)` 覆盖了 `(0, 国内)` 这一分区对，同时也覆盖 `(0, 信用卡)`、`(0, 标准)`、`(标准, 信用卡)` 等多个分区对。
  - 因此最少测试用例数满足：$$N \le \sum_{i<j} p_i p_j$$（单个用例可同时覆盖多个分区对）。

## TWC（全 T 值覆盖）
- 定义：任意 `T` 个参数的所有分区组合都至少出现一次。
- 例取 `T = 3`（三元组合）：
  - 三元乘积求和：
  - $(1,2,3):\;3\times3\times4 = 36$
  - $(1,2,4):\;3\times3\times2 = 18$
  - $(1,3,4):\;3\times4\times2 = 24$
  - $(2,3,4):\;3\times4\times2 = 24$
  - 合计：$$36 + 18 + 24 + 24 = 102$$

## BCC（基本值覆盖）
- 定义：先选一个“基值组合”，再对每个参数用其余分区分别替换一次。
- 示例基值：`qty=1–100, ship=标准, pay=信用卡, country=国内`
- 示例组合数量：$$1 + (3-1) + (3-1) + (4-1) + (2-1) = 9$$
	- $1$: 代表基值组合`qty=1–100, ship=标准, pay=信用卡, country=国内`
	- $(3-1)$: 选择qty中除了基值`1-100`之外的两个非基本值搭配其他基值的组合
		- `qty=1, ship=标准, pay=信用卡, country=国内`
		- `qty=100, ship=标准, pay=信用卡, country=国内`

## MBCC（多基本值覆盖）
- 定义：为部分参数选择多个基值；基值组合使用[[组合测试策略-Combination Strategies#^9fe143|单值覆盖]]，并对每个参数的非基值分区与其他参数的基值做替换。
- 示例多基值选择：
  - `qty` 取 1 个（`1–100`）→ `b₁=1`
  - `ship` 取 2 个（`标准, 加急`）→ `b₂=2`
  - `pay` 取 2 个（`信用卡, PayPal`）→ `b₃=2`
  - `country` 取 1 个（`国内`）→ `b₄=1`
- 示例组合数量（公式）：
  - 基值组合：$\max(1,2,2,1)=2$
  - 逐参替换：
    - `qty`：$(3-1)\times 2\times 2\times 1 = 8$
    - `ship`：$(3-2)\times 1\times 2\times 1 = 2$
    - `pay`：$(4-2)\times 1\times 2\times 1 = 4$
    - `country`：$(2-1)\times 1\times 2\times 2 = 4$
  - 合计：$$4 + 8 + 2 + 4 + 4 = 22$$

> [!summary]+ 重点：参数约束的处理 (Handling Constraints)
> **约束类型**：
> 1. **不可组合 (Cannot be combined)**：分区互斥（如 `open` 不在 `str` 中时，`pos` 无意义）。
> 2. **必须组合 (Must be combined)**：分区依赖（如 `pos` 有效前提是 `open` 在 `str` 中）。
>
> **处理策略**：
> - **ACoC, PWC, TWC**：直接**丢弃**不可行的组合 (drop the infeasible combination)。
> - **BCC, MBCC**：若变更值与基值冲突，**修改基值**以满足约束 (change the choice for the base)。
