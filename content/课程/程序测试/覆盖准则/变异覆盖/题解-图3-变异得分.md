# 图3：一阶变异得分（强杀准则）

## 题目
- 测试输入集合：`{N=1, N=2}`
- 以强杀死作为杀死变异体的标准

## 原始与变异
```java
// 原始
if (N >= 2 && N <= 20) {
  for (int i = 1; i <= 10; i++) {
    System.out.println(N + " x " + i + " = " + N * i);
  }
}

// 变异体（一阶）：将 && 改为 ||
if (N >= 2 || N <= 20) {
  for (int i = 1; i <= 10; i++) {
    System.out.println(N + " x " + i + " = " + N * i);
  }
}
```

## 测试用例与输出对比
|   N | 原始程序输出     | 变异体输出      | 是否强杀 |
| --: | ---------- | ---------- | ---- |
|   1 | 不输出        | 输出 10 行乘法表 | 是    |
|   2 | 输出 10 行乘法表 | 输出 10 行乘法表 | 否    |

解释：`N=1` 时，原始条件为假而变异条件为真，产生可观察差异，满足可达/感染/传播，强杀成立；`N=2` 时两者均输出相同，不构成强杀。

## 变异得分 MS(T)
- 变异体总数：`1`
- 被强杀的变异体数：`|D| = 1`
- 存活变异体数：`|L| = 0`
- `MS(T) = |D| / (|L| + |D|) = 1 / (0 + 1) = 1`

结论：在测试输入集合 `{N=1, N=2}` 下，变异得分为 `1.0`。
