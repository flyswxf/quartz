变异算子是针对程序的. 将程序变异以检测测试用例鉴别错误的能力

## 强杀死（Strong Kill）
- 条件：[[RIP 模型]]中可达（reachability）、感染（infection）、传播（propagation）同时成立
- 解释：可达→执行到变异位置；感染→状态产生差异；传播→差异影响到可观察结果
- 示例代码：
```
minVal = A;
minVal = B;         //错误代码
if (B < A)
  minVal = B;
```
- 约束：可达=true；感染：`A ≠ B`；传播：`(B < A) = false` 即 `B ≥ A`
- 强杀示例：`A = 3, B = 5`

## 弱杀死（Weak Kill）
- 条件：满足[[RIP 模型]]可达与感染，但不要求传播
- 解释：内部状态不同，但未影响到输出
- 示例：`A = 5, B = 3` 可弱杀但非强杀

# 变异覆盖
## Mutant：
**变异体**, 即正常程序应用变异算子的结果
- Live mutant：对测试集所有用例结果均与原程序一致的变异体(**包括弱杀死**)
- Killing mutant：至少一个测试用例结果与原程序不同的变异体(即**被强杀死的变异体**)
- Equivalent mutant：对全输入域结果与原程序完全一致的变异体
	- 比如`x<y`变异为`x<=y-1`
## Mutation Score (MS)：
$$MS = |D| / (|L| + |D|)$$
- 其中 $|D|$ 为被杀死数量，$|L|$ 为存活数量

# 例子：变异覆盖与 MS(T) 计算

## 原程序
```cpp
1 begin

2 int x, y;
3 input(x, y);
4 if (x < y)
5   output(x + y);
6 else
7   output(x * y);

8 end
```

## 变异体列表（M1–M8）
| Line | 原始          | Mutant ID | 变异体             |
| ---- | ----------- | --------- | --------------- |
| 4    | if(x<y)     | M1        | if(x+1<y)       |
| 4    | if(x<y)     | M2        | if(x<y+1)       |
| 6    | output(x+y) | M3        | output(x+1+y)   |
| 6    | output(x+y) | M4        | output(x+y+1)   |
| 6    | output(x+y) | M5        | output(x−y)     |
| 8    | output(x*y) | M6        | output((x+1)*y) |
| 8    | output(x*y) | M7        | output(x*(y+1)) |
| 8    | output(x*y) | M8        | output(x/y)     |

## 测试集 T
| 用例 | x | y | 期望输出 |
|---|---:|---:|---:|
| t1 | 0 | 0 | 0 |
| t2 | 0 | 1 | 1 |
| t3 | 1 | 0 | 0 |
| t4 | -1 | -2 | 2 |


## 执行结果与杀死情况（强杀死）
- M1：与原程序在 `t2` 不同 → 被杀死
- M2：所有用例与原程序相同 → 存活（live）
- M3：与原程序在 `t2` 不同 → 被杀死
- M4：与原程序在 `t2` 不同 → 被杀死
- M5：与原程序在 `t2` 不同 → 被杀死
- M6：与原程序在 `t4` 不同 → 被杀死
- M7：与原程序在 `t3` 不同 → 被杀死
- M8：至少在 `t1` 表现为未定义/不同 → 被杀死

据此：
- 被杀死集合 `D = {M1, M3, M4, M5, M6, M7, M8}` → `|D| = 7`
- 存活集合 `L = {M2}` → `|L| = 1`

## Mutation Score 计算
- `MS(T) = |D| / (|L| + |D|)`
- `= 7 / (1 + 7)`
- `= 0.875`

>[!important]
>该分数基于当前这组 8 个变异体与测试集 T；若变异体集合改变，分数也随之变化。
>因此只有在**相同的变异体**上, 才能根据变异分数判断**测试用例集的揭错能力**
