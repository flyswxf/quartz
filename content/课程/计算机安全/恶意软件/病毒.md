# 病毒 (Virus)

## 1. 概念
**计算机病毒（Computer Virus）** 是一段可以“感染”其他程序或任何类型的可执行内容的恶意软件。它通过将自身的副本（可能经过修改）注入到其他程序中来进行自我复制。当被感染的主机程序运行时，病毒代码也会随之执行。

## 2. 核心特征
*   **寄生性（Parasitic）**：病毒通常不能独立运行，需要依附于宿主程序（Host Program）或特定的可执行内容（如宏）。
*   **需要用户干预**：病毒的传播通常需要人类用户的某种交互行为，例如通过U盘分享被感染的文件、下载被感染的附件并双击运行等。

## 3. 组成部分
如 [AYCO06] 所述，典型的计算机病毒包含三个变体组件：
*   **感染机制（Infection mechanism / Infection vector）**：病毒传播或复制的方式。
*   **触发条件（Trigger / Logic bomb）**：决定有效载荷何时被激活的事件或条件。
*   **有效载荷（Payload）**：病毒除传播外执行的实际操作（可能是破坏性的，如删除数据；也可能是无害的，如显示弹窗）。

## 4. 生命周期
1.  **休眠阶段（Dormant phase）**：病毒处于闲置状态，等待特定事件（如特定日期）激活。
2.  **传播阶段（Propagation phase）**：病毒将自身副本植入其他程序或磁盘区域。
3.  **触发阶段（Triggering phase）**：病毒被激活以执行其设计功能。
4.  **执行阶段（Execution phase）**：实际执行病毒功能（无害显示或恶意破坏）。

## 5. 病毒分类
### 按攻击目标分类
*   **引导扇区感染者（Boot sector infector）**：感染磁盘的引导记录（MBR），在系统启动时加载。
*   **文件感染者（File infector）**：感染操作系统认为可执行的文件（如 `.exe`, `.com`, `.sys`）。
*   **宏病毒（Macro virus）**：感染包含宏指令的文档（如 Microsoft Word `.doc` 或 Excel `.xls` 文件）。它们独立于操作系统，跨平台传播容易。
*   **多源/多目标病毒（Multipartite virus）**：能够以多种方式感染（例如同时感染引导扇区和可执行文件）。

### 按隐蔽策略分类
*   **加密病毒（Encrypted virus）**：由一个随机加密密钥和病毒主体的密文组成，每次感染使用不同的密钥以躲避特征码检测。
*   **隐蔽病毒（Stealth virus）**：主动隐藏自身的存在，例如拦截操作系统的文件读取请求并返回未感染的原始文件数据。
*   **多态病毒（Polymorphic virus）**：每次复制时都会改变其外观（代码结构），但保持功能不变，通常通过改变加密机制或指令顺序实现。
*   **变形病毒（Metamorphic virus）**：比多态病毒更进一步，它不仅加密改变，而是每次迭代都完全重写自身代码逻辑（使用等价指令），极难被基于特征码的杀毒软件检测。
