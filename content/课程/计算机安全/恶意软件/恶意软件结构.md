# 第六章 Malicious Software

[AYCO06] 指出，计算机病毒包含三个部分。更普遍地说，许多当代恶意软件也包含这三个组件的一个或多个变体：

- **感染机制（Infection mechanism）**：病毒传播或复制的方式，也被称为感染载体（infection vector）。
- **触发条件（Trigger）**：决定有效载荷何时被激活或执行的事件或条件，有时也被称为逻辑炸弹（logic bomb）。
- **有效载荷（Payload）**：病毒除了传播之外执行的操作，可能造成破坏，也可能是无害但会被察觉的活动。

典型病毒在其生命周期中会经历以下四个阶段：

1. **休眠阶段（Dormant phase）**：病毒处于闲置状态。它最终会被某些事件激活，例如特定日期、另一个程序或文件的存在，或磁盘容量超过某个限制。并非所有病毒都有这个阶段。
2. **传播阶段（Propagation phase）**：病毒将自身副本植入其他程序或磁盘上的某些系统区域。副本可能与传播的版本不完全相同，病毒通常会通过变形来躲避检测。每个被感染的程序现在都包含一个病毒副本，这个副本本身也会进入传播阶段。
3. **触发阶段（Triggering phase）**：病毒被激活以执行其设计的功能。与休眠阶段类似，触发阶段可由多种系统事件引起，包括该病毒副本复制自身的次数。
4. **执行阶段（Execution phase）**：执行病毒的功能。该功能可能是无害的，例如在屏幕上显示一条消息；也可能是破坏性的，例如删除程序和数据文件。
