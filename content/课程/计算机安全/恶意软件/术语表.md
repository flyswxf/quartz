# 恶意软件术语表（Table 6.1）

| 名称（英文） | 中文名称（建议译法） | 中文说明 |
|---|---|---|
| Advanced Persistent Threat (APT) | 高级持续性威胁 | 面向商业和政治目标的网络犯罪，使用多种入侵技术与恶意软件，对特定目标长期、持续、有效地实施攻击，常被归因于国家支持的组织。 |
| Adware | 广告软件 | 集成在软件中的广告功能，可能导致弹窗广告，或将浏览器重定向到商业网站。 |
| Attack kit | 攻击工具包 | 一组工具，可利用多种传播与载荷机制自动生成新的恶意软件。 |
| Auto-rooter | 自动提权/自动入侵工具 | 恶意黑客工具，用于远程入侵新机器。 |
| Backdoor (trapdoor) | 后门（暗门） | 任何绕过正常安全检查的机制；可能允许对程序功能或被攻陷系统的未授权访问。 |
| Downloaders | 下载器（投递器） | 在受攻击机器上安装/下载其他项目的代码；通常是最先植入被攻陷系统的恶意代码的一部分，用于导入更大的恶意软件包。 |
| Drive-by-download | 路过式下载 | 利用被攻陷网站上的代码，通过利用浏览器漏洞：当用户浏览该网站时攻击客户端系统。 |
| Exploits | 漏洞利用代码 | 针对单个漏洞或一组漏洞的专用代码。 |
| Flooders (DoS client) | 洪泛器（DoS 客户端） | 通过产生大量数据流量对联网计算机系统实施攻击，执行某种拒绝服务（DoS）攻击。 |
| Keyloggers | 键盘记录器 | 在被攻陷系统上捕获按键输入。 |
| Logic bomb | 逻辑炸弹 | 入侵者插入到恶意软件中的代码；在预定义条件满足前保持休眠，条件满足后触发某种载荷。 |
| Macro virus | 宏病毒 | 使用宏或脚本代码的病毒，通常嵌入文档或文档模板；当文档被查看或编辑时触发运行，并将自身复制到其他类似文档中。 |
| Mobile code | 移动代码 | 可在异构平台集合中原样分发并以相同语义执行的软件（例如脚本与宏）。 |
| Rootkit | Rootkit（根套件） | 攻击者入侵系统并获得 root 级访问后使用的一组黑客工具。 |
| Spammer programs | 垃圾邮件程序 | 用于发送大量非请求邮件。 |
| Spyware | 间谍软件 | 通过监控按键、屏幕数据和/或网络流量，或扫描系统中的敏感信息来收集信息，并传输到另一系统的软件。 |
| Trojan horse | 木马 | 表面上具有有用功能，但隐藏了（潜在）恶意功能并规避安全机制的程序；有时通过滥用合法授权来实现。 |
| Virus | 病毒 | 恶意软件在执行时会尝试将自身复制到其他可执行机器码或脚本代码中；成功后称目标代码被感染。被感染代码执行时，病毒也会执行。 |
| Worm | 蠕虫 | 能独立运行，并可在网络中将自身的完整可工作版本传播到其他主机；通常通过利用目标系统的软件漏洞或使用窃取到的授权凭据实现。 |
| Zombie, bot | 僵尸程序 / 机器人 | 安装在被感染机器上的程序，被激活后用于对其他机器发起攻击。 |
