# 蠕虫 (Worm)

## 1. 概念
**计算机蠕虫（Computer Worm）** 是一种能够自我复制并通过网络连接将自身副本从一台计算机发送到另一台计算机的独立恶意软件程序。

## 2. 与病毒的主要区别
*   **独立性**：蠕虫是一个独立的程序，**不需要**依附于宿主程序即可运行。
*   **主动传播**：蠕虫通常利用网络协议和操作系统的漏洞主动在网络中传播，通常**不需要**用户的交互（例如，不需要用户双击某个文件）。

## 3. 传播机制
蠕虫利用网络进行传播，常见的传播媒介包括：
*   **利用软件漏洞（Software Vulnerabilities）**：通过网络发送特制的数据包，利用远程系统的缓冲区溢出等漏洞直接注入并执行蠕虫代码。
*   **电子邮件或即时通讯**：蠕虫会读取本地的联系人列表，并将包含自身副本的邮件或消息发送给其他人（这种方式兼具社会工程学和蠕虫的自动传播特性）。
*   **文件共享网络（P2P）**：在点对点网络中伪装成热门资源，诱骗其他用户下载。
*   **远程执行能力**：利用操作系统提供的远程执行服务（如 Windows 的 psexec，或弱密码的 SSH/RDP）。

## 4. 蠕虫的传播阶段
网络蠕虫的生命周期通常侧重于网络维度的扩散：
1.  **目标发现/扫描（Target Discovery / Scanning）**：
    *   蠕虫探测网络，寻找潜在的脆弱主机。
    *   **策略**：随机扫描（Random）、顺序扫描（Sequential）、本地子网扫描（Topological/Local subnet）或利用预先生成的命中列表（Hit-list）。
2.  **攻击与利用（Exploitation）**：
    *   向目标发送漏洞利用代码（Exploit），试图获取目标机器的执行权限。
3.  **下载与传输（Transfer/Download）**：
    *   一旦获取执行权限，蠕虫需要将自己的主体代码传送到受害机器。可以通过 FTP、TFTP、HTTP 或直接在初始漏洞利用载荷中携带自身。
4.  **执行与感染（Execution & Infection）**：
    *   蠕虫在目标机器上运行，建立持久化机制，并开始新一轮的扫描和传播。

## 5. 蠕虫的有效载荷 (Payloads)
虽然蠕虫的核心目标是传播，但它们也可能携带其他有效载荷：
*   **僵尸网络代理（Botnet Agent）**：将被感染主机变成“肉鸡”，用于发动 DDoS 攻击。
*   **勒索软件/破坏（Ransomware/Destruction）**：如 WannaCry 蠕虫不仅传播，还加密本地文件勒索赎金。
*   **信息窃取**：搜集受害者的凭证、网络拓扑信息。
