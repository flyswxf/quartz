# 随机与伪随机数 (Random and Pseudorandom Numbers)

## 基本概念

随机数是现代密码学的基石之一。几乎所有密码学操作都依赖于高质量的随机数：密钥生成、初始化向量、Nonce、盐值、挑战值等。随机数的质量直接决定密码系统的安全性。

---

## 三种随机数生成器

### 1. 真随机数生成器 (TRNG)

TRNG 使用**物理熵源**产生真正的不可预测的随机数。

**熵源示例：**
- 电子电路的热噪声 (Thermal Noise)
- 放射性衰变的时间间隔
- 键盘/鼠标事件的微秒级时间差
- 磁盘 I/O 的随机延迟
- 摄像头传感器噪声

**特征：**
- 输出是**真正不可预测**的，不依赖任何确定性算法
- 生成速率受限，取决于物理熵源的采集速度
- 可能出现偏差 (Bias)，需要后处理（去偏）确保均匀分布

### 2. 伪随机数生成器 (PRNG)

PRNG 使用**确定性算法**从一个初始种子值 (Seed) 产生一长串看起来随机的数字序列。

$$ X_{n+1} = f(X_n) $$

给定相同的种子，PRNG 产生完全相同的输出序列——这是其确定性本质。

**特征：**
- 生成速度快，适合大量随机数的需求
- 完全确定性：种子相同则序列相同
- **不可用于密码学**：普通 PRNG（如 C 语言的 `rand()`）可被预测

### 3. 密码学安全伪随机数生成器 (CSPRNG)

CSPRNG 是 PRNG 的一个特殊子集，设计上满足密码学安全要求。

**CSPRNG 必须满足两个条件：**

1. **下一比特不可预测性 (Next-bit Unpredictability)**：给定生成器输出的前 $k$ 个比特，攻击者在计算上无法以高于 50% 的概率预测第 $k+1$ 个比特
2. **前向/后向安全性**：
   - 攻击者即使获取了当前内部状态，也无法重建之前的输出（前向安全）
   - 攻击者无法从当前输出推导出后续输出（后向安全）

## 三种生成器对比

| 特性           |   TRNG   | PRNG (统计) |     CSPRNG      |
| -------------- | :------: | :---------: | :-------------: |
| 熵源           | 物理过程 | 算法 + 种子 | 算法 + 高熵种子 |
| 是否确定性     | ❌ 非确定 |   ✅ 确定    |     ✅ 确定      |
| 可重现         |    ❌     |      ✅      |  ✅ (相同种子)   |
| 生成速度       |    慢    |    极快     |       快        |
| 下一比特可预测 |  ❌ 不可  |    ✅ 可     | ❌ 不可 (计算上) |
| 密码学用途     |    ✅     |      ❌      |        ✅        |

## 熵 (Entropy)

### 定义
在密码学中，熵是衡量信息**不可预测性**的量。高熵意味着攻击者猜测正确值的概率极低。

- 一个完全随机的 $n$ 位值具有 $n$ 比特的熵
- 一个由用户选择的密码通常远低于其位长度对应的熵值

### 熵估计与采集

操作系统从多种物理源收集熵，维护一个熵池 (Entropy Pool)：

- **Linux**：`/dev/random`（阻塞式，熵不足时等待）和 `/dev/urandom`（非阻塞，用 CSPRNG 扩展）
- **Windows**：`CryptGenRandom` / `BCryptGenRandom`
- **Intel / AMD**：RDRAND / RDSEED 指令（硬件 TRNG）

## 密码学中随机数的应用

| 应用场景                                                          | 需要的随机值                  | 要求的特性                     |
| ----------------------------------------------------------------- | ----------------------------- | ------------------------------ |
| [[加密/对称加密\|对称密钥]]生成                                   | 密钥 $K$                      | 高熵、不可预测                 |
| [[加密/非对称加密\|非对称密钥]]生成                               | 大素数 $p, q$ (RSA)、私钥 $d$ | 高熵、不可预测                 |
| [[加密/对称加密#CBC 模式 (Cipher Block Chaining)\|CBC 模式 IV]]   | 初始化向量                    | 不可预测、每会话不同           |
| [[认证/消息认证码(MAC)#防重放攻击的补充机制\|Nonce]] 生成         | 一次性随机数                  | 不可重复、不可预测（某些场景） |
| [[哈希函数#3. 密码存储\|密码盐值]]                                | 随机盐值 $salt$               | 每用户不同、无需保密           |
| [[暴力破解攻击#3. 彩虹表攻击 (Rainbow Table Attack)\|彩虹表防御]] | 随机盐值 $salt$               | 每用户不同                     |
| Challenge-Response 挑战                                           | 随机挑战值                    | 不可预测                       |
| 数字签名 (ECDSA/DSA)                                              | 临时随机数 $k$ (nonce)        | **必须唯一且不可预测**         |

> ⚠️ ECDSA/DSA 签名的临时 nonce $k$ 如果重复或可预测，私钥将直接被计算出来。这是 Sony PS3 被破解的直接原因 (2010)。
