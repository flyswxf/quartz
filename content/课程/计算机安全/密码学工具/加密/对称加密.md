## 基本概念

### 对称加密 (Symmetric Encryption)
对称加密是最基本的密码学工具之一。在对称加密中，通信双方**共享同一个密钥** $K$，该密钥同时用于加密和解密操作。

**五个基本组成部分：**
- **明文 (Plaintext)**：原始的可读消息或数据，记为 $P$ 或 $X$
- **加密算法 (Encryption Algorithm)**：将明文转换为密文的数学函数，记为 $E$
- **密钥 (Secret Key)**：加密算法使用的秘密参数，记为 $K$
- **密文 (Ciphertext)**：加密后产生的不可读输出，记为 $C$ 或 $Y$
- **解密算法 (Decryption Algorithm)**：将密文还原为明文的数学函数，记为 $D$

数学表示：
$$ C = E(K, P) \quad \text{或} \quad C = E_K(P) $$
$$ P = D(K, C) \quad \text{或} \quad P = D_K(C) $$

### 加密的两个基本类型
| 类型       | 流密码 (Stream Cipher) | 块密码 (Block Cipher)        |
| ---------- | ---------------------- | ---------------------------- |
| 处理方式   | 逐位/逐字节处理数据流  | 将明文分块处理，每块固定大小 |
| 典型块大小 | 1 bit 或 1 byte        | 64 bit 或 128 bit            |
| 代表算法   | RC4, ChaCha20          | DES, 3DES, AES               |
| 特点       | 适合实时通信           | 应用广泛，模式灵活           |

## 块密码操作模式 (Block Cipher Modes of Operation)

块密码一次只能处理固定大小的数据块，但实际消息往往长度不定。操作模式定义了如何将块密码应用于任意长度的消息。

### ECB 模式 (Electronic Codebook)

最朴素的块密码操作模式。

**加密过程：**
$$ C_i = E_K(P_i), \quad i = 1, 2, \dots, N $$

**解密过程：**
$$ P_i = D_K(C_i), \quad i = 1, 2, \dots, N $$

**局限性：**
- 当明文长度不是块大小的整数倍时，需要**填充方案** (Padding Scheme，如 PKCS#7)
- **不能直接处理不完整块**

**安全缺陷：**
1. **确定性 (Deterministic)**：相同明文块产生相同密文块。若 $P_i = P_j$，则 $C_i = C_j$
2. **模式保留 (Pattern Preservation)**：明文中的数据模式在密文中依然可见（如加密图像仍可辨认轮廓）
3. **缺乏扩散性 (Lack of Diffusion)**：一个明文块的改变只影响对应密文块，攻击者可进行重放攻击或密文块重排

> ECB 不应被用于安全敏感的应用场景。

### CBC 模式 (Cipher Block Chaining)

通过在块间引入依赖关系克服 ECB 的缺陷。

**加密过程：**
$$ C_1 = E_K(P_1 \oplus IV) $$
$$ C_i = E_K(P_i \oplus C_{i-1}), \quad i = 2, \dots, N $$

**解密过程：**
$$ P_1 = D_K(C_1) \oplus IV $$
$$ P_i = D_K(C_i) \oplus C_{i-1}, \quad i = 2, \dots, N $$

- **IV (Initialization Vector，初始化向量)**：[[随机与伪随机数|随机]]生成的初始块，与第一个明文块异或，确保即使同一消息被加密多次，产生的密文也不同
- IV 不需要保密，但每个加密会话必须使用不同的 IV

### 其他重要模式

| 模式 | 全称                       | 核心特点                           |
| ---- | -------------------------- | ---------------------------------- |
| CFB  | Cipher Feedback            | 将块密码转换为流密码               |
| OFB  | Output Feedback            | 将块密码转换为流密码，避免错误传播 |
| CTR  | Counter                    | 使用计数器生成密钥流，支持并行处理 |
| XTS  | XEX-based Tweaked-codebook | 用于磁盘加密，专为存储设计         |

## 对称加密的安全要求

1. **算法公开性**：加密算法的安全性应仅依赖于密钥的保密性，而非算法本身（Kerckhoffs 原则）
2. **密钥空间**：密钥空间必须足够大，以抵御[[暴力破解攻击|暴力破解攻击]]
3. **扩散 (Diffusion)**：明文的统计特性应分散到整个密文中
4. **混淆 (Confusion)**：密文与密钥之间的关系应尽可能复杂
