# 哈希函数 (Hash Functions)

## 基本概念

### 定义
密码学哈希函数（又称消息摘要函数）是一种将**任意长度**的输入数据映射为**固定长度**输出的数学函数：
$$ h = H(M) $$

- 输入 $M$：任意长度的消息
- 输出 $h$：固定长度的哈希值（摘要），如 SHA-256 输出 256 bits

---

## 密码学哈希函数的安全要求

| 属性                                          | 描述                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------- |
| **抗原像性 (Preimage Resistance)**            | 给定 $h$，在计算上不可行找到任意 $M$ 使得 $H(M) = h$。即 "单向性"    |
| **抗第二原像性 (Second Preimage Resistance)** | 给定 $M_1$，在计算上不可行找到 $M_2 \neq M_1$ 使得 $H(M_2) = H(M_1)$ |
| **抗碰撞性 (Collision Resistance)**           | 在计算上不可行找到任意 $M_1 \neq M_2$ 使得 $H(M_1) = H(M_2)$         |

> **碰撞攻击总是可能的**（鸽巢原理），但找到碰撞在计算上应是不可行的。

---

## 常用哈希算法

| 算法           | 输出长度 (bits) | 安全状态                                         |
| -------------- | :-------------: | ------------------------------------------------ |
| MD5            |       128       | **已破解**，不应用于安全场景                     |
| SHA-1          |       160       | **已破解**，已实现实际碰撞攻击 (SHAttered, 2017) |
| SHA-256        |       256       | 当前安全，广泛使用                               |
| SHA-384        |       384       | 当前安全                                         |
| SHA-512        |       512       | 当前安全                                         |
| SHA-3 (Keccak) |      可变       | 最新标准 (NIST 2015)                             |
| BLAKE3         |      可变       | 现代高性能哈希                                   |

## 哈希函数的应用

### 1. 数字签名
对消息哈希值签名，而非对完整消息签名。大幅提升效率并增强安全性。

### 2. 消息认证 (HMAC)
$$ HMAC(K, M) = H((K \oplus opad) \parallel H((K \oplus ipad) \parallel M)) $$
结合密钥和哈希函数，构造[[消息认证码(MAC)#1. 基于哈希的 MAC (HMAC)|消息认证码]]。

### 3. 密码存储
存储密码的哈希值（加盐），而非明文密码。
- **加盐 (Salting)**：为每个用户生成[[随机与伪随机数|随机]]盐值 $salt$，存储 $H(password \parallel salt)$
- 防止彩虹表攻击和相同密码产生相同的哈希值

### 4. 数据完整性校验
- 文件下载校验（校验和 checksum）
- 区块链（Merkle 树依赖哈希链接）
- 版本控制系统 (Git 使用 SHA-1 进行内容寻址)

### 5. 伪随机数生成
哈希函数可作为 [[随机与伪随机数|CSPRNG]] 的构建块，例如基于 HMAC 的 DRBG。

---

## 雪崩效应 (Avalanche Effect)

密码学哈希函数应具备的特性：输入中**任何微小的变化**（哪怕是一个比特的翻转）都会导致输出中**约 50% 的比特位**发生变化。这确保了哈希值的不可预测性。

---

## 生日攻击 (Birthday Attack)

基于概率论中的生日悖论：对 $n$ 位哈希值：
- [[暴力破解攻击|暴力破解]]原像需要 $2^n$ 次尝试
- 通过生日攻击找到碰撞仅需约 $2^{n/2}$ 次尝试

因此，SHA-256 的碰撞安全性实际上是 **128 位**（而非 256 位）。这解释了对哈希函数输出长度的设计要求。
