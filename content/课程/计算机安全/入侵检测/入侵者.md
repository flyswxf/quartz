# 入侵者 (Intruders)

> [!info] 入侵者
> 任何试图绕过系统安全策略、获取未授权访问的个人或程序。

## 入侵者三类人

| 类型                            | 别称 | 画像                           |
| ------------------------------- | ---- | ------------------------------ |
| **假冒用户** (Masquerader)      | 黑客 | 外部人员，冒充合法用户闯入系统 |
| **违法者** (Misfeasor)          | 内鬼 | 内部人员，有合法账户但滥用权限 |
| **秘密用户** (Clandestine User) | 暗桩 | 获取 root/管理员权限并隐藏踪迹 |

> [!tip] 内部威胁 vs 外部威胁
> 内部人员（违法者、秘密用户）比外部假冒用户**更难检测**——他们本来就有合法访问权限，系统很难区分"正常使用"和"滥用权限"。

## 入侵者在干什么？

攻击行为可以分为三大类：

> [!example] 系统攻击
> 利用软件漏洞获取权限提升。如缓冲区溢出、格式化字符串漏洞、注入攻击。

> [!example] 网络攻击
> 在网络层截获或篡改通信。如网络嗅探（Sniffing）、会话劫持、中间人攻击。

> [!example] 应用层攻击
> 针对认证机制的攻击。如暴力破解、字典攻击、密码猜测。

## 攻击生命周期

```mermaid
graph LR
    A[侦察] --> B[扫描]
    B --> C[获取访问]
    C --> D[维持访问]
    D --> E[清除痕迹]
```

> [!warning] "清除痕迹"是最危险的阶段
> 高级攻击者会在入侵后删除日志、修改时间戳，使安全团队难以发现入侵曾经发生过。
