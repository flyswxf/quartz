# 启发式检测 (Heuristic Detection)

> [!info] 核心思想
> 不靠"已知犯罪手法大全"，而是靠**经验规则**和**行为分析**来判断。就像一个老警察，不看通缉令也能凭直觉看出谁"不太对劲"。

## 规则示例

```
# 暴力破解规则
IF 连续登录失败 > 5 次
AND 间隔 < 1 分钟
AND 来自同一 IP
→ 暴力破解

# 权限提升规则
IF 普通用户执行 sudo/su
AND 未通过正常授权
→ 可疑提权
```

## 技术方法

| 方法         | 说明                                   |
| ------------ | -------------------------------------- |
| **专家系统** | 安全专家编写的规则引擎                 |
| **行为分析** | 分析用户/程序的行为模式变化            |
| **状态机**   | 跟踪攻击的多阶段进展（侦察→利用→提权） |

> [!tip] 优势
> 比签名检测更灵活，能识别变种攻击。规则可以覆盖一类攻击，而不是一个具体特征。

> [!danger] 局限
> 规则设计依赖专家经验，维护成本高。太严格会误报，太宽松会漏报。

---

## 三种方法对比

| 维度         | [[异常检测\|异常检测]] | [[签名检测\|签名检测]] | 启发式检测     |
| ------------ | ---------------------- | ---------------------- | -------------- |
| **检测依据** | 正常行为基线           | 已知攻击签名库         | 专家规则与经验 |
| **未知攻击** | ✅ 能检测               | ❌ 不能                 | ⚠️ 部分可以     |
| **误报率**   | 高                     | 低                     | 中等           |
| **更新需求** | 无（自适应）           | 频繁更新签名库         | 定期调整规则   |

> [!tip] 实际部署策略
> 现代 IDS 通常**三种方法结合**：签名检测快速过滤已知攻击，异常检测发现未知威胁，启发式检测做深度分析。
