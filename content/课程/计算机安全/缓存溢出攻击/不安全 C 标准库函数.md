导致栈溢出的常见原因在于使用了缺乏边界检查的 C 标准库函数。以下是典型的不安全函数列表：

| 函数签名                                     | 描述                                                                    |
| :------------------------------------------- | :---------------------------------------------------------------------- |
| `gets(char *str)`                            | 从标准输入读取一行字符串到 `str` 中，不检查缓冲区长度。                 |
| `sprintf(char *str, char *format, ...)`      | 根据提供的格式和变量创建字符串并写入 `str`，不检查 `str` 的容量。       |
| `strcat(char *dest, char *src)`              | 将 `src` 字符串的内容追加到 `dest` 字符串末尾，不检查 `dest` 剩余空间。 |
| `strcpy(char *dest, char *src)`              | 将 `src` 字符串的内容复制到 `dest` 字符串中，不检查 `dest` 容量。       |
| `vsprintf(char *str, char *fmt, va_list ap)` | 类似 `sprintf`，使用可变参数列表创建字符串，同样不检查边界。            |
