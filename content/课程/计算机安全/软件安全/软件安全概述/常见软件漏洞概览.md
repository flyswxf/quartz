# 常见软件漏洞概览

软件漏洞种类繁多，不同的编程语言和应用架构面临的安全威胁也有所不同。以下是几种最常见、危害最大的软件漏洞分类。

## 1. 注入漏洞 (Injection)
当不受信任的数据作为命令或查询的一部分发送给解释器时，就会发生注入漏洞。攻击者的恶意数据会欺骗解释器执行意外的命令或访问未经授权的数据。
- **[[SQL注入攻击|SQL 注入 (SQLi)]]:** 攻击者通过输入恶意 SQL 语句，操纵后台数据库。
- **命令注入 (Command Injection):** 攻击者向系统 Shell 传递恶意指令并执行。
- **LDAP / XPath 注入:** 针对特定协议或数据格式的注入攻击。

## 2. 内存破坏漏洞 (Memory Corruption)
这类漏洞多见于 C/C++ 等需要手动管理内存的语言，主要由于对内存缓冲区的操作缺乏边界检查或管理不当引起。
- **缓冲区溢出 (Buffer Overflow):** 向缓冲区写入的数据超过了其分配的大小，覆盖了相邻的内存区域，可能导致程序崩溃或执行任意代码。
- **释放后重用 (Use-After-Free):** 程序释放了一块内存，但仍然保留指向该内存的指针并尝试访问它。
- **越界读取 (Out-of-Bounds Read):** 读取缓冲区边界外的数据，常导致敏感信息泄露（如 Heartbleed 漏洞）。

## 3. [[跨站脚本攻击(XSS)|跨站脚本攻击 (XSS - Cross-Site Scripting)]]
XSS 是一种发生在 Web 前端的漏洞。当应用程序未经充分验证和转义，将用户提供的数据包含在发送给浏览器的网页中时，就会发生 XSS。
- 攻击者可以执行恶意 JavaScript 代码，从而窃取用户的 Session Cookie、劫持会话或篡改网页内容。

## 4. 身份验证与会话管理缺陷
如果在实现身份验证和会话管理时存在缺陷，攻击者可能会破坏密码、密钥或会话令牌，暂时或永久地冒充其他用户的身份。
- 弱密码策略或缺乏[[基本认证方式#多因素认证（Multifactor Authentication, MFA）|多因素认证 (MFA)]]。
- 会话固定 (Session Fixation)。
- 凭证硬编码在源代码中。

## 5. 安全配置错误 (Security Misconfiguration)
这是最常见的问题之一，通常是由于不安全的默认设置、不完整的配置、开放的云存储、错误的 HTTP 标头或包含敏感信息的详细错误信息引起的。
- 目录遍历被启用。
- 数据库或后台管理系统使用默认口令。

## 6. 使用含有已知漏洞的组件
现代软件大量依赖第三方开源库。如果开发团队没有及时跟踪并更新这些依赖，攻击者就可以利用这些已知漏洞（CVE）轻易攻破系统。
- 例如利用旧版本 Log4j 中的 Log4Shell 漏洞执行远程代码。

## 7. 业务逻辑漏洞 (Business Logic Vulnerabilities)
这类漏洞与底层代码错误（如溢出）无关，而是源于软件设计和业务流程的缺陷。
- 例如电商平台中，通过篡改请求将商品价格修改为负数，或绕过支付步骤直接获取商品。

> 了解这些常见漏洞的原理是进行安全编码和漏洞修复的基础。在后续的笔记中，将针对具体的漏洞类型进行详细的探讨。
