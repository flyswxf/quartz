# 作业回答模板规则

回答作业题目时，严格按以下结构组织内容：

## 1. 标题

```
# 题号 题目的中文概括
```

## 2. 题目翻译

将英文原题翻译成中文，放在开头，方便回顾题目内容。格式如：

```
## 题目

（中文翻译）
```

## 3. 讲解/分析

- 概念题使用 `## 讲解`，拆解概念、对比分析、可用列表和表格辅助
- 计算题使用 `## 题目分析` + `## 解题过程`，逐步推理

## 4. 参考答案

用分隔线 `---` 与讲解部分分开，使用 `## 参考答案` 标题。答案要求：

- 用**中文**撰写
- 一段话，简洁完整，**可直接作为作业答案抄写**
- 不要过于简略，但也不需要重复讲解中的全部细节

## 语言要求

- 全部使用中文（包括参考答案）
- 专业术语首次出现时附英文原文，如：异常检测（Anomaly Detection）
