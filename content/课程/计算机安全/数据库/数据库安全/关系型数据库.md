# 关系型数据库安全

在数据库安全领域，[[关系模型]]（Relational Model）由于其结构化的二维表特性，提供了细粒度的安全控制基础。

## 1. 结构化访问控制

关系型数据库的安全控制紧密依赖于其底层的数据组织方式：
- **表级控制**：可以限制用户对整张表进行 `SELECT`, `INSERT`, `UPDATE`, `DELETE` 等操作。
- **列级控制**：通过限制对特定属性（列）的访问，保护敏感数据（如密码、身份证号）。
- **行级控制**：在某些高级安全模型中，可以限制用户只能访问特定条件下的元组（行）。

## 2. 视图 (Views) 与安全

视图是关系型数据库中一种强大的安全机制。视图是一个虚拟表，其内容由 SQL 查询定义。
- **隐藏敏感数据**：通过创建视图，可以只暴露底层表中非敏感的列或行，对用户隐藏真实的数据库表结构和敏感信息。
- **简化权限管理**：管理员可以只赋予用户对视图的访问权限，而撤销他们对基础表的直接访问权限。

## 3. 关系型数据库面临的威胁

由于关系型数据库通常通过 SQL 语言进行交互，它面临的最典型威胁是恶意构造的查询输入，如 [[SQL注入攻击]]。此外，在统计数据的查询中，还可能面临 [[推理攻击]]。
