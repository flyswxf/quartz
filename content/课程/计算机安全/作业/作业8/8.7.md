# 8.7 去中心化 NIDS 威胁等级分类概率问题

## 题目

一个去中心化 NIDS 有两个节点在网络中监测异常流量，此外还有一个中心节点，在接收到两个分布式节点的信号后产生警报。两个 IDS 节点的流量签名遵循四种模式之一：P1、P2、P3 和 P4。中心节点根据两个 NIDS 在给定时间观测到的流量来分类威胁等级，规则如下：

| 威胁等级 | 签名组合  |
| -------- | --------- |
| 低       | 1P1 + 1P2 |
| 中       | 1P3 + 1P4 |
| 高       | 2P4       |

如果在某一时刻，至少有一个分布式节点产生了 P3 警报信号，那么观测到的流量被分类为"中"威胁等级的概率是多少？

## 题目分析

两个 NIDS 节点独立监测流量，每个节点等概率地观测到 P1、P2、P3、P4 之一（各 1/4）。两个节点的总可能组合数为 4 × 4 = 16 种。

### 第一步：计算"至少一个节点观测到 P3"的情况数

至少一个 P3 = 总情况数 − 两个节点都不是 P3 = 16 − 3×3 = **7 种**

具体列举：
- (P3, P1)、(P3, P2)、(P3, P3)、(P3, P4)
- (P1, P3)、(P2, P3)、(P4, P3)

### 第二步：计算其中属于"Medium"的情况数

Medium 要求 1P3 + 1P4，即一个节点观测到 P3、另一个观测到 P4：
- (P3, P4) ✓
- (P4, P3) ✓

共 **2 种**。

### 第三步：条件概率

$$P(\text{Medium} \mid \text{至少一个 P3}) = \frac{P(\text{Medium 且 至少一个 P3})}{P(\text{至少一个 P3})} = \frac{2/16}{7/16} = \frac{2}{7}$$

---

## 参考答案

假设每个节点独立且等概率地观测到四种签名之一，两个节点共有 16 种等可能的组合。其中至少一个节点观测到 P3 的组合有 7 种（排除两个节点都不是 P3 的 9 种情况）。在这 7 种中，满足 Medium 签名（1P3 + 1P4）的组合有 2 种：(P3, P4) 和 (P4, P3)。因此，已知至少一个节点观测到 P3 的条件下，威胁等级为 Medium 的条件概率为 **2/7**。
