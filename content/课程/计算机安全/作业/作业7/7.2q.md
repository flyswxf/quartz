### 7.2 State the difference between a SYN flooding attack and a SYN spoofing attack.

SYN 洪泛攻击（SYN flooding attack）和 SYN 欺骗攻击（SYN spoofing attack）的核心区别如下：

1. **核心攻击目标不同**：
   - **SYN 欺骗攻击**：主要消耗目标主机的**系统资源**（如 TCP 连接表、操作系统网络处理代码）。
   - **SYN 洪泛攻击**：主要消耗目标的**网络带宽**（服务器接入链路的容量）。

2. **攻击核心逻辑不同**：
   - **SYN 欺骗攻击**：利用 TCP 三次握手的状态管理机制缺陷，使用伪造源 IP 的 SYN 包生成大量半开连接，占满 TCP 连接表，使服务器无法处理新的合法连接。
   - **SYN 洪泛攻击**：利用网络链路的带宽上限物理限制，用海量 SYN 包（源 IP 可真可假）直接打满链路带宽，让合法流量无法传输。

3. **流量规模需求不同**：
   - **SYN 欺骗攻击**：所需流量规模**极低**，仅需填满容量有限的连接表即可，远达不到链路带宽上限。
   - **SYN 洪泛攻击**：所需流量规模**极高**，需要达到链路的最大带宽容量才能实现最佳攻击效果。
